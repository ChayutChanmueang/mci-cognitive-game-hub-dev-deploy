# 🍎 Game Design Document: Zoo Feeder
## 📄 Overview

**ชื่อเกม:** Zoo Feeder
**หมวดหมู่:** เกมการศึกษา, การจำลองสถานการณ์ (Simulation), การจัดการทรัพยากร (Resource Management)
**วัตถุประสงค์หลัก:** เพื่อให้ผู้เล่นเรียนรู้เกี่ยวกับความต้องการทางอาหารของสัตว์แต่ละชนิดในสวนสัตว์ และฝึกทักษะในการวางแผนและการจัดการทรัพยากรอย่างมีประสิทธิภาพ

---

## 💡 แนวคิดเกม (Concept)

ผู้เล่นรับบทเป็นเจ้าหน้าที่ดูแลสวนสัตว์ที่มีหน้าที่ให้อาหารและดูแลความเป็นอยู่ที่ดีของสัตว์ต่างๆ สัตว์แต่ละตัวมีความต้องการอาหารที่เฉพาะเจาะจง (เช่น กินเนื้อ, กินผัก, หรือกินทั้งสองอย่าง) และการจัดการทรัพยากร (เช่น อาหาร, เวลา) ให้เพียงพอต่อความสุขและการดำรงชีวิตของพวกมัน

## 🧩 กลไกหลักของเกม (Core Mechanics)

1.  **ระบบ Conveyor Belt:**
    *   เป็นหัวใจของการเล่น ที่จำลองสายพานลำเลียงอาหารและสัตว์ที่เคลื่อนที่อย่างต่อเนื่อง (`conveyer.js`).
    *   สัตว์และอาหารจะปรากฏขึ้นตามเวลาที่กำหนดบนสายพานนี้ ทำให้การตอบสนองของผู้เล่นต้องรวดเร็วและแม่นยำ.

2.  **ระบบโภชนาการของสัตว์ (Animal Diet System):**
    *   มีการกำหนดชนิดอาหารอย่างชัดเจนสำหรับสัตว์แต่ละตัว (เช่น `AnimalSetting.COW` อาจต้องการหญ้า/ผัก, `LION` ต้องการเนื้อ).
    *   เมื่อเกิดปฏิสัมพันธ์ระหว่างสัตว์และอาหาร ระบบจะตรวจสอบว่าอาหารที่ได้รับนั้น "เหมาะสม" กับชนิดของสัตว์หรือไม่ (`if(foodType == this.animal.currentAnimal.AcceptableFoodType)`).

3.  **การจัดการทรัพยากร (Resource Management):**
    *   ผู้เล่นต้องบริหารจัดการ 'ความสุข' หรือ 'พลังงาน' ของสัตว์ โดยการให้อาหารที่ถูกต้องและทันเวลา.
    *   ถ้าอาหารผิดชนิดหรือขาดแคลน จะส่งผลต่อสถานะของสัตว์ ซึ่งเป็นเป้าหมายหลักในการทำคะแนน/ผ่านด่าน.

4.  **ปฏิสัมพันธ์ (Interactions):**
    *   **Food Items:** อาหารต่างๆ จะปรากฏบนสายพาน และจะต้องถูก "จับคู่" หรือปล่อยให้เข้าถึงสัตว์ที่เหมาะสมเท่านั้น (`fruit.js`).
    *   **Animal Actions:** สัตว์จะแสดงปฏิกิริยาตามความหิว/ได้รับอาหารอย่างถูกต้อง

## 🗺️ การไหลของเกม (Gameplay Flow)

1.  **เริ่มต้น:** ผู้เล่นถูกแนะนำระบบและเรียนรู้เกี่ยวกับประเภทสัตว์และความต้องการพื้นฐานผ่าน Tutorial Panel.
2.  **การเล่น:** ระบบจะเริ่มส่งสัตว์และอาหารเข้าสู่สายพานลำเลียง. ผู้เล่นต้องสังเกตความหิวของสัตว์ และตัดสินใจว่าจะให้อาหารอะไร (ซึ่งมาจาก `food-items`) กับสัตว์ตัวไหน (ซึ่งอยู่บนสายพาน) ในจังหวะที่เหมาะสมที่สุด.
3.  **การตรวจสอบ:** ระบบจะให้ Feedback ทันทีว่าอาหารนั้น "ถูก" หรือ "ผิด" ทำให้ผู้เล่นต้องปรับกลยุทธ์อย่างรวดเร็ว.
4.  **สิ้นสุดเกม:** เมื่อทำภารกิจตามเป้าหมายได้สำเร็จ (เช่น ดูแลสัตว์ครบจำนวนในเวลาที่กำหนด) จะเข้าสู่หน้าสรุปผลการจัดการทรัพยากรและคะแนนรวม.

## 🧱 องค์ประกอบของระบบ (System Components)

*   **`AnimalSetting`**: แหล่งข้อมูลคงที่ของสัตว์ทุกชนิด รวมถึงคุณสมบัติสำคัญอย่างประเภทอาหารที่สามารถยอมรับได้ (`AcceptableFoodType`).
*   **`Conveyer Belt`**: ระบบหลักในการจำลองเวลาและความเคลื่อนไหวของวัตถุในเกม.
*   **UI Panel:** ใช้สำหรับแสดงสถานะต่างๆ เช่น สัตว์, อาหาร, และคะแนน/แถบความสุข เพื่อให้ผู้เล่นรับทราบข้อมูลอย่างต่อเนื่อง.

## 🛠️ ข้อสังเกตด้านการพัฒนา (Development Notes)

*   เป็นเกมที่มีองค์ประกอบของ Simulation สูง ทำให้เน้นที่ Timing และ Logic การตอบสนอง
*   **การใช้ Object Pooling** เป็นสิ่งสำคัญมากเพื่อให้ประสิทธิภาพการทำงานสูงเมื่อมีวัตถุเคลื่อนไหวจำนวนมาก.
