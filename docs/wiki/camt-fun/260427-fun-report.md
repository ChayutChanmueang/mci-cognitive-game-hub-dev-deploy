
รายงานการประยุกต์ใช้งาน

Claude: ใช้สำหรับงานในด้านของช่วยพัฒนาและเขียนโปรแกรม ซึ่งเน้นไปที่การเขียนโค้ดเชิงเทคนิคในระดับมินิเกมและยูทิลิตี้อย่างเช่นระบบ Procedural Generation, Performance Optimization, UI Interaction, และการ Debugging
Perplexity AI: ใช้สำหรับงานด้านที่เกี่ยวข้องกับงานวิจัยอย่างเช่นการกำหนดขอบเขตในด้านงานวิจัยและใช้ในการช่วยสืบค้นหาข้อมูลที่เกี่ยวข้องกับงานวิจัยที่เกี่ยวกับ MCI และการพัฒนาเกมเพื่อผู้สูงอายุ
OpenRouter: ใช้สำหรับงานในด้านของการช่วยพัฒนาตัวโปรแกรม โดยหลักๆใช้ช่วยในเรื่องของการจัดการภาพรวมระบบและเอกสารตามเทมเพลตมาตรฐาน อย่างเช่น System Architecture & Code Design, Technical Documentation, Progress Log & Management, และ Test Scripting
OverLeaf: ใช้ในด้านของงานเขียน สำหรับเขียนเอกสารงานวิจัย เพื่อส่งตีพิมพ์
