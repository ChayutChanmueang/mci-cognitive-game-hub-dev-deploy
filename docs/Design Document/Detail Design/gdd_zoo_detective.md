# 🦁 Game Design Document: Zoo Detective
## 📄 Overview

**ชื่อเกม:** Zoo Detective
**หมวดหมู่:** เกมการศึกษา, ปริศนาเชิงตรรกะ (Logic Puzzle), การจำแนกสัตว์
**วัตถุประสงค์หลัก:** เพื่อให้ผู้เล่นเรียนรู้เกี่ยวกับชนิดของสัตว์ต่างๆ ในสวนสัตว์ และพัฒนาทักษะในการวิเคราะห์ความสัมพันธ์ทางพื้นที่และตรรกะ

---

## 💡 แนวคิดเกม (Concept)

ผู้เล่นรับบทเป็นนักสืบที่ต้องช่วยจัดวางสัตว์ต่างๆ ในส่วนประกอบของสวนสัตว์ให้ถูกต้องตามเงื่อนไขที่กำหนด โดยแต่ละรอบเกมจะถูกนำเสนอในรูปแบบของการจับคู่ข้อมูล (Puzzle Matching) ซึ่งอาศัยความรู้เกี่ยวกับชนิดและพฤติกรรมของสัตว์

## 🧩 กลไกหลักของเกม (Core Mechanics)

1.  **การสร้างปริศนา (Puzzle Generation):**
    *   ระบบจะสร้างตารางปริศนาที่กำหนดตำแหน่งสำหรับสัตว์หลายตัว (`totalSlots`) โดยใช้ชุดข้อมูลสัตว์พื้นฐาน (`DefaultAnimals`).
    *   มีการสุ่มจัดเรียงสัตว์ในตำแหน่งต่างๆ อย่างเป็นระเบียบแต่ท้าทาย เพื่อให้เกิดความสัมพันธ์ทางพื้นที่ (Relative Positioning).

2.  **การโต้ตอบของผู้เล่น (Player Interaction):**
    *   ผู้เล่นต้องทำการเลือกและวางสัตว์ลงในช่องว่างที่กำหนด (`cell`).
    *   การเลือกและการวางมีเงื่อนไข: ผู้เล่นสามารถทำได้เฉพาะกับสัตว์ที่ไม่ถูกล็อกตำแหน่งเท่านั้น และไม่สามารถวางทับสัตว์ตัวอื่น.

3.  **ระบบตรรกะ (Logic System):**
    *   เกมจะใช้หลักการเปรียบเทียบความสัมพันธ์ระหว่างสัตว์ที่อยู่ใกล้กัน หรือตามเงื่อนไขที่กำหนดในรอบนั้นๆ เช่น "สัตว์ A อยู่ทางเหนือของสัตว์ B" หรือ "สัตว์ C กินสัตว์ D".
    *   ผู้เล่นต้องใช้ตรรกะในการตัดตัวเลือกที่ไม่ถูกต้องออกไปทีละขั้น จนกว่าจะสามารถจัดวางตำแหน่งของสัตว์ทั้งหมดให้สอดคล้องกับเงื่อนไขที่กำหนดได้.

## 🗺️ การไหลของเกม (Gameplay Flow)

1.  **เริ่มต้น:** ระบบนำเสนอฉากและรายการคำใบ้/ข้อจำกัดต่างๆ ของรอบปัจจุบัน
2.  **การเล่น:** ผู้เล่นเลือกสัตว์และพยายามวางลงในตารางปริศนาทีละตัว โดยระบบจะทำการตรวจสอบความถูกต้องของการจัดวางทันที.
3.  **การประเมินผล:** หลังจากวางตำแหน่งแล้ว ระบบจะคำนวณว่าการจัดวางนั้นสอดคล้องกับเงื่อนไขของเกมหรือไม่ หากไม่ถูกต้อง ผู้เล่นจะต้องปรับเปลี่ยนหรือพิจารณาสัตว์ตัวถัดไป.
4.  **สิ้นสุดรอบ:** เมื่อผู้เล่นสามารถเติมเต็มสัตว์ในทุกช่องให้สมบูรณ์และสอดคล้องกับตรรกะทั้งหมด ระบบจะจบตาเกมและคำนวณคะแนน/ความสำเร็จ.

## 🧱 องค์ประกอบของระบบ (System Components)

*   **`Constants`**: เป็นแหล่งเก็บข้อมูลหลักของสัตว์ต่างๆ รวมถึงคุณสมบัติที่ใช้ในการทำ Puzzle เช่น ชนิดอาหาร, ตำแหน่งอ้างอิงทางทิศทาง.
*   **`AnimalIconTray`**: ส่วนติดต่อผู้ใช้สำหรับแสดงสัตว์ที่มีให้เลือก และจัดการการใช้งานเมื่อมีการเลือก/วาง.
*   **`GameplayController`**: ตัวควบคุมหลักของเกม รับผิดชอบในการรับ Input จากผู้เล่น, จัดการสถานะของกระดาน (Board State), และเรียกใช้ตรรกะจาก `RandomPuzzle`.

## 🛠️ เทคโนโลยีและการพัฒนา (Technical Notes)

*   **Framework:** Phaser Game Engine.
*   **Language:** JavaScript/TypeScript.
*   **จุดเด่นด้านเทคนิค:** มีการจัดการหน่วยความจำที่ดีด้วย **Object Pooling** ในส่วนของยูทิลิตี้ เพื่อรองรับการสร้างและทำลายวัตถุในเกมซ้ำๆ อย่างมีประสิทธิภาพ.
