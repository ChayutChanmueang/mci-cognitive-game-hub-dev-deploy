# 📐 Game Design Document: Symmetry Decor
## 📄 Overview

**ชื่อเกม:** Symmetry Decor
**หมวดหมู่:** เกมการศึกษา, ศิลปะดิจิทัล (Digital Art), การออกแบบเชิงสมมาตร (Symmetry Logic)
**วัตถุประสงค์หลัก:** เพื่อให้ผู้เล่นได้เรียนรู้และฝึกทักษะในการสร้างสรรค์ลวดลายหรือองค์ประกอบภาพที่สมบูรณ์โดยอาศัยหลักการของความสมมาตร (Symmetry Principle).

---

## 💡 แนวคิดเกม (Concept)

ผู้เล่นได้รับมอบหมายให้ออกแบบงานศิลปะดิจิทัล (Decoration/Template) โดยมีพื้นฐานของลวดลายเพียงครึ่งเดียว (Half-Pattern) หรือจุดศูนย์กลางที่ต้องทำให้สมมาตรกัน เกมจะเน้นการใช้หลักการทางเรขาคณิตและทัศนศิลป์ในการจัดวางองค์ประกอบให้เกิดความลงตัวและความเป็นระเบียบ.

## 🧩 กลไกหลักของเกม (Core Mechanics)

1.  **Template/Mirroring System:**
    *   ระบบจะแสดงพื้นที่ทำงานที่มีแนวแกนสมมาตร (Axis of Symmetry).
    *   เมื่อผู้เล่นวางองค์ประกอบชิ้นหนึ่งในฝั่งหนึ่ง (เช่น ด้านซ้าย), ระบบจะต้องทำการ "สะท้อน" องค์ประกอบนั้นไปยังอีกด้านหนึ่งโดยอัตโนมัติ เพื่อให้เกิดความสมมาตรที่สมบูรณ์.

2.  **Draggable Components:**
    *   ผู้เล่นจะได้รับชุดของชิ้นส่วนตกแต่ง (Decorating Elements) ที่เป็นวัตถุแบบ `draggable`.
    *   การลากและวางองค์ประกอบเหล่านี้จะต้องคำนึงถึงตำแหน่งและความสัมพันธ์กับแกนสมมาตร.

3.  **Placement Logic (Matching):**
    *   เกมจะให้เงื่อนไขเฉพาะสำหรับแต่ละรอบ เช่น "ต้องใช้ดอกไม้ 2 ชนิด", หรือ "ส่วนบนต้องมีสี A, ส่วนล่างมีสี B".
    *   การจัดวางองค์ประกอบทั้งหมดในพื้นที่ทำงานจะต้องสอดคล้องกับเงื่อนไขเหล่านี้ และรักษาสภาวะสมมาตรอยู่เสมอ.

4.  **Evaluation & Feedback:**
    *   ระบบจะตรวจสอบความถูกต้องของการตกแต่งโดยเปรียบเทียบแต่ละส่วนที่ผู้เล่นใส่ลงไป กับหลักการทางทัศนศิลป์และความต้องการของรอบนั้นๆ เพื่อให้คะแนน/Feedback ทันที.

## 🗺️ การไหลของเกม (Gameplay Flow)

1.  **เริ่มต้น:** ระบบจะนำเสนอแนวคิดหรือธีมของงานศิลปะที่จะต้องสร้างสรรค์ และกำหนดแกนสมมาตร.
2.  **การวางแผน:** ผู้เล่นเลือกองค์ประกอบที่เหมาะสมจากพาเลทและเริ่มลากวางบนพื้นที่ทำงานฝั่งใดฝั่งหนึ่ง.
3.  **การตกแต่ง:** เมื่อปล่อยชิ้นส่วน ระบบจะทำการ Mirroring (สะท้อน) ชิ้นส่วนนั้นไปยังอีกฝั่งโดยอัตโนมัติ ทำให้เกิดภาพสมบูรณ์แบบตามหลักสมมาตร.
4.  **ความคืบหน้า:** ผู้เล่นจะต้องเติมเต็มพื้นที่ทั้งหมดให้เสร็จสิ้น โดยที่ทุกองค์ประกอบยังคงรักษาความเป็นระเบียบและความหมายเชิงศิลปะไว้.
5.  **จบเกม:** เมื่อออกแบบลวดลายได้ครบถ้วน ระบบจะประเมินผลตามเกณฑ์ต่างๆ (เช่น ความสมบูรณ์, การใช้สี, ความหลากหลายของลวดลาย) และสรุปคะแนนการเป็นนักออกแบบที่ยอดเยี่ยม

## 🧱 องค์ประกอบของระบบ (System Components)

*   **`TemplatePanel`**: ส่วนติดต่อผู้ใช้สำหรับแสดงชิ้นส่วนตกแต่งที่มีให้เลือก.
*   **`UI-Panel`**: จัดการพื้นที่ทำงานหลักและแนวแกนสมมาตร.
*   **`Draggable Component`**: องค์ประกอบที่สามารถถูกลากเพื่อเริ่มกระบวนการออกแบบได้.
*   **`Symmetry Logic Engine`**: ส่วนโค้ดสำคัญที่สุดที่รับผิดชอบในการคำนวณตำแหน่งที่สะท้อนของวัตถุเมื่อผู้เล่นวางในฝั่งใดฝั่งหนึ่ง.

## 🛠️ ข้อสังเกตด้านการพัฒนา (Development Notes)

*   เป็นเกมที่เน้น Visual Learning และ Fine Motor Skills
*   ความซับซ้อนอยู่ที่การสร้างระบบ Reflection/Mirroring ที่แม่นยำทางโค้ด เพื่อให้มั่นใจว่าทุกวัตถุถูกวางในตำแหน่งที่สมมาตรอย่างแท้จริง.
