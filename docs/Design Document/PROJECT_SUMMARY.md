# 📖 สรุปภาพรวมโครงการ (Project Overview)

โปรเจกต์นี้เป็นแอปพลิเคชันขนาดใหญ่ที่ประกอบด้วย **Mini-Games Collection** หรือชุดเกมย่อยหลายเกม ที่มีวัตถุประสงค์ในการเรียนรู้และการโต้ตอบ โดยถูกออกแบบมาให้มีโครงสร้างแบบโมดูลาร์สูง ทำให้ง่ายต่อการพัฒนาและเพิ่มเกมใหม่ๆ เข้าไปในระบบ

---

## 📂 โครงสร้างหลักของโครงการ (Project Structure)

โปรเจกต์นี้แบ่งออกเป็นส่วนประกอบที่ชัดเจนดังนี้:

### 1. โมดูลหลัก/ส่วนกลาง (`src/util` & `src/core`)
เป็นส่วนที่จัดการฟังก์ชันพื้นฐานและเครื่องมือที่ใช้ร่วมกันทั่วทั้งโปรเจกต์ เพื่อให้เกมต่างๆ สามารถเรียกใช้งานได้โดยไม่ต้องเขียนโค้ดซ้ำ (Reusability).

*   **`src/util/`**: กลุ่มยูทิลิตี้ที่สำคัญ เช่น:
    *   **Layout Management**: สำหรับการจัดวางองค์ประกอบ UI ต่างๆ บนหน้าจออย่างเป็นระบบ (`progress-bar`, `square-grid-layout`)
    *   **Object Pooling**: ใช้จัดการวัตถุในเกมเพื่อเพิ่มประสิทธิภาพการทำงาน (Memory Optimization).
    *   **Thai Text Handling**: การรองรับและแสดงผลข้อความภาษาไทยที่ซับซ้อน.
*   **`src/core/`**: จัดการระบบระดับสูงของแอปพลิเคชัน:
    *   **Database/Storage Manager**: ระบบจัดการข้อมูลและการบันทึกสถานะของผู้ใช้ (Persistence).
    *   **Drag-Drop Manager**: กลไกที่ควบคุมการลากและวางวัตถุในเกม.

### 2. โมดูลเกมย่อย (`src/game/`)
แต่ละโฟลเดอร์ภายใต้ `src/game/` คือเกมหลักหนึ่งเกม ซึ่งมีการจัดโครงสร้างภายในที่สม่ำเสมอ ประกอบด้วย:

*   **`constants.js`**: ค่าคงที่เฉพาะของเกมนั้นๆ.
*   **`main.js`**: ตัวควบคุมและตรรกะหลักในการทำงานของเกม (Game Controller).
*   **`scenes/`**: การจัดการสถานะต่างๆ ของเกม ตั้งแต่การโหลด (`Preloader`) จนถึงหน้าเล่นจริง (`Gameplay`).
*   **`entity/` และ `components/`**: ส่วนประกอบที่ใช้กำหนดวัตถุและฟังก์ชันเฉพาะที่จะโต้ตอบได้ในฉากเกม (Game Elements).
*   **`ui-elements/`**: การสร้างส่วนติดต่อผู้ใช้ย่อยๆ ที่จำเป็นสำหรับเกมนั้นๆ เช่น แผงคะแนน, ปุ่มคำถาม.

## 🧩 เกมที่ตรวจพบ (Detected Mini-Games)

โครงการนี้ได้พัฒนาเกมการเรียนรู้หลายหัวข้อ ซึ่งแต่ละหัวข้อถูกแยกเป็นโดเมนของตัวเอง:

1.  **Zoo Detective**: แนวสืบสวน/ควิซเกี่ยวกับสัตว์
2.  **Context Clues**: เน้นทักษะทางภาษาและการเดาคำศัพท์จากบริบทแวดล้อม.
3.  **Zoo Feeder**: เกมจำลองการจัดการทรัพยากร/กิจกรรมในสวนสัตว์ (อาจเกี่ยวข้องกับเส้นทาง).
4.  **Symmetry Decor**: เกมที่ใช้หลักการสมมาตรในการตกแต่งศิลปะ.
5.  **Postcard Reader**: เกมที่น่าจะเกี่ยวกับการจัดเรียงหรืออ่านข้อมูลจากไพ่/โปสการ์ด.

## ✅ ข้อสรุปและแนวทางการพัฒนา

*   **จุดแข็ง:** การออกแบบระบบโมดูลาร์ทำให้สามารถขยายฟังก์ชันได้ง่ายมาก นักพัฒนามีการแยกความรับผิดชอบ (Separation of Concerns) ได้ดีเยี่ยม
*   **เทคโนโลยีที่ใช้:** น่าจะใช้ Game Engine เช่น Phaser ร่วมกับ JavaScript/TypeScript.
*   **คำแนะนำสำหรับการทำงานต่อ:** หากต้องการเพิ่มเกมใหม่ ควรทำตามโครงสร้างของเกมที่มีอยู่แล้วใน `src/game/...` และใช้ยูทิลิตี้จาก `src/util/...` เป็นหลัก
