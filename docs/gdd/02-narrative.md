# MCI Cognitive Games — Narrative & Theme

**Version:** 1.0 | **Last Updated:** 2026-05-02

## World / Theme
โปรเจกต์นี้ใช้ธีมที่เน้นความเป็นมิตรและเข้าถึงง่ายสำหรับผู้สูงอายุ โดยแบ่งออกเป็น 2 ธีมหลัก:
- **Zoo Theme (สวนสัตว์):** ใช้ในเกม Zoo Detective และ Zoo Feeder เพื่อสร้างความตื่นเต้นและการผจญภัยที่เข้าใจง่าย
- **Daily Life (ชีวิตประจำวัน):** ใช้ในเกม Context Clues และ Postcard Reader เพื่อให้ผู้เล่นรู้สึกคุ้นเคยกับสถานการณ์จริง

## Narrative Tone
โทนของเกมเน้นความใจเย็น (Calm), การให้กำลังใจ (Encouraging), และความสนุกสนาน (Playful) ไม่กดดันผู้เล่นจนเกินไป เพื่อให้เหมาะกับการเป็นเกมฝึกทักษะทางปัญญา
