# 📬 Game Design Document: Postcard Reader
## 📄 Overview

**ชื่อเกม:** Postcard Reader (ผู้อ่านไปรษณีย์)
**หมวดหมู่:** เกมการศึกษา, ความจำ (Memory), การอ่านเข้าใจ (Reading Comprehension)
**วัตถุประสงค์หลัก:** เพื่อพัฒนาทักษะการจดจำข้อมูลเชิงลำดับ (Sequencing) และการดึงข้อมูลจากความทรงจำระยะสั้น

---

## 💡 แนวคิดเกม (Concept)

ผู้เล่นจะได้รับบทเป็นผู้รับไปรษณีย์ที่ต้องอ่านและจดจำรายละเอียดต่างๆ ที่ปรากฏบนการ์ด (เช่น ชื่อผู้ส่ง, สถานที่, หรือสิ่งที่ทำ) จากนั้นระบบจะซ่อนไปรษณีย์และตั้งคำถามเพื่อทดสอบความแม่นยำในการจำของผู้เล่น

## 🧩 กลไกหลักของเกม (Core Mechanics)

1.  **ระยะการจดจำ (Memory Phase):**
    *   ระบบแสดงไปรษณีย์ที่มีทั้งข้อความ (Text) และรูปภาพ (Visuals).
    *   ผู้เล่นมีเวลาจำกัดในการอ่านและจดจำเนื้อหา โดยมี `ProgressBar` แสดงเวลาที่เหลือ.

2.  **ระยะการตอบคำถาม (Quiz Phase):**
    *   ไปรษณีย์ถูกซ่อนหรือเลือนหายไป.
    *   ระบบแสดงคำถามที่เกี่ยวข้องกับเนื้อหาในไปรษณีย์ (เช่น "ใครเป็นผู้ส่งไปรษณีย์ฉบับนี้?").
    *   ผู้เล่นเลือกคำตอบที่ถูกต้องจากตัวเลือกที่กำหนด.

3.  **ระบบการให้คะแนน (Scoring System):**
    *   คำนวณคะแนนตามความถูกต้องของคำตอบและเวลาที่ใช้ในการตอบในแต่ละรอบ.

## 🗺️ การไหลของเกม (Gameplay Flow)

1.  **เริ่มต้น:** ระบบแสดงไปรษณีย์สุ่ม.
2.  **จดจำ:** ผู้เล่นจดจำรายละเอียดภายในเวลาที่กำหนด.
3.  **ทดสอบ:** ระบบถามคำถามเกี่ยวกับรายละเอียดที่จำไป.
4.  **สิ้นสุดรอบ:** สรุปผลการตอบคำถามและเริ่มไปรษณีย์ฉบับถัดไป หรือจบเกมเมื่อครบจำนวนรอบ.

## 🧱 องค์ประกอบของระบบ (System Components)

*   **`PostcardPanel`**: จัดการการแสดงผลกราฟิกและข้อความบนไปรษณีย์ให้ดูสมจริงและอ่านง่าย.
*   **`ProgressBar`**: แสดงสถานะเวลาคงเหลือในระยะการจดจำ.
*   **`GameLogicController`**: ควบคุมสถานะการเปลี่ยนผ่านระหว่าง Memory Phase และ Quiz Phase.

## 🛠️ เทคโนโลยีและการพัฒนา (Technical Notes)

*   **Framework:** Phaser 3.
*   **Architecture:** ใช้รูปแบบ **ECS Lite** เพื่อจัดการ UI Elements และ Gameplay Logic แยกกันอย่างชัดเจน.
*   **Polish Focus:** เน้นการแสดงผลที่ชัดเจนและระบบเสียงอ่าน (Voice Over) เพื่อช่วยผู้สูงอายุจดจำข้อมูลได้ดียิ่งขึ้น.
