# 📝 Game Design Document: Context Clues
## 📄 Overview

**ชื่อเกม:** Context Clues (คำใบ้บริบท)
**หมวดหมู่:** เกมการศึกษา, ภาษา (Language), การเข้าใจบริบท (Contextual Learning)
**วัตถุประสงค์หลัก:** เพื่อพัฒนาทักษะการอ่าน การจำแนกคำศัพท์ และการใช้เหตุผลเชิงภาษาผ่านสถานการณ์ในชีวิตประจำวัน

---

## 💡 แนวคิดเกม (Concept)

ผู้เล่นจะได้อ่านประโยคที่มีช่องว่างหายไป และต้องเลือกคำตอบที่ถูกต้องที่สุดจากตัวเลือกที่กำหนดให้ โดยอาศัยคำใบ้หรือบริบทที่ปรากฏในประโยค (Contextual Clues) เพื่อช่วยในการตัดสินใจ

## 🧩 กลไกหลักของเกม (Core Mechanics)

1.  **ระบบนำเสนอโจทย์ (Quiz Presentation):**
    *   ระบบสุ่มโจทย์จากคลังข้อมูล (`QuizGameData`).
    *   แต่ละโจทย์ประกอบด้วยประโยคคำถาม (Sentence with Gaps) และรายการตัวเลือกคำตอบ (Multiple Choices).

2.  **การโต้ตอบของผู้เล่น (Player Interaction):**
    *   ผู้เล่นอ่านโจทย์และเลือกคำตอบที่คิดว่าถูกต้องผ่านการ Click/Tap.
    *   ใช้ `EmojiRenderer` เพื่อแสดงผลไอคอนหรืออิโมจิประกอบคำตอบ เพื่อช่วยให้ผู้สูงอายุจดจำและแยกแยะได้ง่ายขึ้น.

3.  **ระบบการให้คะแนน (Scoring System):**
    *   ตอบถูก: +20 คะแนน.
    *   ตอบผิด: -5 คะแนน.
    *   มีระดับความยาก 3 ระดับ (Easy, Medium, Hard) ซึ่งส่งผลต่อความซับซ้อนของประโยคและจำนวนรอบ.

## 🗺️ การไหลของเกม (Gameplay Flow)

1.  **เริ่มต้น:** แสดงโจทย์และตัวเลือกคำตอบ.
2.  **การเล่น:** ผู้เล่นพิจารณาบริบทและเลือกคำตอบที่เหมาะสมที่สุด.
3.  **การตรวจสอบ:** ระบบประเมินคำตอบทันที (Correct/Incorrect Feedback).
4.  **สิ้นสุดรอบ:** เมื่อตอบครบจำนวนรอบที่กำหนด (ปกติ 10 รอบ) ระบบจะสรุปคะแนนและแสดงหน้า GameOver.

## 🧱 องค์ประกอบของระบบ (System Components)

*   **`RandomQuiz`**: จัดการการสุ่มโจทย์และลำดับของตัวเลือกคำตอบ เพื่อป้องกันการจดจำตำแหน่ง.
*   **`EmojiRenderer`**: คอมโพเนนต์สำหรับจัดการการแสดงผลอิโมจิใน UI ให้มีความสวยงามและชัดเจน.
*   **`TriggerListener`**: จัดการเหตุการณ์การโต้ตอบ (Event Handling) เมื่อผู้เล่นเลือกคำตอบ.

## 🛠️ เทคโนโลยีและการพัฒนา (Technical Notes)

*   **Framework:** Phaser 3.
*   **Architecture:** ใช้รูปแบบ **ECS Lite** (Entity-Component System) เพื่อแยก Logic การแสดงผลและการตรวจสอบออกจากกัน.
*   **Thai Support:** รองรับฟอนต์ภาษาไทยอย่างสมบูรณ์ผ่าน `ThaiText` utility.
