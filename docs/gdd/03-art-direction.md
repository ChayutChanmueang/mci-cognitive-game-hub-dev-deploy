# MCI Cognitive Games — Art Direction

**Version:** 1.0 | **Last Updated:** 2026-05-02

## Visual Style
- **Art Style:** Emoji-based และ Iconic สไตล์ (🦁🐘🍎🐟) เพื่อความชัดเจนและประหยัดทรัพยากร
- **UI Framework:** Material UI สำหรับระบบ Login/Signup/GameHub
- **In-Game UI:** Phaser-based UI พร้อมปุ่มขนาดใหญ่ (Large Buttons)

## UI/UX Guidelines for MCI Players
- **High Contrast:** ใช้สีที่ตัดกันชัดเจนเพื่อช่วยการมองเห็น
- **Feedback Systems:** 
  - Visual: Animation และไอคอนสถานะ (Correct/Incorrect)
  - Audio: เสียงตอบรับเมื่อมีการกระทำที่ถูกต้องหรือผิด
- **Simplified Navigation:** ลดขั้นตอนการเข้าถึงเกมให้สั้นที่สุด (One-click access)

## Assets
- **Location:** `public/assets/`
- **Type:** Emoji Icons, SVG, and basic Sound Effects
