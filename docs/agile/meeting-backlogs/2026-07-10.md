## 2. Discussion Notes (ข้อเสนอแนะจากการลงพื้นที่)

### 2.1 ภัยพิบัติระดับ Symmetry (Symmetry Decor)
- ผู้สูงอายุ **เอารูปสัตว์ไปวางในช่องฝั่งโจทย์** ผิดเยอะมาก → ต้อง **บล็อกไม่ให้วางในช่องฝั่งโจทย์**
- รูปแบบการสะท้อน **สะท้อนเฉียง** และ **สะท้อนหมุน 180°** ยากเกินไปสำหรับผู้สูงอายุ → **เอาออก** เหลือแค่สะท้อนซ้าย-ขวา
- **ลดจำนวนช่อง** ต่อเลเวล: ง่าย = **2×2**, ปานกลาง = **4×4**, ยาก = **6×6**
- **เส้นแบ่ง** ระหว่างฝั่งโจทย์/ฝั่งตอบ มองไม่ชัด → ลองเส้นใหญ่ขึ้น / เข้มขึ้น
- เมื่อ **เวลาหมด** ผู้สูงอายุที่เล่นไม่ผ่าน **จบเกมไม่ได้** → ต้องให้เกม **ตัดจบได้เลย** เมื่อหมดเวลา

### 2.2 เกมทำอาหาร (Fry Food)
- บางเครื่องผู้สูงอายุ **ไม่มี Gyroscope** ทำให้ผัดอาหารไม่ได้
- ต้องมี **ปุ่มข้าม** — ผู้เล่นที่กดข้าม **ไม่ได้รับคะแนน** ในมินิเกมนี้

### 2.3 เกมสัตว์นักสืบ (Zoo Detective)
- Input ปัจจุบันเป็น **จิ้มเพื่อวาง** แต่เกมอื่นใช้ **ลากเพื่อวาง** → ผู้สูงอายุสับสน
- ปรับเป็น **ลากเพื่อวาง** ให้สอดคล้องกับเกมอื่น

### 2.4 เกมจดหมายจากหลานรัก (Postcard Reader)
- ผู้สูงอายุตั้งใจอ่านโจทย์มาก แต่ **ตัวหนังสือยังเล็ก** (แม้จะขยายใน [US-E7-09](../user-stories/US-E7-09.md) แล้ว)
- ต้อง **ขยายตัวอักษรโจทย์ให้ใหญ่ขึ้นอีก**

### 2.5 ต้นคิดดี (Check-in Tree)
- **นำต้นคิดดีทั้ง 4 ต้นมาสุ่มให้ผู้สูงอายุ**
- ⤷ **ครอบคลุมแล้ว** ใน [US-E8-01](../user-stories/US-E8-01.md) (Sprint 08) — สุ่ม `tree_type` จาก `game_tree_list` (`a`/`b`/`c`/`d`)

### 2.6 ข้อมูลหลังบ้าน (Backend / Admin)
- ลองหาวิธี **ดึงข้อมูลทั้งหมดของผู้เล่นออกมาทีเดียว** ได้แบบ **ข้อมูลไม่หาย**
- จัดเป็น **Phase 2** (หลังแก้ปัญหาระหว่างเล่นเกม)

### 2.7 หน้าจอดับระหว่างเล่น (Screen Timeout)
- บางเครื่องตั้งค่า **พักหน้าจอน้อย** ทำให้เล่นเกมไปแล้ว **จอดับ**

### 2.8 ประสิทธิภาพเครื่องสเปคต่ำ
- เอฟเฟคหน้า **"เก่งมาก!!!"** ทำให้เครื่องสเปคต่ำ **กระตุกและค้าง**
- **Phaser ใช้ทรัพยากรมากเกินไป** — บางเครื่องเข้าเกมไม่ได้
- เครื่องอ้างอิงขั้นต่ำสุด: **Samsung Galaxy A10s** (Helio P22, 2–3 GB RAM, PowerVR GE8320)

### 2.9 Game Hub — ชื่อเกม vs หมวดหมู่
- ใน node บน Game Hub **ชื่อเกม** และ **ชื่อหมวดหมู่** ยังสลับกันไม่ตรงความต้องการ
- ต้องการ: **ชื่อเกมด้านบน** / **หมวดหมู่ด้านล่าง** (สลับจากสถานะปัจจุบัน)

### 2.10 ฟอนต์ระบบขยายใหญ่ (System Font Scale)
- โทรศัพท์บางเครื่องตั้ง **ขนาดตัวอักษรระบบใหญ่มาก** (ผู้สูงอายุใช้สายตาอ่าน)
- ฟอนต์ในเกม **ขยายตามระบบเกินไป** → **layout ผิดเพี้ยน**

### 2.11 แก้ไข HN ที่ลงทะเบียนผิด (Admin CLI)
- ต้องการสคริปต์แก้ **`hn`** แบบเดียวกับ `delete-user.js`
- กรณีที่พบ: ผู้เล่น **ใส่เบอร์โทรแทน HN**

### 2.12 ปีเกิดในหน้าสร้างบัญชี — พ.ศ.
- หน้า Sign-up แสดงปีเป็น **ค.ศ.** ทำให้ผู้สูงอายุบางคน **ไม่รู้ว่าเกิดปี ค.ศ. ไหน**
- ควรเป็น **พ.ศ.**
