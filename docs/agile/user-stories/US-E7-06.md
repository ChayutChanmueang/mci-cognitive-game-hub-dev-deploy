# User Story: US-E7-06 - มินิเกมรองรับการยืดแนวตั้ง (Vertical Responsive)

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** [Developer/AI]

---

## 📖 Description
**ในฐานะ** ผู้เล่นบนมือถือที่มีอัตราส่วนหน้าจอแนวตั้งหลากหลาย
**ฉันต้องการ** ให้มินิเกม (Phaser) ยืดเต็มพื้นที่ในแนวตั้งได้
**เพื่อให้** เกมใช้พื้นที่หน้าจอเต็มที่ ไม่มีแถบดำ (letterbox) ด้านบน/ล่าง และ element ในเกมไม่ถูกตัดขอบบนจอที่สูง

---

## ✅ Acceptance Criteria
1. [ ] มินิเกมทุกเกม (Zoo Detective, Zoo Feeder, Context Clues, Symmetry Decor, Postcard Reader, Fry Food) ยืดเต็มความสูงของ viewport
2. [ ] เมื่อความสูงเพิ่มขึ้น element ในเกม (HUD, board, ปุ่ม, พื้นหลัง) จัดตำแหน่ง/anchor ถูกต้อง ไม่ลอยกลางจอหรือถูกตัด
3. [ ] ไม่มีแถบดำ/พื้นที่ว่างผิดปกติด้านบนหรือล่างของเกมบนจอแนวตั้ง
4. [ ] gameplay ยังทำงานถูกต้อง (hitbox, drag-drop, การวางตำแหน่ง) หลังการยืดแนวตั้ง
5. [ ] ผ่านการทดสอบบนช่วงความสูงหน้าจอแนวตั้งที่กว้าง (เช่น 16:9 ถึง 20:9 ขึ้นไป)

---

## 🛠 Technical Tasks
- [ ] เลือก/ปรับกลยุทธ์ Phaser `Scale` ให้รองรับการยืดแนวตั้ง (เช่น `Scale.RESIZE` หรือ `FIT` + reflow แทน letterbox)
- [ ] ปรับ resize/reflow handler ในแต่ละ Gameplay scene ให้ re-layout เมื่อความสูงเปลี่ยน
- [ ] ผูก anchor ของ HUD/board/background กับขอบจอ (top/bottom/center) แทนค่าพิกัดคงที่
- [ ] ตรวจสอบ background และ asset ให้ครอบคลุมพื้นที่แนวตั้งที่เพิ่มขึ้น
- [ ] ทดสอบ regression ของ gameplay ทุกเกมหลังเปลี่ยน scale
