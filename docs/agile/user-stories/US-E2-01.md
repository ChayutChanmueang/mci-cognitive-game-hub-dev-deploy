## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** หน้าหลัก (Gamehub) ที่รวมข้อมูลความคืบหน้าของฉันไว้ในที่เดียว
**เพื่อให้** ฉันสามารถเข้าถึงการเล่นเกมและดูสถานะของตนเองได้อย่างง่ายดาย

---

## ✅ Acceptance Criteria
1. [x] แสดงข้อมูลพื้นฐานของผู้เล่น (ชื่อ, HN)
2. [x] มีส่วนแสดงผล Daily Goal (เป้าหมายของวันนี้)
3. [x] มีส่วนแสดงผล Daily Streak (เป้าหมายของฉัน)
4. [x] มีปุ่มหรือไอคอนสำหรับเข้าถึงเมนู "ข้อมูลผู้ใช้" (Admin only)
5. [x] มีหน้าแผนที่ด่าน (Level Progression) ที่แสดงปุ่มกดเข้าเล่นเกม
