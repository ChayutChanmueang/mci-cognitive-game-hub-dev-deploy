## 📖 Description
**ในฐานะ** ผู้พัฒนา
**ฉันต้องการ** ออกแบบและสร้างโครงสร้างฐานข้อมูล (Table Schema) ใน Supabase
**เพื่อให้** ระบบสามารถจัดเก็บข้อมูลผู้ป่วยและผลการเล่นเกมได้อย่างปลอดภัยและเป็นระบบ

## ✅ Acceptance Criteria
1. [x] ออกแบบโครงสร้าง Table รองรับข้อมูลผู้ป่วย (Patients) และผลลัพธ์ (Results)
2. [x] กำหนดความสัมพันธ์ (Relationship) ระหว่างตารางให้ถูกต้อง
3. [x] ตั้งค่า Row Level Security (RLS) เพื่อความปลอดภัยของข้อมูล
