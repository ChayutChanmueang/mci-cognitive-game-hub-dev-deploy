## 📌 Implementation Notes

**ทำไมไม่ใช้ `<input type="date">`:** HTML5 date input **บังคับให้ render ปฏิทินและข้อความตาม locale ของ browser เอง** และไม่มี attribute ใดให้ override เป็น พ.ศ. ได้ (ไม่มี `era` / `calendar` option) — จึงต้องเปลี่ยน control ทั้งตัว ไม่ใช่แค่ format ค่า

**ทำไมเลือก native `<select>` 3 ช่อง แทน datepicker library:** ทางเลือกที่พิจารณาคือ `bootstrap-datepicker-thai` ซึ่งต้องดึง **jQuery** (ไม่ใช่ dependency ของโปรเจกต์) + plugin ยุค Bootstrap 2/3 + CSS ของมันเอง (~120KB) และชนกับ component system `gh-*` ที่มีอยู่ — ขัดกับหลัก "keep the bundle small" ของโปรเจกต์ ส่วน select 3 ช่อง: **ไม่เพิ่ม dependency เลย**, ผู้สูงอายุ **ไม่ต้องพิมพ์**, ได้ native wheel picker บนมือถือ (touch target ใหญ่), และ **กรอกวันที่ผิดรูปแบบไม่ได้เลย**

**เดือนแสดงแบบย่อ:** native `<select>` แสดงได้เฉพาะ text ของ option ที่ถูกเลือก จึงทำ "ย่อตอนปิด / เต็มตอนเปิด" ด้วย CSS ไม่ได้ — component เขียนทับ text ของ option ตอนเปิด/ปิด dropdown (`มกราคม` ใน list → `ม.ค.` เมื่อเลือกแล้ว) โดย `value` ยังเป็นเลขเดือนเสมอ ค่าจึงไม่ถูกกระทบ

**Layout:** 3 select ถูกรวมเป็น pill เดียว (`gh-frame-field-box-date-l/-c/-r` — มุมโค้งเฉพาะซ้าย-ขวานอก) เพื่อให้แถววันที่ยังอยู่ใน 2-column grid เดิมเหมือนช่องอื่น ๆ และใช้ font-size เท่ากับช่อง ชื่อ / เพศ / การศึกษา
