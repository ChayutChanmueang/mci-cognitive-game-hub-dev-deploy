## 📖 Description
**ในฐานะ** ผู้สูงอายุที่ลงทะเบียนใหม่
**ฉันต้องการ** ให้เลือก/เห็น **ปีเกิดเป็น พ.ศ.** ในหน้าสร้างบัญชี
**เพื่อให้** รู้ว่าเกิดปีไหน โดยไม่ต้องแปลงจาก ค.ศ. ที่ไม่คุ้นเคย

---

## 🐛 Problem (จากการลงพื้นที่ — v1.0.0)
- หน้า Sign-up แสดง/รับ **ปีเกิดเป็น ค.ศ.**
- ผู้สูงอายุหลายคน **ไม่รู้ว่าเกิดปี ค.ศ. ไหน** แต่คุ้นเคย **พ.ศ.**

---

## ✅ Acceptance Criteria
1. [ ] ฟิลด์ปีเกิดในหน้า **Sign-up** แสดงและรับค่าเป็น **พ.ศ.** (หรือมีตัวเลือก พ.ศ./ค.ศ. โดย default = พ.ศ.)
2. [ ] ระบบ **แปลงและบันทึก** ลง DB ในรูปแบบที่แอปใช้อยู่ (ค.ศ. ภายในได้ ถ้า schema เป็น ค.ศ.) — ผู้เล่นเห็นเฉพาะ พ.ศ.
3. [ ] ช่วงปีที่เลือกได้ **สมเหตุสมผล** สำหรับผู้สูงอายุ (เช่น พ.ศ. 2400–2569 หรือตามกฎธุรกิจ)
4. [ ] การคำนวณอายุ / `user_data` ยังถูกต้องหลังแปลง พ.ศ. → ค.ศ.
5. [ ] ผู้เล่นที่ลงทะเบียนแล้ว **ไม่ถูกกระทบ** (เฉพาะ flow ใหม่)
6. [ ] ทดสอบบนมือถือจริง — owner ยืนยัน
