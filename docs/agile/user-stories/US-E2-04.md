**Status:** 🏗 To Do
**Epic:** [E2: Core Gamehub & Progression System](../01-product-backlog.md)
**Owner:** [TBD]

---

## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** เห็นจำนวนวันที่ฉันเล่นต่อเนื่องกัน
**เพื่อให้** ฉันรู้สึกภูมิใจและอยากทำตามเป้าหมาย 14 วันให้สำเร็จ

---

## ✅ Acceptance Criteria
1. [ ] แสดงจำนวน "วันที่เช็คอิน" จากทั้งหมด 14 วัน ในหน้า Gamehub
2. [ ] วันที่เช็คอินจะเพิ่มขึ้นก็ต่อเมื่อผู้เล่นเล่นจนถึง "ด่านเส้นชัย" (Finish Level) ของวันนั้นๆ
3. [ ] หากเล่นไม่ครบ 1 รอบ (ไม่ถึงด่านเส้นชัย) ระบบจะไม่นับว่าเป็นการเช็คอิน
4. [ ] ระบบแสดงผลวันที่เช็คอินด้วยไอคอนหรือปฏิทินแบบง่าย
