**Status:** ✅ Done
**Epic:** [E1: User Management & Authentication](../01-product-backlog.md)
**Owner:** [TBD]

---

## 📖 Description
**ในฐานะ** ผู้ป่วย/ผู้ใช้งาน
**ฉันต้องการ** เข้าสู่ระบบด้วยรหัส HN (Hospital Number) ที่ได้รับจากโรงพยาบาล
**เพื่อให้** ระบบสามารถระบุตัวตนและดึงข้อมูลการเล่นของฉันมาแสดงผลได้

---

## ✅ Acceptance Criteria
1. [x] มีช่องกรอกรหัส HN ในหน้าแรกของแอปพลิเคชัน
2. [x] ระบบตรวจสอบรหัส HN ในฐานข้อมูล (Supabase)
3. [x] หากรหัสถูกต้องและเคยลงทะเบียนแล้ว ให้ข้ามไปยังหน้า Gamehub
4. [x] หากรหัสถูกต้องแต่ยังไม่เคยลงทะเบียน ให้พาไปยังหน้าลงทะเบียนผู้ใช้ใหม่ (US-E1-02)
5. [x] หากรหัสไม่ถูกต้อง ให้แสดงข้อความแจ้งเตือนข้อผิดพลาด
