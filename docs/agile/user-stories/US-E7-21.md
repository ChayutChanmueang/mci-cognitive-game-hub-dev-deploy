# User Story: US-E7-21 - Progress-tree: เปลี่ยนสีตัวเลขความคืบหน้าอัตโนมัติเมื่อหลอดเกินครึ่ง (contrast)

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ตัวเลขความคืบหน้าบนหลอด progress (หน้า check-in / progress-tree) อ่านชัดเสมอ ไม่ว่าหลอดจะเติมไปถึงไหน
**เพื่อให้** มองเห็นค่าจำนวนวันได้ง่าย ไม่กลมกลืนกับสีหลอด

---

## 🔎 สถานะปัจจุบัน (2026-07-02)
หลอด progress ในหน้า progress-tree (`checkin-summary-screen.js`, ขั้น `calendar`) แสดงตัวเลข `NN/รวม` ไว้ **กึ่งกลางหลอดตายตัว** โดยสีคงที่:
- track: `#FCE9CC` (ครีมอ่อน) · fill: `#FDCB34` (เหลือง) · text `.tree-progress-bar__text`: `#5a5a5a` (เทา)

เมื่อหลอดเติม **เกินครึ่ง** ตัวเลขที่อยู่กึ่งกลางจะไปทับพื้นเหลือง (`#FDCB34`) ทำให้ตัวเลขสีเทา **contrast ต่ำ / กลมกลืน** อ่านยาก

---

## ✅ Acceptance Criteria
1. [ ] ตัวเลขความคืบหน้าเปลี่ยนสี **อัตโนมัติ** ตามค่าความคืบหน้า — เมื่อ fill **ถึง/เกินครึ่ง (≥ 50%)** ให้เปลี่ยนเป็นสีที่ contrast กับพื้นเหลือง (เช่น สีเข้ม/ขาว ตามที่ให้ค่า contrast ผ่าน)
2. [ ] เมื่อ fill **น้อยกว่าครึ่ง** ตัวเลขยังอ่านชัดบนพื้น track ครีม (คงสีเดิมหรือปรับให้ผ่าน contrast)
3. [ ] ตัวเลขอ่านชัดในทุกค่าตั้งแต่ 0% → 100% (ไม่มีจุดที่ตัวเลขกลืนกับพื้นหลัง)
4. [ ] สีที่เลือกผ่านเกณฑ์ contrast ที่เหมาะกับผู้ใช้สูงอายุ (แนะนำ WCAG AA, contrast ratio ≥ 4.5:1)
5. [ ] ทำงานอัตโนมัติเมื่อค่าจำนวนวันเปลี่ยน (ผูกกับ `fillPercent`/จำนวนวันที่ทำสำเร็จ) โดยไม่ต้องแก้มือทีละค่า

---

## 🛠 Technical Tasks
- [ ] ผูกสีตัวเลขกับค่าความคืบหน้าในการ render (`checkin-summary-screen.js` ขั้น `calendar`) — สลับ class/ตัวแปรสีเมื่อ `fillPercent >= 50`
- [ ] เพิ่ม CSS ให้ `.tree-progress-bar__text` รองรับสถานะ contrast (เช่น modifier `--over-half` หรือ custom property `--progress-text-color`) ใน `public/style.css`
- [ ] (ทางเลือกที่ทนต่อทุกค่า) พิจารณาเทคนิคตัวเลขสองชั้น: ตัวเลขบน track + ตัวเลขสำเนาที่ clip เฉพาะส่วนที่อยู่บน fill (ใช้ `clip-path`/overlay กว้างเท่า `fillPercent`) เพื่อให้ contrast ถูกต้องแม้ตัวเลขคร่อมขอบ fill
- [ ] ตรวจ contrast ทั้งช่วง 0–100% (โดยเฉพาะจุดคาบเกี่ยว ~50%)
