## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ตัวเลขความคืบหน้าบนหลอด progress (หน้า check-in / progress-tree) อ่านชัดเสมอ ไม่ว่าหลอดจะเติมไปถึงไหน
**เพื่อให้** มองเห็นค่าจำนวนวันได้ง่าย ไม่กลมกลืนกับสีหลอด

---

## 🔎 สถานะปัจจุบัน (2026-07-02)
หลอด progress ในหน้า progress-tree (`checkin-summary-screen.js`, ขั้น `calendar`) แสดงตัวเลข `NN/รวม` ไว้ **กึ่งกลางหลอดตายตัว** โดยสีคงที่:
- track: `#FCE9CC` (ครีมอ่อน) · fill: `#FDCB34` (เหลือง) · text `.tree-progress-bar__text`: `#5a5a5a` (เทา)

เมื่อหลอดเติม **เกินครึ่ง** ตัวเลขที่อยู่กึ่งกลางจะไปทับพื้นเหลือง (`#FDCB34`) ทำให้ตัวเลขสีเทา **contrast ต่ำ / กลมกลืน** อ่านยาก

## ✅ Acceptance Criteria
1. [x] ตัวเลขความคืบหน้าปรับสี **อัตโนมัติ** ตามค่าความคืบหน้า — ส่วนที่อยู่บนพื้นเหลือง (fill) ใช้สีเข้ม contrast ผ่าน (ทำได้ทุกค่า ไม่ใช่แค่ตัดที่ 50% — ดูหมายเหตุวิธีทำ)
2. [x] เมื่อ fill **น้อยกว่าครึ่ง** ตัวเลขยังอ่านชัดบนพื้น track ครีม (คงสีเดิม `#5a5a5a`)
3. [x] ตัวเลขอ่านชัดในทุกค่าตั้งแต่ 0% → 100% (ไม่มีจุดที่ตัวเลขกลืนกับพื้นหลัง แม้ตอนคร่อมขอบ fill)
4. [x] สีที่เลือกผ่านเกณฑ์ contrast (WCAG AA ≥ 4.5:1) — เลือก **สีเข้ม `#4a3400` (≈7:1 บนเหลือง)**; **ไม่ใช้สีขาว** เพราะขาวบนเหลือง `#FDCB34` ตก AA (≈1.5:1)
5. [x] ทำงานอัตโนมัติเมื่อค่าจำนวนวันเปลี่ยน (ผูกกับ `--tree-fill` = `fillPercent`) ไม่ต้องแก้มือทีละค่า
6. [x] ยืนยันการแสดงผลโดยเจ้าของงาน (2026-07-02)

## 🎨 วิธีที่ใช้จริง — two-layer clipped text (ทนทุกค่า ดีกว่าสลับที่ 50%)
แทนการ "สลับสีทั้งก้อนเมื่อ ≥50%" (ซึ่งช่วงที่ตัวเลขคร่อมขอบ fill จะยังกลืนครึ่งหนึ่ง) ใช้ตัวเลข **สองชั้นซ้อนทับกัน**:
- **ชั้นฐาน** `.tree-progress-bar__text` สี `#5a5a5a` — อ่านชัดบน track ครีม
- **ชั้นบน** `.tree-progress-bar__text--filled` สีเข้ม `#4a3400` — clip ด้วย `clip-path: inset(0 calc(100% - var(--tree-fill)) 0 0)` ให้โผล่เฉพาะส่วนที่อยู่บน fill เหลือง
- `--tree-fill: <fillPercent>%` ตั้ง inline บน `.tree-progress-bar`; ใช้ทั้งความกว้าง fill และ clip ของชั้นบน → sync กันเสมอ
