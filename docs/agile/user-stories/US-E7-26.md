## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้หน้า Leaderboard จัด layout เพิ่มเติมให้เป็นระเบียบและอ่านง่ายขึ้น (ต่อยอดจากงาน art ที่พอร์ตมาแล้ว)
**เพื่อให้** ดูอันดับ/คะแนน/ตำแหน่งของตัวเองได้ชัดเจนบนทุกขนาดหน้าจอ

## ✅ Acceptance Criteria
1. [ ] ปรับ layout หน้า Leaderboard เพิ่มเติมจากที่พอร์ต art มาแล้วใน [US-E7-01](US-E7-01.md) (ระยะห่าง/การจัดตำแหน่งแถวอันดับ, top-bar, bottom-status)
2. [ ] แถบ "อันดับของคุณ" (Bottom-Status) และวงแหวนเน้นแถวผู้เล่นปัจจุบันยังแสดงถูกต้องหลังปรับ layout
3. [ ] รายการยังเลื่อน (scroll/infinite scroll) ได้ถูกต้อง ไม่มี element ทับซ้อน/ล้น
4. [ ] สเกลด้วย `--gh-scale` และแสดงผลคมชัด/จัดวางถูกต้องบนมือถือจริง
