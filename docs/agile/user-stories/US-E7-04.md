# User Story: US-E7-04 - Game art assets / ระบบภาพสำหรับ Popup (dialog)

**Status:** 🔍 Review / Testing (Sprint 7) — Figma popup art applied v0.20.0 (check-in success, resting, day/program completion) + `popup-dialog.js` confirm/prompt (Frame_Panel + Button_Close_Stroke/Button_OK_Stroke, list mode = frame-only); รอ QA มือถือ
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** [Developer/AI]

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ป๊อปอัป (popup/dialog) ทั้งหมดมีงานศิลป์ตรงธีมเกมและเข้าชุดกัน
**เพื่อให้** ข้อความแจ้งเตือน/ยืนยัน/ผลลัพธ์ ดูเป็นมิตรและเข้าใจง่าย ไม่ดูเป็นกล่องระบบเปล่า ๆ

---

## ✅ Acceptance Criteria
1. [x] Popup กลุ่ม check-in success / resting / day-completion / program-completion ใช้ระบบภาพเดียวกัน (Frame_Form_Panel + Start-Game-Button)
2. [x] มีโครงร่าง popup ที่ใช้ซ้ำได้ — `renderFramePopupMarkup` (`src/ui/components/frame-popup.js`) + CSS `.gh-popup`
3. [x] ปุ่มเดียวจาก `Start-Game-Button` (เขียว, ใหญ่ชัดเจน) ตามที่เจ้าของงานกำหนด
4. [ ] art asset ไม่ทำให้ popup ล้นจอบนมือถือแนวตั้ง *(รอ QA)*
5. [x] `popup-dialog.js` (confirm/prompt) ใช้ Figma component: `Frame_Panel` เป็นกรอบ (หัวเรื่อง + ข้อความอยู่กลาง) และปุ่ม `Button_Close_Stroke` (ยกเลิก/แดง) + `Button_OK_Stroke` (ยืนยัน/เขียว) วางใต้กรอบ ตาม layout ที่เจ้าของงานกำหนด; แบบ acknowledge (ไม่มี cancelText) แสดงปุ่มเขียวเดี่ยว
6. [x] โหมด multi-choice (`actions: [...]`, เช่น เปิดเกมเก็บ/ไม่เก็บประวัติ) ซึ่งเป็นหน้าแบบ list — **เปลี่ยนเฉพาะกรอบ** เป็น `Frame_Panel` (คลาส `.gh-dialog--framed`) คงปุ่ม Material list เดิมไว้ตามเดิม
