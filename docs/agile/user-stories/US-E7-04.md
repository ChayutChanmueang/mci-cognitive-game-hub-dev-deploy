# User Story: US-E7-04 - Game art assets / ระบบภาพสำหรับ Popup (dialog)

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** [Developer/AI]

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ป๊อปอัป (popup/dialog) ทั้งหมดมีงานศิลป์ตรงธีมเกมและเข้าชุดกัน
**เพื่อให้** ข้อความแจ้งเตือน/ยืนยัน/ผลลัพธ์ ดูเป็นมิตรและเข้าใจง่าย ไม่ดูเป็นกล่องระบบเปล่า ๆ

---

## ✅ Acceptance Criteria
1. [ ] Popup หลัก (resting point, day/program completion, game-exit, check-in, confirmation ฯลฯ) ใช้ระบบภาพ/asset ที่เข้าชุดกัน
2. [ ] มีโครงร่างภาพ popup ที่นำกลับมาใช้ซ้ำได้ (reusable) ผ่าน shared dialog component
3. [ ] ปุ่มยืนยัน/ปิด ยังมีขนาดใหญ่และชัดเจนตามแนวทาง Accessibility
4. [ ] art asset ไม่ทำให้ popup ล้นจอหรือเลื่อนผิดเพี้ยนบนมือถือแนวตั้ง

---

## 🛠 Technical Tasks
- [ ] นิยามระบบภาพ popup ที่ใช้ร่วมกัน (กรอบ, หัวเรื่อง, ภาพประกอบ) บน `popup-dialog.js` / `app-popup` skeleton
- [ ] ส่งออก/รวบรวม art asset ของ popup และจัดเก็บใน `public/assets/`
- [ ] ปรับ popup ที่มีอยู่ (`resting-point-popup.js`, `day-completion-popup.js`, `game-exit-popup.js` ฯลฯ) ให้ใช้ระบบภาพใหม่
- [ ] พิจารณาทำกรอบ/ลวดลายด้วย CSS แทนรูปภาพในจุดที่ทำได้
