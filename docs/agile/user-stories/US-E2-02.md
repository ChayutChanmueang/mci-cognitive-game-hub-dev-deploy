# User Story: US-E2-02 - ระบบแผนที่ด่าน (Level Progression)

**Owner:** [TBD]

---

## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** เห็นแผนที่การเดินด่านตั้งแต่วันที่ 1 ถึง 14
**เพื่อให้** ฉันรู้ว่าปัจจุบันเล่นถึงไหนแล้วและเหลืออีกกี่วันที่ต้องฝึก

---

## ✅ Acceptance Criteria
1. [ ] แสดงรายการด่านแบ่งตาม "วันที่ 1-14"
2. [ ] ในแต่ละวันจะมีด่านย่อยทั้งหมด 12 ด่าน (10 เกม, 1 จุดพัก, 1 เส้นชัย)
3. [ ] ระบบล็อคด่านของวันถัดไปไว้จนกว่าจะถึงวันที่กำหนด
4. [ ] ด่านที่เล่นผ่านแล้วจะมีสัญลักษณ์ระบุสถานะ (เช่น เครื่องหมายถูก)
5. [ ] แสดง Avatar ตัวแทนผู้เล่นบนด่านที่กำลังเล่นอยู่ปัจจุบัน

---

## 🛠 Technical Tasks
- [ ] ออกแบบและพัฒนา UI แผนที่ด่าน (คล้าย Candy Crush / Duolingo)
- [ ] พัฒนาระบบตรวจสอบเงื่อนไขการปลดล็อคด่าน (ล็อคตามวันจริง)
- [ ] สร้างระบบจัดการสถานะด่าน (Played/Locked/Current)
