# User Story: US-E2-02 - ระบบแผนที่ด่าน (Level Progression)

**Status:** ✅ Done
**Epic:** [E2: Core Gamehub & Progression System](../01-product-backlog.md)
**Owner:** [Team Game / Team Web]

---

## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** เห็นแผนที่การเดินด่านตั้งแต่วันที่ 1 ถึง 14
**เพื่อให้** ฉันรู้ว่าปัจจุบันเล่นถึงไหนแล้วและเหลืออีกกี่วันที่ต้องฝึก

---

## ✅ Acceptance Criteria
1. [x] แสดงรายการด่านแบ่งตามโปรแกรมฝึกฝน "วันที่ 1-14"
2. [x] แต่ละวันจะมีภารกิจย่อยในรูปแบบรายการการเข้าเล่นมินิเกมต่างๆ (เช่น 12 ด่าน ได้แก่ 10 เกม, 1 จุดพักยืดเหยียดร่างกาย, 1 ปุ่มเช็คชื่อ/เส้นชัย)
3. [x] ระบบล็อคด่านของวันถัดไปไว้ตามเงื่อนไขของวันนับจากวันที่เริ่มโปรแกรมจริง
4. [x] ด่านที่เล่นผ่านแล้วมีเครื่องหมายแสดงสถานะความสำเร็จสีเขียวและมีคะแนนระบุไว้ชัดเจน
5. [x] หน้าจอเลื่อนอัตโนมัติ (auto-scroll) ไปยังวันปัจจุบันเพื่อให้สะดวกต่อผู้ป่วยสูงอายุ

---

## 🛠 Technical Tasks
- [x] ออกแบบและพัฒนา UI แผนที่ด่านในลักษณะรายการการเล่นที่ชัดเจน ออกแบบมาเพื่อกลุ่มผู้สูงอายุ (MCI) ปุ่มขนาดใหญ่ สีสันแยกตามหมวดหมู่ทักษะ
- [x] พัฒนาระบบตรวจสอบเงื่อนไขการปลดล็อคด่าน อิงตามวันจริงเทียบกับ `started_program`
- [x] สร้างระบบจัดการสถานะของด่านแต่ละวัน (Locked, Active, Completed) ใน Client-side

---

## 📝 Implementation Details
- ระบบทำแผนที่ด่านการเล่นหลักอยู่ใน `src/ui/game-hub-screen.js` โดยเชื่อมข้อมูลประวัติการเล่นจริงจาก Supabase
- ตัวแปรวันปัจจุบัน (`currentDayIndex`) จะคำนวณผ่าน API และเปรียบเทียบระยะเวลาจริง เพื่อปลดล็อคด่านวันต่อวัน ป้องกันการข้ามไปเล่นวันในอนาคตก่อนกำหนด
- เพิ่มฟังก์ชัน `scrollToActiveDay` เพื่อจัดตําแหน่งสกรอลล์หน้าจอไปหาวันปัจจุบันโดยอัตโนมัติเมื่อเข้าสู่หน้า Hub
