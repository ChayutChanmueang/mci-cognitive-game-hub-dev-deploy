# User Story: US-E7-13 - เอฟเฟคฉลองหน้า "เก่งมาก!!!" (ระเบิดริปปิ้น + คนแก่ดีใจ)

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่เล่นครบภารกิจประจำวัน
**ฉันต้องการ** ให้หน้าเช็คอิน "เก่งมาก!!!" มีเอฟเฟคฉลองที่สนุกและน่าตื่นเต้น
**เพื่อให้** รู้สึกภูมิใจ ได้รับรางวัลทางสายตา และอยากกลับมาเล่นต่อในวันถัดไป

---

## ✅ Acceptance Criteria
1. [ ] หน้า check-in popup "เก่งมาก!!!" มี **เอฟเฟคระเบิดริปปิ้น (confetti/ribbon burst)** เมื่อแสดงผล
2. [ ] ตัวละคร **คนแก่มีอนิเมชันขึ้น-ลง (bounce)** คล้ายอนิเมชันคนดีใจ/ฉลอง
3. [ ] เอฟเฟคและอนิเมชันเล่นลื่นไหลบนมือถือจริง โดยไม่ทำให้เฟรมเรตตกอย่างมีนัยสำคัญ
4. [ ] เอฟเฟคสอดคล้องกับสไตล์ภาพ **กึ่งสมจริง** ของแอป และไม่บดบังข้อความ/ปุ่มสำคัญ

---

## 🛠 Technical Tasks
- [ ] เพิ่มเอฟเฟค confetti/ribbon burst ในหน้าเช็คอินสำเร็จ (CSS animation / particle / sprite)
- [ ] เพิ่มอนิเมชัน bounce ขึ้น-ลงให้ตัวละครคนแก่ (ใช้ภาพตัวละครตามเพศที่มีอยู่)
- [ ] จัดจังหวะ (timing) เอฟเฟคให้สัมพันธ์กับการแสดงข้อความ "เก่งมาก!!!"
- [ ] ทดสอบประสิทธิภาพและการแสดงผลบนมือถือจริง
