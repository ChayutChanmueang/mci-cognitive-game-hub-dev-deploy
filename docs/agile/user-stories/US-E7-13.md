## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่เล่นครบภารกิจประจำวัน
**ฉันต้องการ** ให้หน้าเช็คอิน "เก่งมาก!!!" มีเอฟเฟคฉลองที่สนุกและน่าตื่นเต้น
**เพื่อให้** รู้สึกภูมิใจ ได้รับรางวัลทางสายตา และอยากกลับมาเล่นต่อในวันถัดไป

---

## ✅ Acceptance Criteria
1. [x] หน้า check-in popup "เก่งมาก!!!" มี **เอฟเฟคระเบิดริปปิ้น (confetti/ribbon burst)** เมื่อแสดงผล
2. [x] ตัวละคร **คนแก่มีอนิเมชันขึ้น-ลง (bounce)** คล้ายอนิเมชันคนดีใจ/ฉลอง
3. [ ] เอฟเฟคและอนิเมชันเล่นลื่นไหลบนมือถือจริง โดยไม่ทำให้เฟรมเรตตกอย่างมีนัยสำคัญ *(รอ QA บนมือถือจริง)*
4. [x] เอฟเฟคสอดคล้องกับสไตล์ภาพของแอป และไม่บดบังข้อความ/ปุ่มสำคัญ (`pointer-events: none`, ข้อความเดิมของ popup ยังอยู่)

## 🛠 Technical Tasks
- [x] สร้างคอมโพเนนต์ใหม่ `src/ui/components/effects/celebration-effect.js` = **confetti burst ล้วน (generic/reusable)** แยกจากตัว Phaser เดิม ไม่กระทบ 6 minigame
- [x] confetti burst: `position: fixed`, z-index เหนือ popup, `pointer-events: none`, auto-cleanup + `cancel()` handle
- [x] bounce ตัวละครคนแก่ (2 ครั้งช้าๆ 0.5s ขึ้น/0.5s ลง) อยู่ใน `checkin-summary-screen.js` เป็น helper `bounceCheckInCharacter()` เฉพาะหน้านี้ (ไม่ยัดเข้า component กลาง)
- [x] ต่อเข้า `checkin-summary-screen.js` ขั้นตอน "เก่งมาก !!!" + ยกเลิกทั้ง confetti และ bounce ใน `cleanup()` ถ้าปิด popup ก่อน
- [x] รองรับ `prefers-reduced-motion` (confetti ลดจำนวน particle, bounce งด)
- [ ] ทดสอบประสิทธิภาพ/การแสดงผลบนมือถือจริง
