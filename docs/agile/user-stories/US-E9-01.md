## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้เกมภัยพิบัติระดับ Symmetry (Symmetry Decor) ง่ายขึ้น ชัดขึ้น และจบได้เมื่อหมดเวลา
**เพื่อให้** เข้าใจกติกาได้ ไม่วางผิดฝั่ง และไม่ติดค้างในเกมเมื่อเล่นไม่ผ่าน

---

## 🐛 Problem (ก่อนแก้ — v1.0.0)
- ผู้สูงอายุ **วางรูปสัตว์ในช่องฝั่งโจทย์** บ่อยมาก
- โหมดสะท้อนเฉียงและหมุน 180° **ยากเกินไป** สำหรับกลุ่มเป้าหมาย
- จำนวนช่องต่อเลเวล **มากเกินไป** ทำให้สับสน
- เส้นแบ่งระหว่างฝั่งโจทย์/ฝั่งตอบ **มองไม่ชัด**
- เมื่อ **หมดเวลา** ผู้เล่นที่ยังทำไม่เสร็จ **จบเกมไม่ได้**

---

## ✅ Acceptance Criteria
1. [x] ผู้เล่น **ไม่สามารถวาง** รูปสัตว์/ไอเทมลงในช่อง **ฝั่งโจทย์** (prompt side) ได้ — ช่องฝั่งโจทย์รับเฉพาะไอเทมที่ระบบวางไว้แล้ว
2. [x] **เอารูปแบบการสะท้อน** สะท้อนเฉียง (diagonal) และสะท้อนหมุน 180° **ออก** — เหลือเฉพาะ **สะท้อนซ้าย-ขวา** (horizontal mirror)
3. [x] **ลดจำนวนช่อง** ต่อระดับความยาก:
   - ง่าย = **2×2**
   - ปานกลาง = **4×4**
   - ยาก = **6×6**
4. [x] **เส้นแบ่ง** ระหว่างฝั่งโจทย์และฝั่งตอบ **มองเห็นชัดขึ้น** (เช่น หนาขึ้น / เข้มขึ้น / contrast สูงขึ้น) — ทดสอบกับผู้สูงอายุบนมือถือจริง
5. [x] เมื่อ **เวลาหมด** เกม **ตัดจบได้ทันที** (แสดงผลลัพธ์/หน้าจบเกม) โดยไม่บังคับให้ผู้เล่นทำข้อให้เสร็จ
6. [x] การเปลี่ยนแปลง **ไม่กระทบ** ข้อมูลผู้เล่นที่เล่นโปรแกรม 14 วันอยู่แล้ว (ไม่เปลี่ยน schema ที่มีผลย้อนหลัง)
