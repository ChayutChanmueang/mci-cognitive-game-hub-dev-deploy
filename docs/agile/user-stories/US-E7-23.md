# User Story: US-E7-23 - ขยาย collision กล่องวางคำตอบเกม Context Clues

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** ก้องไผ่
**Source:** Owner Task Block — ก้องไผ่ (2026-07-06), [Sprint 07](../sprint-backlogs/sprint-07.md)

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้กล่องตัวเลือกคำตอบในเกม Context Clues มีพื้นที่กด (hit area / collision) กว้างขึ้น
**เพื่อให้** กดเลือกคำตอบได้แม่นยำ ไม่พลาด แม้มือสั่นหรือกดไม่ตรงกลางกล่อง

---

## ✅ Acceptance Criteria
1. [ ] พื้นที่กด (hit area) ของ **กล่องวางคำตอบ/ตัวเลือก** ในเกม Context Clues ครอบคลุมกล่องทั้งใบ (ไม่ใช่แค่บางส่วน) และกดติดทุกจุดภายในกล่อง
2. [ ] ขยาย collision ให้ **ใหญ่กว่ากรอบภาพเล็กน้อย** (เผื่อระยะกดพลาด) โดยไม่ทำให้กล่องที่อยู่ติดกันซ้อนทับพื้นที่กดของกันและกัน
3. [ ] การขยาย collision ไม่กระทบตำแหน่งการแสดงผล/ขนาดภาพของกล่อง (เฉพาะพื้นที่รับ input เท่านั้นที่เปลี่ยน)
4. [ ] ตรวจสอบบนมือถือจริงว่ากดเลือกคำตอบได้ทุกกล่องและทุกระดับความยาก

---

## 🛠 Technical Tasks
- [ ] ปรับ hitbox ใน `src/game/context-clues/components/scripts/clickable.js` — ปัจจุบัน `_hitbox = new Phaser.Geom.Rectangle(-(this.size.x/4), -(this.size.y/4), this.size.x, this.size.y)` ซึ่ง origin/ขนาดยังไม่ครอบกล่องเต็ม ให้แก้ให้ตรงกับขนาดกล่องจริง (และเผื่อ padding)
- [ ] ตรวจ `box.setSize(choiceWidth, choiceHeight)` ใน `src/game/context-clues/entity/script/quiz.js` ให้ค่าที่ส่งเข้า `Clickable`/`setInteractive` สอดคล้องกับขนาดกล่องที่เรนเดอร์
- [ ] ทดสอบว่ากล่องที่อยู่ติดกันไม่กิน input ของกันและกันหลังขยาย collision
- [ ] ทดสอบ tap บนมือถือจริงทุกระดับความยาก
