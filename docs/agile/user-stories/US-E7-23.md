# User Story: US-E7-23 - ขยาย collision กล่องวางคำตอบเกม Context Clues

**Status:** ✅ Done (Sprint 7) — เสร็จ v0.28.0; เจ้าของงานแก้ไข/ยืนยันเอง 2026-07-06 ("แก้ไขเรียบร้อยแล้ว")
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** ก้องไผ่
**Source:** Owner Task Block — ก้องไผ่ (2026-07-06), [Sprint 07](../sprint-backlogs/sprint-07.md)

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้กล่องตัวเลือกคำตอบในเกม Context Clues มีพื้นที่กด (hit area / collision) กว้างขึ้น
**เพื่อให้** กดเลือกคำตอบได้แม่นยำ ไม่พลาด แม้มือสั่นหรือกดไม่ตรงกลางกล่อง

---

## ✅ Acceptance Criteria
1. [x] พื้นที่กด (hit area) ของ **กล่องวางคำตอบ/ตัวเลือก** ในเกม Context Clues ครอบคลุมกล่องทั้งใบ และกดติดทุกจุดภายในกล่อง
2. [x] ขยาย collision ให้ **ใหญ่กว่ากรอบภาพได้** (ปรับแยกผ่าน `answerBox.hitArea`/`hitOffset`) โดยไม่ทำให้กล่องที่อยู่ติดกันซ้อนทับพื้นที่กดของกันและกัน
3. [x] การขยาย collision ไม่กระทบตำแหน่งการแสดงผล/ขนาดภาพของกล่อง (แยก visible size ออกจาก hit area)
4. [x] ตรวจสอบบนมือถือจริงว่ากดเลือกคำตอบได้ทุกกล่องและทุกระดับความยาก — ยืนยันโดยเจ้าของงาน 2026-07-06
5. [x] วางคำได้แบบ **overlap** (ปล่อยแล้วกล่องคำทับ drop zone ก็ติด ไม่ต้องเล็ง pointer ให้ตรงเป๊ะ)

---

## 🛠 Technical Tasks
- [x] เพิ่ม collision/hit area ปรับแยกได้ให้กล่องคำตอบ + ช่อง "วางคำ" — `answerBox.size`/`hitArea`/`hitOffset` ใน `src/game/context-clues/entity/script/quiz.js` + ค่า config ใน `constants.js` และช่อง drop ใน `auto-insert-layout.js` (fallback เป็นขนาดเดิมเมื่อไม่ตั้งค่า)
- [x] เพิ่ม **overlap-based drop** ใน `src/core/drag-drop-manager.js` — `overlapDrop` (default เปิด): เมื่อปล่อยนอก drop zone แต่กล่องคำ **ทับ** zone ที่รับได้ ก็ถือว่า drop สำเร็จ (เลือก zone ที่ทับมากที่สุดด้วย `findOverlappingDropZone`), refactor drop เป็น `performDrop()` ร่วมกัน
- [x] ทดสอบว่ากล่องที่อยู่ติดกันไม่กิน input ของกันและกันหลังขยาย collision
- [x] ทดสอบ tap/วางคำบนมือถือจริงทุกระดับความยาก — ยืนยันโดยเจ้าของงาน 2026-07-06

> หมายเหตุ: บันทึกเป็นเวอร์ชัน **v0.28.0**; แนวทางที่ใช้จริงคือแยก **visible size ↔ hit area** + **overlap drop** (ไม่ได้แก้ที่ `clickable.js` `_hitbox` ตามที่ร่างไว้ตอนแรก)
