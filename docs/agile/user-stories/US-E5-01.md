# User Story: US-E5-01 - ระบบ Admin Login เพื่อดูข้อมูลผู้ป่วย

**Status:** 🏗 In-Progress (Planned for Sprint 6)  
**Epic:** [E5: Admin & Data Management](../01-product-backlog.md)  
**Owner:** [TBD]  

---

## 📖 Description
**ในฐานะ** ผู้ดูแลระบบ, แพทย์ หรือนักวิจัยทางคลินิก  
**ฉันต้องการ** ล็อกอินเข้าสู่หน้าจัดการระบบ (Admin Dashboard) ด้วยบัญชีผู้ดูแลที่มีความปลอดภัยสูง  
**เพื่อให้** ฉันสามารถเข้าถึงประวัติข้อมูลส่วนตัว ความคืบหน้าการเล่นรายวัน และผลการวิเคราะห์ระดับสติปัญญาของผู้ป่วยแต่ละรายได้ในจุดเดียว  

---

## ✅ Acceptance Criteria
1. [ ] **หน้าจอล็อกอินสำหรับผู้ดูแล (Admin Login Screen)**: มีหน้าเข้าสู่ระบบสำหรับแพทย์/ผู้ดูแลแยกออกจากหน้าลงทะเบียนทั่วไป โดยต้องใช้รหัสผ่านความปลอดภัยขั้นต่ำ 8 ตัวอักษร  
2. [ ] **หน้าต่างแสดงรายชื่อผู้ป่วย (Patient List View)**: แสดงรายการผู้ป่วยที่ลงทะเบียนทั้งหมดในระบบ จัดเรียงตามวันที่ลงทะเบียนล่าสุด หรือค้นหาได้อย่างสะดวกรวดเร็วตามรหัส HN  
3. [ ] **แดชบอร์ดรายบุคคล (Individual Patient Dashboard)**: เมื่อเลือกผู้ป่วย ระบบจะแสดงข้อมูลสรุปได้แก่:
   - ข้อมูลผู้ป่วย (HN, ชื่อ, วันเกิด, อายุ, เพศ, การศึกษา, ช่วงวันที่เข้าร่วมโปรแกรม 14 วัน)
   - ความก้าวหน้าการเล่น (Daily Streak, Daily Goals)
   - ประวัติผลการเล่นเกมย่อย และสถิติประสิทธิภาพเชิงลึก (Accuracy, Response Time, Fatigue Effect)
4. [ ] **ความปลอดภัย (Security)**: กั้นไม่ให้บัญชีผู้ใช้งานทั่วไป (Patient) หรือผู้ที่ไม่ได้รับอนุญาตเข้าถึงหน้าผู้ดูแลโดยเด็ดขาด

## 🛠 Technical Tasks
- [ ] พัฒนาหน้าจอ `AdminLoginPanel` และหน้าจอ `AdminDashboardPanel` โดยใช้ React/CSS ของระบบ
- [ ] ติดตั้งฟังก์ชันยืนยันตัวตน Admin ร่วมกับระบบ Supabase Auth (หรือตรวจสอบบทบาท admin จากตารางสิทธิ์)
- [ ] พัฒนาฟังก์ชันค้นหา (Search) และกรอง (Filter) ผู้ป่วยตามรหัส HN
- [ ] พัฒนาฟังก์ชันสรุปข้อมูลกิจกรรมและแสดงผลเป็นกราฟิกง่ายๆ (เช่น ข้อมูลความล้า, ค่าความแม่นยำ) บน Dashboard
- [ ] ทดสอบความปลอดภัยของเส้นทาง (Route Guard) เพื่อปกป้องข้อมูลส่วนบุคคลของผู้ป่วย (PDPA Standard)
