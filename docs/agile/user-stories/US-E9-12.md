## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่กดออกจากมินิเกม
**ฉันต้องการ** ให้ popup ยืนยัน "ออกจากเกม" มี layout และ art assets **เหมือน popup แจ้งเตือนอื่น ๆ**
**เพื่อให้** UI ดูเป็นระบบเดียวกัน ไม่สับสนระหว่าง popup ที่ layout ต่างกัน

---

## 🐛 Problem (ก่อนแก้ — v1.1.3)
- [`game-exit-popup.js`](../../../src/ui/game-exit-popup.js) ใช้ `Frame_Panel` + ปุ่ม stroke แล้ว แต่ **layout ไม่ตรง** [`popup-dialog.js`](../../../src/ui/popup-dialog.js) โหมด confirm:
  - **game-exit (เดิม):** ปุ่มอยู่ **ใต้** panel ใน `.gh-dialog__actions` แยกต่างหาก
  - **popup-dialog:** ปุ่มทั้งคู่อยู่ **ภายใน** `renderFramePanel` body (Frame 1257 layout)
- ผลลัพธ์: spacing, ขนาด panel, ตำแหน่งปุ่ม ไม่ match popup อื่น
