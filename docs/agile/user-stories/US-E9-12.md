## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่กดออกจากมินิเกม
**ฉันต้องการ** ให้ popup ยืนยัน "ออกจากเกม" มี layout และ art assets **เหมือน popup แจ้งเตือนอื่น ๆ**
**เพื่อให้** UI ดูเป็นระบบเดียวกัน ไม่สับสนระหว่าง popup ที่ layout ต่างกัน

---

## 🐛 Problem (ปัจจุบัน)
- [`game-exit-popup.js`](../../../src/ui/game-exit-popup.js) ใช้ `Frame_Panel` + ปุ่ม stroke แล้ว แต่ **layout ไม่ตรง** [`popup-dialog.js`](../../../src/ui/popup-dialog.js) โหมด confirm:
  - **game-exit:** ปุ่ม `Button_Close_Stroke` / `Button_OK_Stroke` อยู่ **ใต้** panel ใน `.gh-dialog__actions` แยกต่างหาก
  - **popup-dialog:** ปุ่มทั้งคู่อยู่ **ภายใน** `renderFramePanel` body ใน `.gh-dialog__actions` (Frame 1257 layout)
- ผลลัพธ์: spacing, ขนาด panel, ตำแหน่งปุ่ม ไม่ match popup อื่น (เช่น confirm ใน Hub / admin)
- [US-E7-04](US-E7-04.md) บันทึกว่า ship แล้ว — งานนี้เป็น **alignment fix** ให้ตรง implementation ล่าสุดของ `popup-dialog.js`

---

## ✅ Acceptance Criteria
1. [ ] Popup ออกจากเกมใช้ **markup/CSS เดียวกับ** `popup-dialog.js` confirm mode (title + message + ปุ่ม **inside** `Frame_Panel`)
2. [ ] ปุ่มสีตาม [US-E7-15](US-E7-15.md): **แดง = ออก** (destructive), **เขียว = เล่นต่อ** (safe) — contract Promise `true` = exit, `false` = keep playing **ไม่เปลี่ยน**
3. [ ] Transition / backdrop / Escape / focus ยังทำงานเหมือนเดิม ([US-E7-20](US-E7-20.md))
4. [ ] แสดงผลถูกต้องบนมือถือแนวตั้ง — ไม่ล้นจอ
5. [ ] Owner ยืนยันบน device จริง (หรือทดสอบจาก minigame HUD ปุ่มออก)

---

## 🛠 Technical Tasks
- [ ] ปรับ markup ใน `src/ui/game-exit-popup.js` ให้ mirror `popup-dialog.js` confirm branch (ปุ่มใน panel) — พิจารณา extract shared helper ถ้าลด duplication ได้โดยไม่ over-engineer
- [ ] ตรวจ/ปรับ CSS `.gh-dialog*` ใน `public/components.css` ถ้ามี rule ที่ทำให้ exit popup ต่างจาก dialog
- [ ] ยืนยัน call sites ใน `src/main.js` (พารามิเตอร์สีธีมต่อเกมที่ deprecated แล้วยังส่งมาหรือไม่)
- [ ] ทดสอบจากมินิเกมอย่างน้อย 2 เกม (Phaser + DOM) — ปุ่มออก/เล่นต่อ resolve ถูกต้อง
