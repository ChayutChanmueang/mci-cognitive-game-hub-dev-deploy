## 📖 Description
**ในฐานะ** ผู้ป่วยหรือแพทย์ผู้ดูแล  
**ฉันต้องการ** สามารถสั่งลงชื่อออกจากระบบเพื่อเปลี่ยนบัญชี หรือลบข้อมูลบัญชีและประวัติการเล่นของผู้ป่วยออกถาวรได้  
**เพื่อให้** สามารถจัดการการเปลี่ยนเครื่องเล่น และปกป้องความเป็นส่วนตัวของข้อมูลผู้ป่วย (สิทธิ์การถูกลืมภายยินยอมภายใต้กฎหมาย PDPA) เมื่อจบโปรแกรมฝึกฝนเรียบร้อยแล้ว
