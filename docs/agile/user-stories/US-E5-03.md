# User Story: US-E5-03 - ระบบลบบัญชีและลงชื่อออก

**Status:** 🏗 In-Progress (Sprint 6)  
**Epic:** [E5: Admin & Data Management](../01-product-backlog.md)  
**Owner:** [Developer/AI]  

---

## 📖 Description
**ในฐานะ** ผู้ป่วยหรือแพทย์ผู้ดูแล  
**ฉันต้องการ** สามารถสั่งลงชื่อออกจากระบบเพื่อเปลี่ยนบัญชี หรือลบข้อมูลบัญชีและประวัติการเล่นของผู้ป่วยออกถาวรได้  
**เพื่อให้** สามารถจัดการการเปลี่ยนเครื่องเล่น และปกป้องความเป็นส่วนตัวของข้อมูลผู้ป่วย (สิทธิ์การถูกลืมภายยินยอมภายใต้กฎหมาย PDPA) เมื่อจบโปรแกรมฝึกฝนเรียบร้อยแล้ว  

---

## ✅ Acceptance Criteria
1. [x] **ปุ่มลงชื่อออก (Logout Button)**: มีปุ่ม "ลงชื่อออก" ในหน้าเมนูการตั้งค่า เมื่อกดแล้วจะทำการล้าง Session/HN ท้องถิ่นออก และนำทางผู้ใช้กลับไปยังหน้าแรก (Login Screen)  
2. [ ] **ปุ่มลบบัญชีผู้ป่วย (Delete Account Button)**: มีฟังก์ชันลบบัญชีในหน้า Dashboard ของ Admin (การเข้าถึงจำกัดเฉพาะผู้ดูแลเท่านั้น)  
3. [ ] **กล่องข้อความยืนยันความต้องการ (Confirmation Modal)**: เมื่อกดลบบัญชี ระบบต้องแสดงหน้าต่างป๊อปอัปแจ้งเตือนให้กดยืนยันอีกครั้งเพื่อป้องกันปัญหาการเผลอกดลบโดยอุบัติเหตุ  
4. [x] **การลบข้อมูลแบบต่อเนื่อง (Cascade Deletion)**: เมื่อ Admin กดยืนยันการลบบัญชี ระบบต้องทำการลบข้อมูลผู้ใช้นี้ออกจากฐานข้อมูล Supabase และลบข้อมูลล็อกการเล่นเกม รวมถึงข้อมูลวิเคราะห์เชิงลึกที่เกี่ยวข้องทั้งหมดแบบ Cascade เพื่อไม่ให้มีข้อมูลขยะหลงเหลือในระบบ

## 🛠 Technical Tasks
- [x] พัฒนาฟังก์ชัน `logout()` ใน `src/core/database.js` เพื่อเคลียร์ข้อมูลการล็อกอินใน Local Storage / Session Storage และทำความสะอาด State ของเกม
- [x] ออกแบบและเขียนฟังก์ชัน `deletePatientAccount(hn)` เพื่อส่งคำสั่งลบ (DELETE query) ไปยัง Supabase
- [x] CLI script `delete-user.js` สำหรับลบผู้ใช้จาก Postgres โดยตรง (รองรับ `--dry-run`, cascade delete) — merged 2026-07-07 *(admin UI ยังไม่มี)*
- [x] ติดตั้งคำสั่ง `ON DELETE CASCADE` บน Foreign Key Constraints ของตารางล็อกประวัติ (`user_game_logs`) และตารางผลวิเคราะห์เชิงลึก (`user_performance_insights`) ในฝั่ง Supabase database
- [ ] พัฒนา UI Confirmation Modal ขนาดใหญ่และปุ่มยืนยันที่ชัดเจนสำหรับผู้สูงอายุและผู้ดูแล
- [ ] ตรวจสอบว่าระบบนำทาง (Router) ทำงานสอดคล้องกันหลังจากลงชื่อออกและลบบัญชีสำเร็จ
