## 📖 Description
**ในฐานะ** ผู้วิจัย/ผู้ดูแลระบบ (Researcher/Admin)
**ฉันต้องการ** ให้ Leaderboard ภายในเกมแสดงเฉพาะผู้เล่นในกลุ่มทดสอบที่มี Tag ตรงกับผู้เล่นปัจจุบัน
**เพื่อให้** การเปรียบเทียบคะแนนเกิดขึ้นภายในกลุ่มเดียวกัน ง่ายต่อการเปรียบเทียบผลในแต่ละกลุ่มทดสอบ

---

## ✅ Acceptance Criteria
1. [ ] Leaderboard แสดงเฉพาะผู้เล่นที่มี `group_tag` เดียวกับผู้เล่นที่ล็อกอินอยู่
2. [ ] อันดับ (rank) ของผู้เล่นปัจจุบันคำนวณ **ภายในกลุ่ม** — แถว "อันดับของฉัน" ที่ pin ด้านล่างต้องตรงกับกลุ่ม
3. [ ] ผู้เล่นที่ **ไม่มี Tag** (`NULL`) เห็นเฉพาะผู้เล่นที่ไม่มี Tag ด้วยกัน (นับเป็นกลุ่ม default เดียวกัน) — ยืนยัน behavior นี้กับ owner ก่อนพัฒนา
4. [ ] Infinite scroll / pagination ของ Leaderboard ยังทำงานถูกต้องหลังกรองตามกลุ่ม
5. [ ] เส้นทาง fallback ทั้งหมด (Edge Function → RPC → client query) กรองตามกลุ่มเหมือนกัน — ไม่มีเส้นทางไหนหลุดข้อมูลข้ามกลุ่ม
6. [ ] ทดสอบด้วยผู้เล่นอย่างน้อย 2 กลุ่ม Tag ต่างกัน ว่าข้อมูลไม่ปนกัน
