## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ popup และการเปลี่ยนหน้ามีอนิเมชันนุ่มนวล (ค่อย ๆ ปรากฏ/หายไป ไม่กระโดด)
**เพื่อให้** การใช้งานลื่นไหล ไม่สะดุดตา และดูเป็นเกมที่เป็นมิตร

---

## 🎯 Requirements (2 ข้อ)

### Requirement 1 — อนิเมชัน Popup (fade + scale)
- popup **ทั้งหมดในเกม** ต้องมีอนิเมชัน **fade-in + ขยายขึ้น (scale up)** ตอนเปิด และ **fade-out + ย่อลง (scale down)** ตอนปิด
- ระยะเวลา fade + ย่อ/ขยาย = **0.5 วินาที**

### Requirement 2 — อนิเมชันเปลี่ยนหน้า (page transition)
- เพิ่ม **fade-in / fade-out ตอนเปลี่ยนหน้า** เช่น หน้าโลโก้เกม → หน้า Login → หน้าลงทะเบียน
- ยกเว้นหน้า **Game Hub และ minigame** ให้แสดง **Loading** แทน (ไม่ใช้ fade ธรรมดา) — ตัว loading overlay ถูกสร้างไว้แล้วใน `index.html` (`#app-loading`)
- **แยก loading overlay ออกจาก `index.html` มาเป็นไฟล์ component แยกใน `src/ui/`** เพื่อให้แก้ไข/นำกลับมาใช้ซ้ำได้ง่าย
- หน้าอื่น ๆ (นอกเหนือ Game Hub / minigame) ใช้ fade-in / fade-out ตามปกติ

---

## 🔎 สถานะปัจจุบัน (2026-07-02)
- **Popup:** popup ทั้งหมด (`popup-dialog.js`, `game-exit-popup.js`, `resting-point-popup.js`, `day-completion-popup.js`, `checkin-summary-screen.js`) สร้าง overlay `.app-popup` แล้ว `innerHTML` + `appendChild` โดย **ไม่มี** อนิเมชัน enter/leave — โผล่/หายทันที
- **เปลี่ยนหน้า:** `src/main.js` เปลี่ยนหน้าโดย `uiRoot.innerHTML = ""` แล้ว render ใหม่ทันที — ไม่มีทรานสิชั่น
- **Loading:** boot loading overlay เป็น HTML ฝังตายใน `index.html` (`#app-loading`, ใช้ `Logo.png` + `.dotted-loader`) และถูกถอดออกด้วย `finishBootLoading()` ใน `main.js` (เพิ่ม `.app-loading--hidden` แล้ว `remove()` ที่ 400ms); สไตล์อยู่ใน `public/style.css` (`#app-loading`) — **ยังไม่ได้** แยกเป็น component ใน `src/ui/`

## ✅ Acceptance Criteria
1. [ ] popup ทุกตัวในเกมมี fade-in + scale-up ตอนเปิด และ fade-out + scale-down ตอนปิด (ระยะ **0.5s**), รองรับผ่านโครง `.app-popup` ที่ใช้ร่วมกัน
2. [ ] อนิเมชันปิด popup เล่นจบก่อน แล้วจึงลบ element / resolve ผลลัพธ์ (ไม่ตัดจบทันที) — คง contract เดิมของแต่ละ popup (Promise true/false/value, Escape, backdrop, focus, scroll-lock)
3. [ ] การเปลี่ยนหน้าปกติ (โลโก้ → Login → ลงทะเบียน ฯลฯ) มี fade-out หน้าเก่า → fade-in หน้าใหม่
4. [ ] เข้า **Game Hub** และ **minigame** แสดง Loading แทน fade
5. [ ] Loading overlay ถูกย้ายจาก `index.html` มาเป็น **component แยกใน `src/ui/`** (render/show/hide ได้จากโค้ด) โดยพฤติกรรม boot เดิมไม่เสีย (paint ทันทีก่อน `style.css`/fonts มาถึง, safety timeout กันค้าง)
6. [ ] เคารพ `prefers-reduced-motion: reduce` — ปิด/ลดอนิเมชันให้ผู้ใช้ที่ตั้งค่าไว้ (สอดคล้องกับ pattern ที่ใช้ใน `checkin-summary-screen.js`)
7. [ ] ไม่ล้มพฤติกรรมเดิม (back-button guard, exit log, route-race — ดู [PB-01-01](../problems/PB-01-01.md)) และไม่ทำให้จอค้าง/ซ้อนทรานสิชั่นเมื่อเปลี่ยนหน้าเร็ว ๆ
