# User Story: US-E7-05 - แสดงเลขเวอร์ชันบนตัวเกมหลัก (Game Hub) และซ่อนเมื่อเข้ามินิเกม

**Status:** 🏗 In-Progress (Sprint 7) — implemented; pending on-device visual QA
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** [Developer/AI]

---

## 📖 Description
**ในฐานะ** แพทย์ผู้ดูแล / ทีมพัฒนา / ผู้ทดสอบ
**ฉันต้องการ** ให้ตัวเกมหลัก (Game Hub shell ที่ไม่ใช่มินิเกม) แสดงเลขเวอร์ชันของแอป และซ่อนตัวบ่งชี้นี้เมื่อเข้าสู่มินิเกม
**เพื่อให้** ระบุได้ว่ากำลังใช้แอปเวอร์ชันใดเวลาทดสอบ/รายงานปัญหา โดยไม่ไปรบกวนหน้าจอเล่นมินิเกม (ซึ่งมีตัวบ่งชี้เวอร์ชันของเกมเองอยู่แล้ว)

---

## ✅ Acceptance Criteria
1. [x] ตัวบ่งชี้เวอร์ชันถูก render ที่ **ระดับ body** (append `.app-version-badge` เข้า `document.body` ใน `main.js`) จึงแสดงครอบ **ทุกหน้า DOM** (Game Hub, Login, Sign-up, Leaderboard, Player-Info, Popup ฯลฯ) เพื่อเช็คได้เสมอว่าใช้แอปเวอร์ชันใด
2. [x] เลขเวอร์ชันอ่านค่ามาจากแหล่งความจริงเดียวคือ `package.json` (ไม่ฮาร์ดโค้ดซ้ำ) — inject ด้วย Vite `define: { __APP_VERSION__ }` แสดงเป็น `v0.11.0`
3. [x] เมื่อเข้าสู่มินิเกม (Phaser active → `body.game-mode`) ตัวบ่งชี้เวอร์ชันจะถูก **ซ่อน** ด้วย CSS `body.game-mode .app-version-badge { display: none }`
4. [x] เมื่อออกจากมินิเกมกลับสู่ Game Hub (หรือหน้า DOM ใด ๆ → ลบคลาส `game-mode`) ตัวบ่งชี้เวอร์ชันกลับมาแสดงอีกครั้ง (driven by mode class, ไม่ต้อง toggle ด้วย JS)
5. [x] ตัวบ่งชี้ไม่บดบัง UI หลัก — มุมขวาล่าง, `pointer-events: none`, `user-select: none`, ขนาด/สีพอประมาณ
6. [ ] ทดสอบการแสดงผลจริงบนมือถือ (มุมจอ + ความเด่น + ไม่ทับปุ่มสำคัญ)

---

## 🛠 Technical Tasks
- [x] เปิดเผยค่า version จาก `package.json` เข้าสู่ runtime — Vite `define: { __APP_VERSION__: JSON.stringify(pkg.version) }` ใน `vite/config.dev.mjs` + `vite/config.prod.mjs` (อ่าน `package.json` ด้วย `readFileSync`)
- [x] เพิ่มตัวบ่งชี้เวอร์ชันใน DOM shell — append `.app-version-badge` เข้า `document.body` ใน `src/main.js` (`v${__APP_VERSION__}`, guard `typeof` กันค่าไม่ถูก define)
- [x] ผูกการแสดง/ซ่อนเข้ากับสถานะ active game — ใช้ class `body.game-mode` ที่มีอยู่ ผ่าน CSS (`public/style.css`) ไม่ต้องเพิ่ม logic ใน route change
- [x] ตรวจสอบว่าเลขที่แสดงตรงกับ `package.json` หลัง build จริง — `npm run build-nolog` แล้ว `v0.11.0` ถูก fold เข้า bundle
- [ ] อัปเดต `package.json` version ตอน ship Sprint 7 (ค่า badge จะเปลี่ยนตามอัตโนมัติ)
