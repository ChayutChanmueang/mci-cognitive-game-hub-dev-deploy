# User Story: US-E7-05 - แสดงเลขเวอร์ชันบนตัวเกมหลัก (Game Hub) และซ่อนเมื่อเข้ามินิเกม

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** [Developer/AI]

---

## 📖 Description
**ในฐานะ** แพทย์ผู้ดูแล / ทีมพัฒนา / ผู้ทดสอบ
**ฉันต้องการ** ให้ตัวเกมหลัก (Game Hub shell ที่ไม่ใช่มินิเกม) แสดงเลขเวอร์ชันของแอป และซ่อนตัวบ่งชี้นี้เมื่อเข้าสู่มินิเกม
**เพื่อให้** ระบุได้ว่ากำลังใช้แอปเวอร์ชันใดเวลาทดสอบ/รายงานปัญหา โดยไม่ไปรบกวนหน้าจอเล่นมินิเกม (ซึ่งมีตัวบ่งชี้เวอร์ชันของเกมเองอยู่แล้ว)

---

## ✅ Acceptance Criteria
1. [ ] ตัวบ่งชี้เวอร์ชันถูก render ที่ **ระดับ body (html)** จึงแสดงครอบ **ทุกหน้า DOM** (Game Hub, Login, Sign-up, Leaderboard, Player-Info, Popup ฯลฯ) เพื่อเช็คได้เสมอว่าใช้แอปเวอร์ชันใด
2. [ ] เลขเวอร์ชันอ่านค่ามาจากแหล่งความจริงเดียวคือ `package.json` (ไม่ฮาร์ดโค้ดซ้ำ) เช่น `v0.11.0`
3. [ ] เมื่อเข้าสู่มินิเกม (Phaser active) ตัวบ่งชี้เวอร์ชันจะถูก **ปิด/ซ่อน** ไว้
4. [ ] เมื่อออกจากมินิเกมกลับสู่ Game Hub (หรือหน้า DOM ใด ๆ) ตัวบ่งชี้เวอร์ชันกลับมาแสดงอีกครั้ง
5. [ ] ตัวบ่งชี้ไม่บดบัง UI หลักและมีความเด่นพอประมาณ (ไม่รบกวนผู้เล่นสูงอายุ)

---

## 🛠 Technical Tasks
- [ ] เปิดเผยค่า version จาก `package.json` เข้าสู่ runtime (เช่น Vite `define: { __APP_VERSION__ }` หรือ import)
- [ ] เพิ่มตัวบ่งชี้เวอร์ชันใน DOM shell (เช่นมุมจอ Game Hub) ผ่าน `src/main.js` / component ที่เหมาะสม
- [ ] ผูกการแสดง/ซ่อนเข้ากับสถานะ active game (ใช้ `app` mode class เช่น `hub-mode`/`game-...` ที่มีอยู่)
- [ ] ตรวจสอบว่าเลขที่แสดงตรงกับ `package.json` หลัง build จริง
