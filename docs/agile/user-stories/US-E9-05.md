## 📖 Description
**ในฐานะ** แอดมิน/ทีมวิจัย
**ฉันต้องการ** ดึงข้อมูลทั้งหมดของผู้เล่นออกมา **ทีเดียว** ได้แบบ **ข้อมูลไม่หาย**
**เพื่อให้** วิเคราะห์ผลการเล่นและวิจัยได้ครบถ้วน โดยไม่ต้อง export หลายครั้งแล้วเสี่ยงข้อมูลขาด

---

## 🐛 Problem (จากการลงพื้นที่ — v1.0.0)
- ระบบ export ปัจจุบัน ([US-E5-02](archives/US-E5-02.md)) อาจไม่ครอบคลุมข้อมูลทุกตาราง/ทุก event
- ทีมต้องการวิธี **ดึงข้อมูลผู้เล่นทั้งหมดในครั้งเดียว** โดยไม่สูญหาย

---

## ✅ Acceptance Criteria
1. [ ] มีวิธี export (หรือ download) ข้อมูลผู้เล่น **ครบชุด** ในครั้งเดียว — ครอบคลุมอย่างน้อย: profile, game history, scores, replay events, check-in history (ตาม schema ปัจจุบัน)
2. [ ] ข้อมูลที่ export **ไม่สูญหาย** — จำนวนแถว/event ตรงกับ DB (หรือมี checksum/row count ยืนยัน)
3. [ ] รองรับ export **รายผู้เล่น** (by HN) และ **ทั้งระบบ** (bulk) ตามสิทธิ์ admin
4. [ ] รูปแบบไฟล์อ่านได้ง่าย (CSV และ/หรือ JSON) — มีเอกสารอธิบาย field mapping
5. [ ] ไม่กระทบผู้เล่นที่กำลังเล่นอยู่ (read-only export)
6. [ ] อัปเดต `docs/software/03-data-schema.md` เมื่อมี field/table ใหม่ที่รวมใน export

---

## 🛠 Technical Tasks
- [ ] สำรวจตาราง/event ทั้งหมดที่เกี่ยวกับผู้เล่น — เปรียบเทียบกับ CSV export ปัจจุบัน
- [ ] ออกแบบ full export API หรือ admin action (Supabase RPC / edge function / batch query)
- [ ] Implement export UI ใน admin screen (หรือขยาย CSV export ที่มี)
- [ ] เพิ่ม validation (row count / integrity check)
- [ ] ทดสอบกับข้อมูล production snapshot (read-only)
- [ ] อัปเดตเอกสาร schema + admin guide
