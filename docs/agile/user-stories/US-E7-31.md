## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่กำลังดูละครสั้นประจำวัน
**ฉันต้องการ** ปิดหน้าต่างวิดีโอได้ระหว่างที่คลิปยังเล่นอยู่
**เพื่อให้** ไม่ต้องนั่งรอจนจบคลิปที่บางทีก็ยาวเกินไป กว่าปุ่ม "กลับไปหน้าเกม" จะโผล่มา

ตอนนี้ปุ่ม `กลับไปหน้าเกม` (`.gh-start-button`) จะแสดง **ก็ต่อเมื่อคลิปเล่นจบแล้ว** เท่านั้น
(`.gh-video-popup.is-ended .gh-video-popup__button { display: block }`) ระหว่างที่คลิปยังเล่น
ผู้เล่นจึงไม่มีปุ่มออกเลย

**ปุ่มทั้งสองต้องแสดงสลับกัน** — ปุ่มปิดโผล่ตอนกำลังเล่น, ปุ่ม `กลับไปหน้าเกม` โผล่ตอนจบ
ไม่แสดงพร้อมกัน

---

## 🔎 สิ่งที่พบตอนสำรวจโค้ด (อ่านก่อนเริ่มทำ)

**owner ใส่ปุ่มย้อนกลับไว้แล้ว (ยังไม่ commit) แต่ยังเป็นปุ่มตาย** — `checkin-summary-screen.js`
เรนเดอร์ `renderIconButtonBack()` ไว้ในแถบหัวเรื่องพร้อม CSS `.gh-video-popup__title-back*`
และเปลี่ยน label ปุ่มตอนจบจาก `ต่อไป` เป็น `กลับไปหน้าเกม` แล้ว ผู้เล่นเห็นปุ่มและกดได้
แต่ `wire()` ผูก event ให้เฉพาะ `.gh-start-button` เท่านั้น **ยังไม่มีใครผูก handler ให้ปุ่มนี้**
กดแล้วจึงไม่เกิดอะไรขึ้น

⚠️ ดังนั้นงานนี้ **ไม่ใช่การเพิ่มปุ่มใหม่** แต่คือการทำให้ปุ่มที่มีอยู่แล้วทำงาน + สลับการแสดงผลกับ
ปุ่มตอนจบ ซึ่งถูกกว่าและไม่ต้องเพิ่ม art ใหม่

⚠️ ปุ่มนั้นยังใช้ `id="player-info-back"` ซึ่ง**ก็อปมาจาก `player-info-screen.js:135`** ทั้งดวง —
เป็น id ที่สื่อความหมายผิด (ไม่ใช่หน้า player-info) และเสี่ยง id ซ้ำถ้าวันหนึ่งสอง DOM อยู่พร้อมกัน
ควรเปลี่ยนเป็น id ของตัวเอง เช่น `checkin-video-close`

## ✅ Acceptance Criteria
1. [ ] ระหว่างคลิปกำลังเล่น มีปุ่มปิด/ออกที่มองเห็นชัดและกดได้จริง
2. [ ] เมื่อคลิปเล่นจบ (`is-ended`) ปุ่มปิดหายไป และปุ่ม `กลับไปหน้าเกม` แสดงแทน — **ไม่แสดงพร้อมกัน**
3. [ ] กดปุ่มปิดระหว่างเล่นแล้ว popup ปิด และ flow เช็คอินไปต่อได้เหมือนกดปุ่มตอนจบ (ไม่ค้าง ไม่ต้องดูซ้ำ)
4. [ ] วิดีโอถูก `destroy()` + ถอนออกจาก `VideoManager` เมื่อปิดกลางคัน — ไม่มีเสียงเล่นต่อหลัง popup ปิด
5. [ ] ทรานสิชั่นปิดตาม [US-E7-20](US-E7-20.md) (`dismissPopup`) เหมือนทางออกอื่น
6. [ ] เปลี่ยน `id="player-info-back"` เป็น id เฉพาะของ popup นี้
7. [ ] A11y — ปุ่มมี `aria-label` ที่บอกว่าเป็นการปิด/ข้ามคลิป และกดด้วยคีย์บอร์ดได้

## ❓ ต้องเคลียร์กับ owner ก่อนลงมือ
- **ปิดกลางคันนับว่า "ดูคลิปแล้ว" หรือยัง?** ถ้าเช็คอินของวันนั้นผูกกับการดูคลิปจบ การปล่อยให้กด
  ข้ามได้จะทำให้ผู้เล่นข้ามเนื้อหาได้ทุกวัน — ต้องตัดสินใจว่า
  (ก) ปิดแล้วนับว่าเสร็จเหมือนกัน, หรือ (ข) ปิดแล้วยังไม่นับ ต้องกลับมาดูใหม่
- **ใช้ปุ่มย้อนกลับที่มีอยู่ หรืออยากได้ปุ่มกากบาทแยกต่างหาก?** ปุ่มที่มีอยู่คือ `Icon_ButtonBack`
  (ลูกศร) ซึ่งสื่อว่า "ย้อนกลับ" ไม่ใช่ "ปิด" — ถ้าอยากได้กากบาทต้องขอ art เพิ่ม
