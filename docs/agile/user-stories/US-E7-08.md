# User Story: US-E7-08 - แก้คำศัพท์ยากในเกมคำใบ้บริบท (เนื้อเรื่องกางเต็นท์)

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** [Developer/AI + ทีมแพทย์]
**Source:** [Doctor Feedback — Meeting #2 (2026-06-24)](../meeting-backlogs/2026-06-24.md) §2.1

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้คำศัพท์ในโจทย์เป็นคำที่คุ้นเคยในชีวิตประจำวัน
**เพื่อให้** ไม่สะดุดกับคำที่ไม่รู้จัก (เช่น "สมอบก") และโฟกัสที่การฝึกสมองได้

---

## ✅ Acceptance Criteria
1. [ ] เนื้อเรื่องที่เกี่ยวกับ **กางเต็นท์** ในเกมคำใบ้บริบท (Context Clues) ไม่ใช้คำว่า **"สมอบก"** อีกต่อไป
2. [ ] คำที่ใช้แทนเป็นคำที่ **ผู้สูงอายุคุ้นเคย** และผ่านการเห็นชอบจากทีมแพทย์
3. [ ] ทบทวนชุดคำศัพท์อื่น ๆ ในเกมเพื่อหาคำยากที่อาจเป็นปัญหาคล้ายกัน
4. [ ] โจทย์ที่แก้แล้วยังคงความถูกต้องเชิงไวยากรณ์และความหมาย

---

## 🛠 Technical Tasks
- [ ] ค้นหาตำแหน่งคำว่า "สมอบก" / เนื้อเรื่องกางเต็นท์ในชุดข้อมูลโจทย์ของ Context Clues
- [ ] เสนอคำทดแทนและขอความเห็นชอบจากทีมแพทย์
- [ ] อัปเดตชุดข้อมูลโจทย์ (data) และตรวจ icon/ภาพประกอบให้ตรงกับคำใหม่
- [ ] ทบทวนคลังคำศัพท์เพื่อ flag คำยากอื่น ๆ
