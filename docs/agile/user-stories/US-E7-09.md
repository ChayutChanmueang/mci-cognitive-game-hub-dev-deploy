## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้เกมจดหมายจากหลานรัก (Postcard Reader) มีเสียงอ่านที่เป็นธรรมชาติ หรือถ้าไม่มีก็ให้ตัวหนังสือโจทย์ใหญ่พออ่านเองได้
**เพื่อให้** เข้าใจเนื้อหาจดหมายได้ชัดเจน ไม่สับสนกับเสียงที่ผิดเพี้ยน

## ✅ Acceptance Criteria
1. [ ] ถ้าหา **เสียง AI ใหม่** ที่คุณภาพดีได้ → ใช้เสียงใหม่ในเกมจดหมายจากหลานรัก
2. [ ] ถ้าหาไม่ได้ → **ถอดเสียงออก** และ **ขยายตัวอักษรของโจทย์ให้ใหญ่ขึ้น** ทดแทน
3. [ ] ในกรณีถอดเสียงออก ผู้เล่นยังสามารถอ่านและตอบโจทย์ได้ครบถ้วนภายในเวลาที่กำหนด
4. [ ] พฤติกรรมสอดคล้องกับระบบ Voice Over ส่วนกลางของแอป (ไม่ขัดกัน)
