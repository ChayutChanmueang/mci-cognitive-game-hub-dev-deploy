# User Story: US-E7-16 - แก้ Popup (ตัด popup หลังดูละคร + เข้าเกมซ้ำในวันที่เล่นจบแล้ว)

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** ก้องไผ่
**Source:** Owner Task Block — ก้องไผ่ (2026-06-24), [Sprint 07](../sprint-backlogs/sprint-07.md)

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ Popup ในจังหวะสำคัญแสดงผลถูกต้องและสื่อสารชัดเจน
**เพื่อให้** เข้าใจสถานะของตัวเอง (ดูละครจบ / เล่นครบของวันแล้ว) โดยไม่สับสน

---

## ✅ Acceptance Criteria
1. [ ] **ตัด Popup หลังจากดูละครเสร็จ** ("พบกันใหม่วันพรุ่งนี้" / "พรุ่งนี้มีต้นคิดดี และละครสั้นรอคุณอยู่") **ออก** — ไม่แสดง popup นี้อีก หลังดูละครจบให้ปิด check-in flow แล้วกลับหน้าหลักได้เลย (ตัดความซ้ำซ้อนกับหน้าต้นคิดดี/ละครก่อนหน้า) — ดู [ภาพอ้างอิงของหน้าที่ถูกตัด](assets/us-e7-16-popup-after-drama.jpg)
   > **เปลี่ยนแปลงขอบเขต (2026-06-25):** เดิมข้อนี้คือ "sync ขนาดต้นคิดดีให้ตรงกับหน้าก่อน" → เปลี่ยนเป็น **ตัดหน้านี้ออกทั้งหมด** ตามที่เจ้าของงานสั่ง (หน้านี้ยังไม่ถูก implement ใน code — เป็นการตัดออกจากแบบ/ขอบเขต)
2. [ ] **Popup เมื่อผู้เล่นเล่นจบของวันแล้วและกลับเข้ามาในวันเดิม** ("วันนี้พักก่อน") — แสดง **ตัวละครคนแก่นั่งพัก** ตามเพศ: เพศชาย = **คุณตา**, เพศหญิง = **คุณยาย** — ดู [ภาพอ้างอิง](assets/us-e7-16-popup-same-day-reentry.png)
3. [ ] Popup ทั้งสองใช้กรอบ/ระบบภาพ Popup ตาม [US-E7-04](US-E7-04.md) และมาตรฐานสีปุ่มตาม [US-E7-15](US-E7-15.md)
4. [ ] ตัวละครคนแก่ใน Popup มี **เงาด้านล่าง** ตาม [US-E7-14](US-E7-14.md) ข้อ 4
5. [ ] ทดสอบ flow จริงทั้งสองกรณีบนมือถือ

## 🛠 Technical Tasks
- [ ] **ตัด Popup หลังดูละคร ("พบกันใหม่วันพรุ่งนี้") ออก** — ไม่เพิ่ม/ไม่แสดง popup นี้ในขั้นตอนหลัง short-video; เมื่อดูละครจบให้ปิด check-in flow แล้ว resolve กลับหน้าหลักได้เลย (ปัจจุบัน `state.step === "video"` ปิดด้วยปุ่ม "กลับสู่หน้าหลัก" → `cleanup(true)` อยู่แล้ว ไม่ต้องเพิ่มหน้าใหม่)
- [ ] ตรวจสอบ/แก้ Popup กรณีเข้าเกมซ้ำในวันที่เล่นจบแล้ว (day-completion) — เลือกภาพคุณตา/คุณยายตามเพศผู้เล่น
- [ ] ผูกกรอบ Popup, สีปุ่มมาตรฐาน และเงาตัวละครเข้ากับ Popup ที่เหลือ (เข้าซ้ำในวันเดิม)
