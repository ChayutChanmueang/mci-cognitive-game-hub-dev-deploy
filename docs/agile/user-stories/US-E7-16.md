# User Story: US-E7-16 - แก้ Popup (หลังดูละคร + เข้าเกมซ้ำในวันที่เล่นจบแล้ว)

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** ก้องไผ่
**Source:** Owner Task Block — ก้องไผ่ (2026-06-24), [Sprint 07](../sprint-backlogs/sprint-07.md)

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ Popup ในจังหวะสำคัญแสดงผลถูกต้องและสื่อสารชัดเจน
**เพื่อให้** เข้าใจสถานะของตัวเอง (ดูละครจบ / เล่นครบของวันแล้ว) โดยไม่สับสน

---

## ✅ Acceptance Criteria
1. [ ] **Popup หลังจากดูละครเสร็จ** ("พบกันใหม่วันพรุ่งนี้") — **ต้นคิดดี** ที่แสดงใน Popup นี้ต้องมีขนาด/สถานะการเติบโต **ตรงกับต้นคิดดีในหน้าก่อนหน้า** (หน้าก่อนโตแค่ไหน Popup นี้ก็โตตามนั้น) — ดู [ภาพอ้างอิง](assets/us-e7-16-popup-after-drama.jpg)
2. [ ] **Popup เมื่อผู้เล่นเล่นจบของวันแล้วและกลับเข้ามาในวันเดิม** ("วันนี้พักก่อน") — แสดง **ตัวละครคนแก่นั่งพัก** ตามเพศ: เพศชาย = **คุณตา**, เพศหญิง = **คุณยาย** — ดู [ภาพอ้างอิง](assets/us-e7-16-popup-same-day-reentry.png)
3. [ ] Popup ทั้งสองใช้กรอบ/ระบบภาพ Popup ตาม [US-E7-04](US-E7-04.md) และมาตรฐานสีปุ่มตาม [US-E7-15](US-E7-15.md)
4. [ ] ตัวละครคนแก่ใน Popup มี **เงาด้านล่าง** ตาม [US-E7-14](US-E7-14.md) ข้อ 4
5. [ ] ทดสอบ flow จริงทั้งสองกรณีบนมือถือ
