## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้หน้ากระดานคะแนน (Leaderboard) มีงานศิลป์ที่ตรงกับธีมเกม
**เพื่อให้** หน้าจอดูน่าใช้ มีเอกลักษณ์ และเข้าใจง่ายแทนการใช้ UI ว่างเปล่า/placeholder

---

## ✅ Acceptance Criteria
1. [x] หน้า Leaderboard ใช้ art asset จากธีมเกม (พื้นหลังเขียว + กรอบครีมมน, กรอบอันดับการ์ดขาว, ไอคอนถ้วยรางวัล, เหรียญทอง/เงิน/ทองแดง) แทน UI เปล่า
2. [x] อันดับผู้เล่นปัจจุบันเน้นด้วยภาพชัดเจน 2 จุด — วงแหวนสีส้มรอบแถว (`data-variant~="you"`) และแถบ "อันดับของคุณ" ปักหมุดด้านล่าง (Bottom-Status-Player)
3. [x] art asset แสดงผลคมชัดบนมือถือจริงและไม่ทำให้รายการคะแนนเลื่อน (scroll) ผิดเพี้ยน *(ยืนยันโดยเจ้าของงาน 2026-07-06)*
4. [x] asset เก็บใน `public/assets/leaderboard/` (coin SVG + flower/trophy PNG ≈ 30 KB รวม) — เหรียญ/ดอกไม้/ถ้วยเป็นไฟล์ ส่วนพื้นหลัง/กรอบ/หลอดทำด้วย CSS ล้วน
