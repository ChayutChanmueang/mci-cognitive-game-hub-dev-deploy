## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้หน้ากระดานคะแนน (Leaderboard) มีงานศิลป์ที่ตรงกับธีมเกม
**เพื่อให้** หน้าจอดูน่าใช้ มีเอกลักษณ์ และเข้าใจง่ายแทนการใช้ UI ว่างเปล่า/placeholder

---

## ✅ Acceptance Criteria
1. [ ] หน้า Leaderboard ใช้ art asset จากธีมเกม (พื้นหลัง, กรอบอันดับ, ไอคอนถ้วยรางวัล/เหรียญ ฯลฯ) แทน UI เปล่า
2. [ ] อันดับผู้เล่นปัจจุบัน (pinned rank) มีการเน้นด้วยภาพให้ชัดเจน
3. [ ] art asset แสดงผลคมชัดบนมือถือจริงและไม่ทำให้รายการคะแนนเลื่อน (scroll) ผิดเพี้ยน
4. [ ] asset ถูกจัดเก็บภายใต้ `public/assets/` และไม่ทำให้เวลาโหลดหน้าช้าลงอย่างมีนัยสำคัญ

---

## 🛠 Technical Tasks
- [ ] รวบรวม/ส่งออก art asset ของ Leaderboard (จาก Figma) และจัดเก็บใน `public/assets/`
- [ ] ปรับ `src/ui/leaderboard-screen.js` และ CSS ให้ใช้ asset ใหม่
- [ ] พิจารณาทำพื้นหลัง/กรอบด้วย CSS แทนรูปภาพในจุดที่ทำได้ (ลดขนาด bundle)
- [ ] ตรวจสอบ scroll/无限 scroll ยังทำงานถูกต้องหลังเปลี่ยนภาพ
