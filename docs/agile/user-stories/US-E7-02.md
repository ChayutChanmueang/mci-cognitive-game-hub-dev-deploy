# User Story: US-E7-02 - Game art assets สำหรับหน้า Login และ Sign-up

**Status:** 🔍 Review / Testing (Sprint 7) — Login (v0.17.0) + Sign-up (v0.18.0) เสร็จด้วย Figma components; รอ QA มือถือ

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่เพิ่งเปิดแอป
**ฉันต้องการ** ให้หน้าเข้าสู่ระบบ (Login) และหน้าลงทะเบียน (Sign-up) มีงานศิลป์ตรงธีมเกม
**เพื่อให้** สร้างความประทับใจแรกที่ดี และทำให้ขั้นตอนการกรอกข้อมูลดูเป็นมิตร ไม่น่ากลัว

---

## ✅ Acceptance Criteria
1. [x] หน้า Login มี art asset (Frame_Panel + Frame_TextFieldBox + Start-Game-Button จาก Figma) สอดคล้องกับธีมเกม
2. [x] หน้า Sign-up มี art asset ที่เข้าชุดกัน (Frame_Form_Panel + Frame_TextFieldBox + Button_OK "ยืนยันข้อมูลผู้เล่น") — v0.18.0
3. [x] **หน้า Login ของ Admin** มี art asset เข้าชุดกับธีม (ขอบเขตเพิ่มจาก Owner Task Block ก้องไผ่)
4. [x] ขนาดตัวอักษร/ปุ่มยังคงเป็นไปตามแนวทาง Accessibility สำหรับผู้สูงอายุ (ปุ่ม Start-Game-Button ใหญ่ + ฟิลด์ใหญ่)
5. [ ] แสดงผลถูกต้องทั้งแนวตั้งบนมือถือ และไม่ล้นจอ (overflow) เมื่อคีย์บอร์ดเด้งขึ้น *(รอ QA บนมือถือ)*
