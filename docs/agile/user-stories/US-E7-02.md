# User Story: US-E7-02 - Game art assets สำหรับหน้า Login และ Sign-up

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** [Developer/AI]

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่เพิ่งเปิดแอป
**ฉันต้องการ** ให้หน้าเข้าสู่ระบบ (Login) และหน้าลงทะเบียน (Sign-up) มีงานศิลป์ตรงธีมเกม
**เพื่อให้** สร้างความประทับใจแรกที่ดี และทำให้ขั้นตอนการกรอกข้อมูลดูเป็นมิตร ไม่น่ากลัว

---

## ✅ Acceptance Criteria
1. [ ] หน้า Login มี art asset (โลโก้/ตัวละคร/พื้นหลังธีมเกม) สอดคล้องกับหน้า Welcome
2. [ ] หน้า Sign-up มี art asset ที่เข้าชุดกัน และไม่บดบังฟิลด์กรอกข้อมูล
3. [ ] **หน้า Login ของ Admin** มี art asset เข้าชุดกับธีม (ขอบเขตเพิ่มจาก Owner Task Block ก้องไผ่)
4. [ ] ขนาดตัวอักษร/ปุ่มยังคงเป็นไปตามแนวทาง Accessibility สำหรับผู้สูงอายุ
5. [ ] แสดงผลถูกต้องทั้งแนวตั้งบนมือถือ และไม่ล้นจอ (overflow) เมื่อคีย์บอร์ดเด้งขึ้น
