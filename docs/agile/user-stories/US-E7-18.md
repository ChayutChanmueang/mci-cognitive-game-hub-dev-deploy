## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ / ผู้ดูแล
**ฉันต้องการ** ให้ข้อความ feedback (error หรือสถานะกำลังทำงาน เช่น "กำลังตรวจสอบข้อมูล...") แสดงเป็น **Toast ลอยขึ้นมา** แบบบน Android แทนที่จะเป็นข้อความใต้ช่องกรอก
**เพื่อให้** สังเกตเห็นข้อความได้ชัดเจน สม่ำเสมอทุกหน้า และไม่ดันเลย์เอาต์ของฟอร์ม

> อ้างอิงดีไซน์: กล่องข้อความมุมโค้งสีเทาเข้ม ตัวอักษรขาว ลอยกลางล่างจอ (ดู [ภาพอ้างอิง](assets/us-e7-18-toast.jpg))

---

## ✅ Acceptance Criteria
1. [ ] **Toast เป็นไฟล์ class/module แยกใน `src/ui/components/`** (เช่น `toast.js`) เรียกใช้ซ้ำได้ทั้งแอป ผ่าน API กลาง เช่น `showToast(message, { type, duration })`
2. [ ] สไตล์แบบ Android: กล่องมุมโค้ง (pill) พื้นเทาเข้มกึ่งโปร่ง ตัวอักษรขาว, ลอย **กลาง-ล่างจอ**, `position: fixed`, auto-dismiss หลังไม่กี่วินาที (fade in/out)
3. [ ] รองรับ **ชนิดข้อความ** (info / success / error อย่างน้อย info+error), กำหนด `duration` ได้, มีกลไก **queue หรือ replace** เมื่อมีหลายข้อความ, และ **a11y** (`role="status"` / `aria-live="polite"`; error เป็น `assertive`)
4. [ ] แทนที่ feedback ใต้ช่องกรอกในหน้า **Login, Admin Login, Sign-up, Player-Info** (ข้อความ error + สถานะกำลังทำงาน) ด้วยการเรียก Toast
5. [ ] เอา `<p>` feedback เดิม (`.gh-login__feedback` / `.gh-form__feedback`) ออก (หรือซ่อน) โดยฟอร์มไม่กระโดด/เลย์เอาต์ไม่ขยับ
6. [ ] CSS ของ Toast อยู่ใน `public/components.css` (ตามแนวทางโปรเจค); รองรับ `prefers-reduced-motion`
7. [ ] แสดงผลถูกต้องบนมือถือ — ไม่ถูกคีย์บอร์ด/safe-area บัง และอ่านง่ายสำหรับผู้สูงอายุ (ขนาดตัวอักษรเหมาะสม)

---

## 🛠 Technical Tasks
- [ ] สร้าง `src/ui/components/toast.js` — API `showToast(message, { type = "info", duration = 3000 })` + auto-dismiss + queue/replace + `cancel()`/clear, ใส่ `role`/`aria-live`, เคารพ `prefers-reduced-motion`
- [ ] เพิ่ม CSS `.gh-toast` (+ ชนิด `--error`/`--success`) ใน `public/components.css`; container เดียวต่อท้าย `document.body`
- [ ] แทนที่การใช้ `feedback.textContent = ...` ใน `login-screen.js`, `admin-login-screen.js`, `signup-screen.js`, `player-info-screen.js` ด้วย `showToast(...)`
- [ ] ลบ/ซ่อน element `<p>` feedback เดิม และเก็บกวาด CSS ที่ไม่ใช้
- [ ] (ตัวเลือก) ค้นหา feedback/inline-status ในหน้าอื่น ๆ (leaderboard, popups) ที่ควรย้ายมาใช้ Toast ด้วย
