# User Story: US-E7-18 - Toast component (ย้าย feedback ข้อความ → Toast แบบ Android)

**Status:** ✅ Done (Sprint 7) — implemented v0.23.0; ยืนยันการแสดงผลถูกต้องโดยเจ้าของงาน (2026-07-02)

**Owner:** ก้องไผ่
**Source:** Owner request (2026-06-29), [Sprint 07](../sprint-backlogs/sprint-07.md)

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ / ผู้ดูแล
**ฉันต้องการ** ให้ข้อความ feedback (error หรือสถานะกำลังทำงาน เช่น "กำลังตรวจสอบข้อมูล...") แสดงเป็น **Toast ลอยขึ้นมา** แบบบน Android แทนที่จะเป็นข้อความใต้ช่องกรอก
**เพื่อให้** สังเกตเห็นข้อความได้ชัดเจน สม่ำเสมอทุกหน้า และไม่ดันเลย์เอาต์ของฟอร์ม

> อ้างอิงดีไซน์: กล่องข้อความมุมโค้งสีเทาเข้ม ตัวอักษรขาว ลอยกลางล่างจอ (ดู [ภาพอ้างอิง](assets/us-e7-18-toast.jpg))

---

## ✅ Acceptance Criteria
1. [x] **Toast เป็นไฟล์ module แยก** `src/ui/components/toast.js` — API กลาง `showToast(message, { type, duration })` + `clearToast()`
2. [x] สไตล์แบบ Android: กล่อง pill พื้นเทาเข้มกึ่งโปร่ง ตัวอักษรขาว, ลอย **กลาง-ล่างจอ**, `position: fixed`, auto-dismiss (fade + slide in/out)
3. [x] รองรับชนิด info / success / error (error → `role="alert"` + `assertive` + แดง), กำหนด `duration` ได้ (`0` = sticky), กลไก **replace** (โชว์ทีละอัน แบบ Android), a11y (`role`/`aria-live`)
4. [x] แทนที่ feedback ในหน้า **Login, Admin Login, Sign-up, Player-Info** (error + สถานะกำลังทำงาน + สำเร็จ) ด้วย Toast
5. [x] เอา `<p>` feedback เดิม (`.gh-login__feedback` / `.gh-form__feedback`) ออกทั้งหมด — ฟอร์มไม่กระโดด (Toast เป็น `fixed` ไม่ดันเลย์เอาต์); ลบ CSS ที่ไม่ใช้แล้ว
6. [x] CSS `.gh-toast*` อยู่ใน `public/components.css`; รองรับ `prefers-reduced-motion`
7. [x] แสดงผลถูกต้องบนมือถือ (ไม่ถูกคีย์บอร์ด/safe-area บัง, อ่านง่าย) — ยืนยันโดยเจ้าของงาน (2026-07-02)
