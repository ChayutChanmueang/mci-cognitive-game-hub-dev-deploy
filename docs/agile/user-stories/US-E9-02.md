## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่ใช้มือถือไม่มี Gyroscope
**ฉันต้องการ** มีปุ่ม **ข้าม** มินิเกมทำอาหาร (Fry Food) ได้
**เพื่อให้** ไม่ติดค้างในเกมและสามารถเล่นด่านอื่นต่อได้ แม้จะไม่ได้รับคะแนนในมินิเกมนี้

---

## 🐛 Problem (จากการลงพื้นที่ — v1.0.0)
- บางเครื่องผู้สูงอายุ **ไม่มี Gyroscope** (หรือไม่ได้รับอนุญาต motion)
- ทำให้ **ผัดอาหารไม่ได้** และไม่สามารถผ่านมินิเกมได้

---

## ✅ Acceptance Criteria
1. [ ] มีปุ่ม **"ข้าม"** ที่มองเห็นได้ชัดบนหน้าเล่น Fry Food (ขนาดปุ่มเหมาะกับผู้สูงอายุ)
2. [ ] เมื่อกดข้าม มินิเกม **จบทันที** และผู้เล่นกลับสู่ flow ปกติ (Game Hub / ด่านถัดไป)
3. [ ] ผู้เล่นที่กดข้าม **ไม่ได้รับคะแนน** ในมินิเกมนี้ (score = 0 หรือไม่บันทึกคะแนนปกติ — ตาม convention ที่มีอยู่)
4. [ ] บันทึก event ว่าผู้เล่น **ข้าม** (เพื่อ analytics) — ไม่กระทบข้อมูลผู้เล่นที่เล่นอยู่แล้ว
5. [ ] ผู้เล่นที่มี Gyroscope ยังเล่นแบบเดิมได้ — ปุ่มข้ามไม่รบกวน UX หลัก
6. [ ] ทดสอบบนเครื่อง **ไม่มี Gyroscope** และเครื่องปกติ
