## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่อ่านภาษาอังกฤษไม่คล่อง
**ฉันต้องการ** ให้ชื่อมินิเกมทุกเกมเป็นภาษาไทย และตัวหนังสืออธิบายวิธีเล่นมีขนาดใหญ่ขึ้น
**เพื่อให้** เข้าใจได้ทันทีว่าเกมชื่ออะไรและเล่นอย่างไร โดยไม่ต้องเดาจากภาษาอังกฤษ

---

## ✅ Acceptance Criteria
1. [x] ชื่อมินิเกมทุกเกมแสดงเป็น **ภาษาไทย** ทั้งบน **หน้าปกเกม** และหน้า **Gamehub** (ไม่มีชื่ออังกฤษค้าง)
   - [x] **Gamehub** — แก้ข้อมูลในฐานข้อมูล (คอลัมน์ `th_name`) เป็นภาษาไทย; game-hub อ่าน `th_name` อยู่แล้ว (`displayName = th_name || name`)
   - [x] **หน้าปกเกม/ทูทอเรียล** ของแต่ละมินิเกม — ยืนยันโดยเจ้าของงาน 2026-07-06
2. [x] ตัวหนังสือ **อธิบายวิธีเล่น** บนหน้าปกเกมมีขนาด **ใหญ่ขึ้น** อ่านง่ายบนมือถือจริง — ยืนยันโดยเจ้าของงาน 2026-07-06
3. [x] ชื่อภาษาไทยสอดคล้องกันทุกจุดที่เกมถูกอ้างถึง (ปก, Gamehub, ผลคะแนน)
4. [x] ไม่กระทบ key/asset ภายในที่ใช้อ้างอิงเกม (เปลี่ยนเฉพาะ display label / ข้อมูล `th_name` ไม่แตะ `gid`/slug)
