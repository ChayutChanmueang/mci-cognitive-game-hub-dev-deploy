## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่อ่านภาษาอังกฤษไม่คล่อง
**ฉันต้องการ** ให้ชื่อมินิเกมทุกเกมเป็นภาษาไทย และตัวหนังสืออธิบายวิธีเล่นมีขนาดใหญ่ขึ้น
**เพื่อให้** เข้าใจได้ทันทีว่าเกมชื่ออะไรและเล่นอย่างไร โดยไม่ต้องเดาจากภาษาอังกฤษ

---

## ✅ Acceptance Criteria
1. [ ] ชื่อมินิเกมทุกเกมแสดงเป็น **ภาษาไทย** ทั้งบน **หน้าปกเกม** และหน้า **Gamehub** (ไม่มีชื่ออังกฤษค้าง)
2. [ ] ตัวหนังสือ **อธิบายวิธีเล่น** บนหน้าปกเกมมีขนาด **ใหญ่ขึ้น** อ่านง่ายบนมือถือจริง
3. [ ] ชื่อภาษาไทยสอดคล้องกันทุกจุดที่เกมถูกอ้างถึง (ปก, Gamehub, ผลคะแนน)
4. [ ] ไม่กระทบ key/asset ภายในที่ใช้อ้างอิงเกม (เปลี่ยนเฉพาะ display label)

---

## 🛠 Technical Tasks
- [ ] รวบรวมชื่อไทยมาตรฐานของแต่ละเกม (นักสืบสวนสัตว์, คนเลี้ยงสัตว์, คำใบ้บริบท, ตกแต่งสมมาตร, ผู้อ่านไปรษณีย์/จดหมายจากหลานรัก, ทอดอาหาร ฯลฯ)
- [ ] ปรับ display label ในหน้า Gamehub และหน้าปก/ทูทอเรียลของแต่ละมินิเกม
- [ ] ปรับขนาด/น้ำหนักฟอนต์ของข้อความวิธีเล่นบนหน้าปกเกม
- [ ] ตรวจสอบบนมือถือจริงว่าข้อความไม่ล้น/ตัดคำผิด
