# User Story: US-E4-03 - บันทึกข้อมูลเชิงลึก (Accuracy, Reaction Time, Fatigue Effect)

**Status:** ✅ Done (Implemented and tested in Sprint 6)  
**Epic:** [E4: Data Tracking & Analytics (Supabase)](../01-product-backlog.md)  
**Owner:** [Developer/AI]  

---

## 📖 Description
**ในฐานะ** ผู้ดูแลหรือแพทย์ผู้ทำการรักษา  
**ฉันต้องการ** ให้ระบบบันทึกพฤติกรรมและการตอบสนองอย่างละเอียดขณะเล่นเกม (ความแม่นยำ, เวลาตอบสนอง, ความล้า, การเดา)  
**เพื่อให้** ฉันสามารถนำประวัติการตอบสนองไปประเมินสภาวะทางสติปัญญา (Cognitive Status) และความเสื่อมถอยของผู้ป่วยได้อย่างมีหลักฐานอ้างอิง  

---

## ✅ Acceptance Criteria
1. [x] **ความแม่นยำ (Accuracy)**: คำนวณอัตราส่วนการตอบถูกเฉลี่ย (Correct Answers / Total Attempts) เป็นเปอร์เซ็นต์ในแต่ละรอบเกม  
2. [x] **เวลาตอบสนอง (Reaction Time)**: บันทึกเวลาที่ใช้ตอบสนองของแต่ละการคลิก (หน่วยเป็นมิลลิวินาที นับตั้งแต่แสดงสิ่งเร้าจนถึงผู้เล่นกดตัวเลือก) และคำนวณหาค่าเฉลี่ย (Average Reaction Time)  
3. [x] **ความผันผวนของความเร็ว (Reaction Time Variability)**: คำนวณค่าเบี่ยงเบนมาตรฐาน (Standard Deviation) หรือความแกว่งของเวลาการตอบในแต่ละด่านย่อย เพื่อประเมินความสม่ำเสมอในการคิด  
4. [x] **ดัชนีความล้า (Fatigue Effect)**: ประเมินเปรียบเทียบเวลาตอบสนองในช่วงครึ่งแรกของมินิเกม กับครึ่งหลังของมินิเกม (หากครึ่งหลังผู้เล่นตอบสนองช้าลงอย่างมีนัยสำคัญ จะถือว่ามีดัชนีความล้าสูง)  
5. [x] **อัตราการเดา (Guessing Rate)**: คำนวณสัดส่วนของการกดตอบที่เร็วเกินจริงผิดธรรมชาติ (เช่น ต่ำกว่า 300ms) ซึ่งชี้ให้เห็นว่าผู้ป่วยกดสุ่มเลือกโดยไม่ได้อ่านโจทย์  
6. [x] **โครงสร้างฐานข้อมูล (Supabase Integration)**: ข้อมูลทั้งหมดต้องถูกบันทึกสำเร็จลงในตาราง `user_performance_insights` ทันทีหลังจบมินิเกมแต่ละด่าน  

---

## 🛠 Technical Tasks
- [x] ออกแบบและสร้าง Table `user_performance_insights` ในฐานข้อมูล Supabase พร้อมตั้งค่าความสัมพันธ์ (Foreign Key) ไปยัง `user_patient_data` และเปิดใช้งาน Row Level Security (RLS)
- [x] พัฒนากลไกการคำนวณสถิติในระดับ Client (Client-Side Analytics Processor) เพื่อวัดค่าเฉลี่ย, ส่วนเบี่ยงเบนมาตรฐาน และดัชนีความล้าจากการเล่น
- [x] เพิ่มฟังก์ชัน `savePerformanceInsights(data)` ใน `src/core/database.js` เพื่อส่งผลการวิเคราะห์ไปยัง Supabase
- [x] นำระบบวิเคราะห์เวลาไปติดตั้งในมินิเกมต่างๆ (เช่น Zoo Detective, Zoo Feeder, Context Clues, Symmetry Decor, Postcard Reader)
- [x] ทำการทดสอบส่งข้อมูลเชิงวิเคราะห์และตรวจสอบความถูกต้องของโครงสร้าง JSON ในฐานข้อมูล
