# User Story: US-E9-06 - ป้องกันหน้าจอดับระหว่างเล่นเกม (Screen Wake Lock)

**Status:** 📋 Backlog
**Epic:** [E9: Field Feedback Hotfixes](../01-product-backlog.md)

**Source:** [Field Feedback — ลงพื้นที่ (2026-07-10)](../meeting-backlogs/2026-07-10.md) §2.7
**Priority:** 🔴 P0 — แก้ด่วน
**Target version:** `1.1.1` (PATCH)

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้หน้าจอไม่ดับระหว่างเล่นเกม แม้เครื่องจะตั้งค่าพักหน้าจอไว้สั้น
**เพื่อให้** เล่นเกมต่อเนื่องได้โดยไม่ต้องปลุกหน้าจอซ้ำ ๆ

---

## 🐛 Problem (จากการลงพื้นที่ — v1.0.0)
- บางเครื่องตั้งค่า **พักหน้าจอ (screen timeout) น้อย**
- ระหว่างเล่นเกม **หน้าจอดับ** ทำให้ขาดจังหวะและสับสน

---

## ✅ Acceptance Criteria
1. [ ] ระหว่างเล่น **มินิเกม** (Phaser scene active) หน้าจอ **ไม่ดับ** ตาม timeout ปกติของระบบ
2. [ ] ระหว่างดู **วิดีโอละครสั้น** / check-in video หน้าจอไม่ดับ (ถ้า browser รองรับ)
3. [ ] เมื่อออกจากมินิเกมกลับ Game Hub / DOM screen → **ปล่อย wake lock** (ไม่กินแบตเตอรี่ตลอดเวลา)
4. [ ] ถ้า browser/OS **ไม่รองรับ** Screen Wake Lock API → degrade gracefully (ไม่ error, อาจแสดงคำแนะนำสั้น ๆ ให้ตั้ง timeout นานขึ้น)
5. [ ] ทดสอบบน Android จริง (รวมเครื่องที่ตั้ง timeout สั้น)

---

## 🛠 Technical Tasks
- [ ] ใช้ [Screen Wake Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API) — acquire ตอนเข้ามินิเกม / video, release ตอนออก
- [ ] สร้าง helper (เช่น `src/core/wake-lock-manager.js`) — reuse ข้ามมินิเกม
- [ ] ผูก lifecycle กับ minigame entry/exit และ VideoPlayer
- [ ] Handle `visibilitychange` (tab switch) — re-acquire ถ้าจำเป็น
- [ ] ทดสอบบนมือถือจริง
