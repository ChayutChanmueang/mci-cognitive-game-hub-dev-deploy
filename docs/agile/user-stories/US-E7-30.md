## 📖 Description
**ในฐานะ** ผู้ดูแลระบบที่ใช้หน้าข้อมูลผู้เล่น (Player-Info)
**ฉันต้องการ** ให้ Popup เลือกส่งออกข้อมูล CSV ใช้ art assets ชุดเดียวกับ popup อื่นในเกม
**เพื่อให้** UI สอดคล้องเป็นมาตรฐานเดียวกันทั้งแอป (Frame_Form_Panel + ปุ่มมาตรฐานเขียว/แดง)

## 🔀 Decisions
- **วงกลมหน้าตาเหมือนกันทั้งสองกลุ่ม แต่ความหมายต่างกัน** ตาม mockup ที่ owner ให้ — `ข้อมูลของ` เป็น
  radio (เลือกได้อย่างเดียว) ส่วน `ประเภทข้อมูล` เป็น checkbox (เลือกได้หลายอย่าง) ความต่างถูกสื่อผ่าน
  `<input type>` จริง คีย์บอร์ดกับ screen reader จึงยังบอกได้ถูก แม้ภาพจะไม่ต่าง
  ⚠️ ถ้าภายหลังพบว่าผู้ใช้สับสน ให้แยกรูปวงกลมของ radio ออกจาก checkbox
- **ปุ่มยืนยันถูก disable เมื่อไม่ได้ติ๊กประเภทข้อมูลเลย** (ของเดิมกดได้ แล้วได้ไฟล์เปล่า)
