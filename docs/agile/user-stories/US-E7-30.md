## 📖 Description
**ในฐานะ** ผู้ดูแลระบบที่ใช้หน้าข้อมูลผู้เล่น (Player-Info)
**ฉันต้องการ** ให้ Popup เลือกส่งออกข้อมูล CSV ใช้ art assets ชุดเดียวกับ popup อื่นในเกม
**เพื่อให้** UI สอดคล้องเป็นมาตรฐานเดียวกันทั้งแอป (Frame_Form_Panel + ปุ่มมาตรฐานเขียว/แดง)

---

## ✅ Acceptance Criteria
1. [ ] Popup export CSV (`player-info-export-popup`) เปลี่ยนมาใช้ art ชุด popup-dialog (Frame_Form_Panel + ปุ่มมาตรฐาน) แทนสไตล์ generic เดิม
2. [ ] ฟังก์ชันเดิมครบ: สวิตช์ขอบเขต (ผู้เล่นคนนี้/ทุกคน) + checkbox เลือกประเภทข้อมูล (Player/Game/History) ยังใช้งานได้เหมือนเดิม
3. [ ] ปุ่มยืนยัน/ยกเลิกตามระบบสีมาตรฐาน (เขียว=ยืนยัน, แดง=ยกเลิก — [US-E7-15](US-E7-15.md))
4. [ ] ทรานสิชั่น popup fade+scale ตามระบบ [US-E7-20](US-E7-20.md)
5. [ ] Layout ไม่แตกบนมือถือจอเล็ก (แนวตั้ง) และ scroll ภายใน popup ได้ถ้าเนื้อหาสูงเกิน
6. [ ] A11y เดิมคงอยู่ (aria labels, focus, ปิดด้วยปุ่มยกเลิก)

---

## 🛠 Technical Tasks
- [ ] แยก/ปรับ markup popup export ใน `src/ui/player-info-screen.js` ให้ใช้โครง `popup-dialog.js` (แนวเดียวกับ [US-E9-12](US-E9-12.md) ที่รวม game-exit popup เข้า `renderConfirmDialog`)
- [ ] ตรวจว่า `renderConfirmDialog` รองรับ custom body content (switch + checkboxes) หรือเพิ่ม variant ใหม่
- [ ] ปรับ CSS `player-info-export-popup__*` ให้เข้ากับ `gh-popup--<variant>` system ([US-E7-25](US-E7-25.md)/0.26.1)
- [ ] ใช้ art assets: Frame_Form_Panel + Button_OK/Close (ชุดเดียวกับ [US-E7-04](US-E7-04.md))
- [ ] ทดสอบ export ทุก scope/type หลังเปลี่ยน UI ว่ายังทำงานครบ (US-E9-05 regression)
