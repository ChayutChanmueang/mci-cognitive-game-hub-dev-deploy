## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** การยืนยันเมื่อฉันเล่นจบโปรแกรมของวันนั้นๆ
**เพื่อให้** ฉันรู้ว่าภารกิจประจำวันเสร็จสิ้นแล้วและได้รับการเช็คชื่อเข้าระบบ

## ✅ Acceptance Criteria
1. [ ] ด่านเส้นชัยจะปรากฏหลังจากเล่นครบ 10 เกม และ 1 จุดพัก
2. [ ] แสดงหน้าจอ "ยินดีด้วย!" เมื่อผู้เล่นเข้าสู่ด่านเส้นชัย
3. [ ] ระบบจะทำการ "เช็คอิน" (US-E2-04) ให้โดยอัตโนมัติเมื่อมาถึงหน้านี้
4. [ ] แสดงผลสรุปความคืบหน้าประจำวันและเป้าหมายของวันถัดไป
5. [ ] มีปุ่มสำหรับกลับสู่หน้า Gamehub
