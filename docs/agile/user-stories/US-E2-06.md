# User Story: US-E2-06 - ด่านเส้นชัย (Finish Level)

**Status:** ✅ Done
**Epic:** [E2: Core Gamehub & Progression System](../01-product-backlog.md)
**Owner:** [Team Game / Team Web]

---

## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** การยืนยันเมื่อฉันเล่นจบโปรแกรมของวันนั้นๆ
**เพื่อให้** ฉันรู้ว่าภารกิจประจำวันเสร็จสิ้นแล้วและได้รับการเช็คชื่อเข้าระบบ

---

## ✅ Acceptance Criteria
1. [x] ปุ่ม "เช็คชื่อประจำวัน" (Finish/Check-in) จะปลดล็อคให้ใช้งานได้หลังจากผู้เล่นทำภารกิจหลักครบ 10 มินิเกมย่อยและ 1 จุดพักผ่อนยืดเหยียดของวันนั้น
2. [x] แสดงหน้าต่างยืนยันความสำเร็จ ("ยินดีด้วย!") เมื่อผู้เล่นทำการกดปุ่มเช็คชื่อเสร็จสิ้น
3. [x] ระบบจะส่งข้อมูลการบันทึกสถานะการทำภารกิจเสร็จสิ้น (เช็คอิน) ไปยังฐานข้อมูล Supabase เมื่อผู้ใช้กดยืนยันความสำเร็จ
4. [x] แสดงหน้าจอแจ้งเตือนเช็คอินสำเร็จ พร้อมปิดหน้าต่างและอัปเดตสถานะความคืบหน้าของหน้าหลัก
5. [x] ล็อคระบบการเข้าเล่นมินิเกมของวันนั้นเพื่อป้องกันการป้อนสถิติซ้ำซ้อน และแสดงสถานะรอทำภารกิจใหม่ในวันถัดไป

---

## 🛠 Technical Tasks
- [x] พัฒนาฟังก์ชันแสดงหน้าจอยืนยันการเช็คชื่อประจำวัน (Check-in Confirmation Popup / Dialog) ในหน้า Hub
- [x] เชื่อมต่อและทดสอบฟังก์ชัน `submitCheckIn` เพื่อยิงข้อมูลเข้าสู่ตารางประวัติ Supabase
- [x] รีเฟรชสถานะใน Game Hub แบบ reactive เมื่อการทำเช็คอินเสร็จสมบูรณ์

---

## 📝 Implementation Details
- ฟังก์ชันนี้ถูกรวมเข้าเป็นส่วนหนึ่งของระบบตรวจสอบสิทธิ์ของหน้าหลักใน `src/ui/game-hub-screen.js` โดยเชื่อมต่อผ่านปุ่ม Check-in สีเขียวขนาดใหญ่ที่ตำแหน่งท้ายรายการประจำวัน
- เมื่อกดยืนยัน ปุ่มจะเรียกฟังก์ชัน `submitCheckIn` ของ API ฐานข้อมูล เพื่อแทรก record พิเศษที่มีค่าฟิลด์ `check-in: true` และ `gid: null` (หรือเป็นค่าเฉพาะของด่านตรวจสอบ)
- เมื่อบันทึกสำเร็จ ตัวหน้าจอจะรีเฟรชข้อมูล ทำให้แถบสถานะการผ่านด่านด้านบนอัปเดตดาวดวงใหม่ทันที พร้อมทั้งแสดงกล่องข้อความสำเร็จและล็อกรายการเล่นของวันนั้น
