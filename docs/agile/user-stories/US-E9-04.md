## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ตัวอักษรโจทย์ในเกมจดหมายจากหลานรัก (Postcard Reader) **ใหญ่ขึ้นอีก**
**เพื่อให้** อ่านเนื้อหาจดหมายได้สบายตา โดยเฉพาะเมื่อตั้งใจอ่านโจทย์ก่อนตอบ

---

## 🐛 Problem (จากการลงพื้นที่ — v1.0.0 / v0.30.0)
- [US-E7-09](US-E7-09.md) ขยายฟอนต์โจทย์แล้ว แต่จากการลงพื้นที่จริง ผู้สูงอายุยังรู้สึกว่า **ตัวหนังสือเล็ก**
- ผู้สูงอายุ **ตั้งใจอ่านโจทย์มาก** — readability เป็นจุดสำคัญ

---

## ✅ Acceptance Criteria
1. [ ] ขนาดตัวอักษร **โจทย์/เนื้อหาจดหมาย** ใหญ่ขึ้นอีกจากค่าปัจจุบัน (หลัง US-E7-09) — อ้างอิง [UX/UI Guidelines](../../wiki/guidelines/ux-ui-guidelines.md)
2. [ ] ข้อความยัง **อ่านได้ครบ** บนหน้าจอมือถือทั่วไป (ไม่ล้นจนอ่านไม่ได้ — ปรับ line-height / scroll ถ้าจำเป็น)
3. [ ] Contrast ระหว่างตัวอักษรกับพื้นหลัง **เพียงพอ** สำหรับผู้สูงอายุ
4. [ ] ตัวเลือกคำตอบยังใช้งานได้ปกติ — ไม่ถูกบังโดยข้อความที่ขยาย
5. [ ] ทดสอบบนมือถือจริงกับผู้สูงอายุ — owner ยืนยัน
