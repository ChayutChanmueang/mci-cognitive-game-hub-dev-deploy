# User Story: US-E7-29 - ปิดปุ่มเริ่มเกมบน Game Hub ก่อนถึงวันเริ่มโปรแกรม

**Status:** ✅ Done (2026-07-07)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** ก้องไผ่
**Source:** Owner request (2026-07-07)

---

## 📖 Description
**ในฐานะ** ผู้ดูแลโปรแกรม / ผู้เล่นที่ลงทะเบียนแล้วแต่ยังไม่ถึงวันเริ่มโปรแกรม
**ฉันต้องการ** ให้หน้า **Game Hub ไม่แสดงปุ่ม "เริ่มเกม"** และไม่ให้เริ่มเล่นมินิเกมได้ **ก่อนถึงวันที่เริ่มโปรแกรม** (`started_program`)
**เพื่อให้** ผู้เล่นไม่สามารถเล่นเกมล่วงหน้าก่อนวันที่กำหนด และ UI สะท้อนสถานะ "ยังไม่ถึงวันที่ต้องเล่น" อย่างชัดเจน

---

## 🐛 Problem (ปัจจุบัน)
- ผู้เล่นสามารถ **เข้า Game Hub และกดเริ่มเกมได้** แม้วันที่ปัจจุบันยัง **ก่อน** `started_program` (วันเริ่มโปรแกรมที่ตั้งตอน Sign-up / ใน DB)
- Node บน level path ยังอาจอยู่ใน state **`current`** พร้อม lesson card + ปุ่มเริ่มเกม ทั้งที่โปรแกรมยังไม่เริ่ม
- ระบบมี `programStarted` ใน `getProgramDayStatus()` แล้ว แต่ **Game Hub ยังไม่ได้ใช้** เพื่อบล็อก UI/การเล่น

---

## ✅ Acceptance Criteria
1. [x] เมื่อ **วันนี้ < วันเริ่มโปรแกรม** (`programStarted === false` จาก `getProgramDayStatus(startedProgram, programDayCount)`) หน้า Game Hub **ไม่แสดงปุ่ม "เริ่มเกม"** บน lesson card ของ node ใด ๆ
2. [x] Node ที่เกี่ยวข้องแสดงเป็น state **"ยังไม่ถึงวันที่ต้องเล่น"** — ไม่ใช่ `current` ที่มีปุ่มเริ่มเกม (ใช้ `next` + `disabled` โดยไม่ตั้ง node ใดเป็น `current` จึงไม่มี lesson card/ปุ่ม)
3. [x] ผู้เล่น **ไม่สามารถ launch มินิเกม** จาก Game Hub ได้ก่อนถึงวันเริ่มโปรแกรม (guard ที่ handler `handleNodeAction` เป็น safety net แม้ UI ซ่อนปุ่มแล้ว)
4. [x] เมื่อ **ถึงหรือเลยวันเริ่มโปรแกรม** พฤติกรรมกลับมาเหมือนเดิม: node วันปัจจุบันเป็น `current` + แสดงปุ่มเริ่มเกมตาม flow ปกติ (ไม่กระทบ [US-E2-02](archives/US-E2-02.md) การล็อควันถัดไป)
5. [x] แสดงข้อความบอกผู้เล่นว่า **โปรแกรมเริ่มวันที่ …** (ใช้ `formatThaiProgramDate(startedProgram)`) ผ่าน `sideLabel` ของ node วันปัจจุบัน
6. [x] ทดสอบบนมือถือจริง: สร้าง/ใช้บัญชีที่ `started_program` เป็นวันในอนาคต → ไม่มีปุ่มเริ่มเกม + ไม่เข้าเกมได้; เปลี่ยนเป็นวันนี้หรืออดีต → เล่นได้ตามปกติ

---

## 🛠 Technical Tasks
- [x] ใน `buildLevelSections()` (`src/ui/game-hub-screen.js`) อ่าน `programStarted` จาก `getProgramDayStatus(getStartedProgram(), getProgramDayCount())` (field มีอยู่แล้วใน `src/util/program-date-util.js` และ `database.getDailyProgram()`)
- [x] เมื่อ `!programStarted`: ไม่ตั้ง node ใดเป็น `current` (`isActiveCurrent = isCurrent && !isProgramEnded && isProgramStarted`) → ทุก node เป็น `next`, `renderSide` ใน `level-path.js` แสดง label แทน lesson card จึงไม่มีปุ่ม
- [x] node side content: node วันปัจจุบันแสดง `sideLabel` = "โปรแกรมเริ่มวันที่ …" (ไม่มีปุ่ม) + ตั้ง `disabled` เมื่อยังไม่เริ่ม
- [x] Guard `handleNodeAction` ใน `game-hub-screen.js` ให้ reject การ launch เมื่อ `!programStarted` (เป็น launch site เดียวของ `onLaunchGame`)
- [x] reuse state `next` เดิม (ไม่ต้องเพิ่ม state `upcoming` / art ใหม่)
- [x] ทดสอบ edge case: `started_program` วันนี้ (เล่นได้), วันพรุ่งนี้ (เล่นไม่ได้), โปรแกรมจบแล้ว (ยังใช้ flow `programEnded` เดิม) — ตรวจผ่าน `getProgramDayStatus` + build
