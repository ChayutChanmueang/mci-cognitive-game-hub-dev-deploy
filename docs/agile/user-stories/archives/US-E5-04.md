# User Story: US-E5-04 - เครื่องมือจัดการตารางเล่นรายวัน (Daily Preset Editor)

**Status:** ✅ Done (Implemented and tested)
**Epic:** [E5: Admin & Data Management](../../01-product-backlog.md)
**Owner:** TBD

---

## 📖 Description
**ในฐานะ** แอดมิน/นักวิจัย
**ฉันต้องการ** หน้าจอจัดการกำหนดการเล่นเกม (Preset) ในแต่ละวันสำหรับโปรแกรม 14 วันได้โดยตรงผ่านเว็บแอปพลิเคชัน
**เพื่อให้** สะดวกและรวดเร็วในการปรับเปลี่ยนระดับความยาก หรือเปลี่ยนชนิดเกมโดยไม่ต้องเข้าไปดำเนินการแก้ไขข้อมูลลงฐานข้อมูลโดยตรง

---

## ✅ Acceptance Criteria
1. [x] พัฒนารูปแบบหน้าตารางจัดการด่านรายวันแบบ Interactive (เพิ่ม/ลด/แก้ไขวัน และชนิดของด่านย่อย)
2. [x] หน้าต่างเครื่องมือสนับสนุนการอัปโหลดไฟล์ด่านออฟไลน์ด้วยไฟล์ CSV (CSV Upload/Import)
3. [x] ตรวจสอบสิทธิ์ความถูกต้องของรูปแบบไฟล์และประเภทของด่านก่อนจะสั่งแก้ไขลงตารางใน Database
4. [x] ป้องกันไม่ให้แอดมินลบหรือแก้ไขคีย์ที่สำคัญหากด่านนั้นกำลังถูกเปิดใช้งานโดยคนไข้อยู่ในขณะนั้น

- [x] เขียนตรรกะการแปลงไฟล์ CSV (CSV Parsing) เพื่อนำเข้าข้อมูลแบบกลุ่ม
