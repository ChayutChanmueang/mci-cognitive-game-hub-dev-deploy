# User Story: US-E3-02 - ระบบ Voice Over คำแนะนำการเล่นเกม

**Status:** ✅ Done (Implemented project-wide voice-service)
**Epic:** [E3: Accessibility & UX](../../01-product-backlog.md)
**Owner:** -

---

## 📖 Description
**ในฐานะ** ผู้ป่วยภาวะสมองเสื่อมระยะเริ่มต้น (MCI)
**ฉันต้องการ** ให้มีเสียงบรรยาย (Voice Over) แนะนำวิธีการเล่นในแต่ละเกม
**เพื่อให้** ฉันเข้าใจกติกาการเล่นได้ง่ายขึ้น แม้ในกรณีที่การอ่านข้อความบนหน้าจอเป็นเรื่องยาก

---

## ✅ Acceptance Criteria
1. [x] ระบบต้องสามารถเล่นไฟล์เสียงคำแนะนำได้โดยอัตโนมัติเมื่อเริ่มเกมหรือเข้าสู่ขั้นตอนใหม่
2. [x] มีปุ่มสำหรับกดเพื่อ "ฟังซ้ำ" (Replay Audio) คำแนะนำ
3. [x] เสียงบรรยายต้องเป็นภาษาไทยที่ชัดเจน และมีความเร็วที่เหมาะสมสำหรับผู้สูงอายุ
4. [x] ระบบต้องรองรับการเปิด/ปิดเสียง (Mute/Unmute) ในการตั้งค่า

---

## 🛠 Technical Tasks
- [x] เตรียมไฟล์เสียงคำแนะนำ (Voice assets) สำหรับแต่ละเกม
- [x] พัฒนา Audio Service สำหรับจัดการการเล่นเสียงภายในเกม
- [x] บูรณาการ Audio Service เข้ากับหน้าจอหลักของแต่ละมินิเกม
