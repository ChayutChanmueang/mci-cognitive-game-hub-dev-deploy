# User Story: US-E5-02 - ระบบส่งออกข้อมูลเป็นไฟล์ CSV

**Status:** ✅ Done (Implemented and tested in Sprint 6)  
**Epic:** [E5: Admin & Data Management](../01-product-backlog.md)  
**Owner:** [Developer/AI]  

---

## 📖 Description
**ในฐานะ** แพทย์, นักวิจัย หรือผู้ดูแลระบบ  
**ฉันต้องการ** ส่งออกข้อมูลประวัติการเล่นและข้อมูลประสิทธิภาพเชิงลึกของผู้ป่วยที่เลือกมาเป็นไฟล์รูปแบบ CSV  
**เพื่อให้** ฉันสามารถนำไฟล์ไปเปิดวิเคราะห์และประมวลผลต่อด้วยโปรแกรมภายนอก เช่น Microsoft Excel, SPSS หรือภาษา Python ได้อย่างสะดวก  

---

## ✅ Acceptance Criteria
1. [x] **ปุ่มส่งออกข้อมูล (Export Button)**: มีปุ่ม "ส่งออกข้อมูลเป็น CSV" ปรากฏเด่นชัดในส่วนจัดการข้อมูลผู้ป่วยของ Admin Dashboard  
2. [x] **การจัดเตรียมข้อมูล (Data Fetching)**: เมื่อกดปุ่ม ระบบต้องรวบรวมข้อมูลจาก 3 แหล่ง:
   - ข้อมูลผู้ป่วย (HN, ชื่อ, เพศ, อายุ, การศึกษา)
   - ประวัติการเข้าเล่นมินิเกมทั้งหมด (Score, Date, Game ID, Difficulty, Time Spent)
   - ข้อมูลเชิงลึกประสิทธิภาพ (Accuracy, Average RT, SD RT, Fatigue Index, Guessing Rate)
3. [x] **โครงสร้างไฟล์ CSV**: รูปแบบข้อมูลต้องเป็นตารางที่มีส่วนหัวคอลัมน์ (Headers) ชัดเจน และคั่นด้วยเครื่องหมายจุลภาค (Comma)  
4. [x] **รองรับภาษาไทย (Thai Language Support)**: ตัวไฟล์ต้องเข้ารหัสในรูปแบบ UTF-8 พร้อม BOM (Byte Order Mark) เพื่อให้เปิดด้วย Microsoft Excel บนระบบปฏิบัติการ Windows แล้วไม่แสดงผลเป็นอักษรต่างดาว  
5. [x] **การดาวน์โหลดไฟล์**: เมื่อประมวลผลเสร็จสิ้น ระบบต้องเริ่มขั้นตอนการดาวน์โหลดไฟล์ CSV สู่เครื่องคอมพิวเตอร์ของผู้ใช้อัตโนมัติทันที  

---

## 🛠 Technical Tasks
- [x] พัฒนาฟังก์ชันแปลงอาเรย์ JSON เป็นรูปแบบสตริง CSV (JSON-to-CSV Converter) ในระบบ Utility
- [x] ใส่รหัส UTF-8 BOM (`\ufeff`) นำหน้าสตริงก่อนส่งออกไฟล์เพื่อแก้ไขปัญหาฟอนต์ภาษาไทยบน Excel
- [x] เขียน API/Query เชื่อมฐานข้อมูล Supabase เพื่อ Join ตารางข้อมูลผู้ป่วย ตารางล็อกเกม และตารางข้อมูลเชิงลึกเข้าด้วยกัน
- [x] เชื่อมต่อปุ่มกด UI ในหน้า `AdminDashboardPanel` เข้ากับกระบวนการดึงข้อมูลและดาวน์โหลด
- [x] ทดสอบความถูกต้องของคอลัมน์ข้อมูล (Data Validation) เมื่อนำไปเปิดบน Microsoft Excel หรือโปรแกรมวิเคราะห์ข้อมูลอื่นๆ
