## 📖 Description
**ในฐานะ** ผู้เล่น/ผู้ป่วยภาวะสมองเสื่อมระยะเริ่มต้น (MCI)
**ฉันต้องการ** เล่นมินิเกมทำอาหาร (ทอดอาหาร) โดยใช้การเอียงหน้าจอ (Tilt Control)
**เพื่อให้** ฝึกการประสานงานของประสาทและกล้ามเนื้อข้อมือ (Motor Coordination) และเพิ่มความหลากหลายในการเล่นเกมฝึกสมอง
