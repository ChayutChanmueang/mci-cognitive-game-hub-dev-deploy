# User Story: US-E3-08 - ระบบติดตั้งแอปพลิเคชันแบบ Progressive Web App (PWA)

**Status:** ✅ Done (Implemented and tested)
**Epic:** [E3: Cognitive Games Implementation](../../01-product-backlog.md)
**Owner:** TBD

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ/ผู้ป่วยภาวะสมองเสื่อม
**ฉันต้องการ** ให้แอปพลิเคชันรองรับการติดตั้งลงบนหน้าจอมือถือโดยตรงเป็น PWA (Progressive Web App)
**เพื่อให้** สามารถกดเข้าเล่นเกมได้ง่ายขึ้นในครั้งต่อไปโดยไม่ต้องเปิดผ่านเว็บเบราว์เซอร์และพิมพ์ URL ใหม่ทุกครั้ง

---

## ✅ Acceptance Criteria
1. [x] แอปพลิเคชันมีปุ่มหรือป็อปอัปแจ้งติดตั้งเมื่อเปิดใช้งานในสมาร์ทโฟน/แท็บเล็ต
2. [x] มีการตั้งค่าไฟล์ Service Worker และ Web Manifest พร้อมรูปภาพ App Icon ที่ถูกต้อง
3. [x] แอปพลิเคชันสามารถแสดงผลแบบ Fullscreen เสมือน Native App เมื่อเปิดจากการติดตั้งบนหน้าจอหลัก

---

## 🛠 Technical Tasks
- [x] จัดทำโครงร่างไฟล์ `manifest.json` เพื่อกําหนดรูปไอคอน ธีมสี และลักษณะการแสดงผล
- [x] เขียนโปรแกรม Service Worker ในการจัดการแคชไฟล์เบื้องต้นเพื่อประสิทธิภาพการเปิดแอป
- [x] บูรณาการ PWA configuration เข้ากับ Vite Bundler (`vite.config.js` / plugin)
- [x] ทดสอบพฤติกรรมการติดตั้งแอปบนระบบปฏิบัติการ iOS (Safari) และ Android (Chrome)
