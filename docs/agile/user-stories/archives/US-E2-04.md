# User Story: US-E2-04 - ระบบ Daily Streak (เป้าหมายของฉัน)

**Status:** ✅ Done
**Epic:** [E2: Core Gamehub & Progression System](../01-product-backlog.md)
**Owner:** [Team Game / Team Web]

---

## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** เห็นจำนวนวันที่ฉันเล่นต่อเนื่องกัน
**เพื่อให้** ฉันรู้สึกภูมิใจและอยากทำตามเป้าหมาย 14 วันให้สำเร็จ

---

## ✅ Acceptance Criteria
1. [x] แสดงจำนวน "วันที่เข้าเรียนสะสม" และจำนวนดาว/สถานะเช็คอินจากทั้งหมด 14 วัน ในแถบสถิติส่วนบน (Header/HUD) หน้า Gamehub
2. [x] วันที่เช็คอินจะเพิ่มขึ้นเมื่อผู้เล่นเล่นมินิเกมครบตามเป้าหมายของวันนั้นๆ และกดปุ่มเช็คชื่อเสร็จสิ้น (เช็คอิน)
3. [x] หากเล่นไม่จบด่านของวันนั้นและยังไม่ได้กดยืนยันเช็คชื่อ ระบบจะไม่นับประวัติการเช็คอินในวันดังกล่าว
4. [x] แสดงภาพสัญลักษณ์ดวงดาวหรือเครื่องหมายอย่างชัดเจนเข้าใจง่ายสำหรับผู้สูงอายุ

---

## 🛠 Technical Tasks
- [x] พัฒนา Logic การนับจำนวนวันเช็คอินสะสมหลังกดยืนยันเช็คชื่อในหน้าสรุปของวัน
- [x] ปรับปรุงระบบประวัติการเล่นและจัดเก็บสถานะ `check-in` ลงในตาราง `user_game_history` ของ Supabase
- [x] ออกแบบและพัฒนา UI แดชบอร์ดสรุปสถิติผู้ป่วยที่ส่วนบนของหน้า Hub

---

## 📝 Implementation Details
- ในหน้าจอ `src/ui/game-hub-screen.js` แถบข้อมูลด้านบน (Dashboard Header) จะดึงประวัติเช็คอินที่เสร็จสิ้นจากฐานข้อมูลมาแสดงในรูปแบบ "เช็คชื่อแล้ว X / 14 วัน" และมีตัวบ่งชี้ความคืบหน้าแบบวงกลมหรือไอคอนความสำเร็จ
- การเช็คอินที่เสร็จสิ้นจะทำผ่านกลไก `submitCheckIn` เพื่อแทรกข้อมูลการบันทึกสถานะ `check-in: true` ลงตาราง `user_game_history` ในฐานข้อมูล Supabase
