# User Story: US-E5-05 - เครื่องมือทดสอบเกมสแตนด์อโลน (Test Game Hub & Video Player)

**Status:** ✅ Done (Implemented and tested)
**Epic:** [E5: Admin & Data Management](../../01-product-backlog.md)
**Owner:** TBD

---

## 📖 Description
**ในฐานะ** ผู้พัฒนาและนักทดสอบระบบ (QA)
**ฉันต้องการ** ศูนย์กลางเปิดเล่นเกมเพื่อทดสอบโดยเฉพาะ (Test Game Hub) ที่สามารถเลือกเล่นด่านใดก็ได้โดยอิสระ
**เพื่อให้** สะดวกในการควบคุมตัวแปรเพื่อทดสอบบั๊กและโฟลว์การทำงาน รวมถึงสามารถเปิดเล่นวิดีโอแนะนำการเล่นจำลองได้

---

## ✅ Acceptance Criteria
1. [x] พัฒนาอินเทอร์เฟซแยกสำหรับ Test Game Hub ให้ผู้ทดสอบเข้าถึงได้
2. [x] แสดงรายชื่อเกมและด่านย่อยทั้งหมดพร้อมสวิตช์เลือกว่าจะ "บันทึกประวัติ" หรือ "ไม่บันทึกประวัติการเล่น" (Launch Mode)
3. [x] รักษาสถานะตำแหน่งสกอลของกลุ่มเกมเมื่อผู้ทดสอบกดกลับมาจากหน้าจบเกม (Scroll State Retention)
4. [x] มีวิดีโอแนะนำวิธีการเล่นจำลอง (Floating Video FAB) ที่กดเปิดเล่นหรือพับหน้าจอได้จากหน้านี้
