# User Story: US-E7-15 - ระบบสีปุ่มมาตรฐาน (เขียว = ยืนยัน, แดง = ยกเลิก)

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้สีปุ่มสื่อความหมายชัดเจนและสม่ำเสมอทั้งแอป
**เพื่อให้** เข้าใจได้ทันทีว่าปุ่มไหนคือยืนยัน/ไปต่อ และปุ่มไหนคือยกเลิก

---

## ✅ Acceptance Criteria
1. [ ] **ปุ่มเขียว** ใช้สำหรับการกระทำเชิงบวก: **"เริ่มเกม", "ตกลง", "ต่อไป"**
2. [ ] **ปุ่มแดง** ใช้สำหรับการกระทำเชิงยกเลิก/ลบ: **"ยกเลิก"** (และการกระทำทำลายอื่น ๆ)
3. [ ] ใช้สีตามมาตรฐานนี้สม่ำเสมอทุกหน้าจอและทุก Popup
4. [ ] สีปุ่มมี contrast เพียงพอและเข้าถึงง่ายสำหรับผู้สูงอายุ

---

## 🛠 Technical Tasks
- [ ] กำหนด token/utility class สำหรับปุ่มเขียว/แดง (ดู theme tokens ที่มีอยู่)
- [ ] ไล่ปรับปุ่มในทุกหน้าจอและ Popup ให้ตรงตามมาตรฐาน
- [ ] ตรวจสอบ contrast/ขนาดปุ่มบนมือถือจริง
