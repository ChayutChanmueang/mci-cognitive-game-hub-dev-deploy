## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่ใช้มือถือสเปคต่ำ
**ฉันต้องการ** ให้เกมรันลื่นและเข้าเล่นได้บนเครื่องราคาประหยัด
**เพื่อให้** ไม่กระตุก ค้าง หรือเข้าเกมไม่ได้เพราะ Phaser/เอฟเฟคใช้ทรัพยากรมากเกินไป

---

## 🐛 Problem (จากการลงพื้นที่ — v1.0.0)
1. **เอฟเฟคหน้า "เก่งมาก!!!"** (confetti/celebration) ทำให้เครื่องสเปคต่ำ **กระตุกและค้าง**
2. **Phaser ใช้ประสิทธิภาพเครื่องเยอะเกินไป** — บางเครื่อง **เข้าเกมไม่ได้**
3. เครื่องอ้างอิงขั้นต่ำสุด: **Samsung Galaxy A10s** (Helio P22, 2–3 GB RAM, PowerVR GE8320, Android 9–11)

### 📱 Reference Device — Samsung Galaxy A10s (minimum optimization target)
| Spec | Value |
| --- | --- |
| Chipset | Mediatek MT6762 Helio P22 (12 nm) |
| CPU | Octa-core 2.0 GHz Cortex-A53 |
| GPU | PowerVR GE8320 |

## ✅ Acceptance Criteria

### A. เอฟเฟค "เก่งมาก!!!" (Celebration)
1. [ ] หน้า check-in success / "เก่งมาก!!!" **ไม่ทำให้เครื่องสเปคต่ำค้าง** บน Galaxy A10s (หรือ emulator ใกล้เคียง)
2. [ ] ลด/ปรับ celebration effect (particle count, animation complexity, duration) หรือ **ปิดเอฟเฟคหนัก** บน low-end profile
3. [ ] ยังคง feedback เชิงบวกให้ผู้เล่น (เสียง/ข้อความ/เอฟเฟคเบา) แม้ลด confetti

### B. Phaser / มินิเกม Performance
4. [ ] ผู้เล่นบน Galaxy A10s (หรือเครื่องเทียบเท่า) **เข้าและเล่นมินิเกมหลักได้** โดยไม่ crash / hang ตอนโหลด
5. [ ] ปรับ Phaser game config สำหรับ low-end: renderer, resolution scale, FPS cap, disable heavy features ตามความจำเป็น
6. [ ] พิจารณา **low-performance mode** (auto-detect หรือ fallback) — ลด particle, shader, concurrent tweens
7. [ ] Game Hub → เข้ามินิเกม → กลับ Hub ทำงานได้บน A10s

### C. การทดสอบ
8. [ ] มี checklist ทดสอบบน **Galaxy A10s จริง** (หรือ device lab ที่ owner กำหนด) ก่อน ship
9. [ ] ไม่กระทบประสบการณ์บนเครื่องสเปคสูง (high-end ยังได้เอฟเฟคเต็มหรือใกล้เดิม)
