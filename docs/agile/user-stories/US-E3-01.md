# User Story: US-E3-01 - ปรับแต่งขนาด Font และปุ่มสำหรับผู้สูงอายุ (Standard Accessibility)

**Status:** 🏗 In-Progress
**Epic:** [[E3: Accessibility & UX]]
**Owner:** -

---

## 📖 Description
**ในฐานะ** ผู้ป่วยภาวะสมองเสื่อมระยะเริ่มต้น (MCI)
**ฉันต้องการ** ให้มีขนาดตัวอักษรที่ใหญ่ขึ้นและปุ่มกดที่มีขนาดเหมาะสม
**เพื่อให้** ฉันสามารถอ่านเนื้อหาและเล่นเกมได้สะดวกโดยไม่ต้องเพ่งหรือกดผิดพลาดบ่อยครั้ง

---

## ✅ Acceptance Criteria
1. [ ] ขนาดตัวอักษรพื้นฐาน (Base Font) ต้องมีขนาดอย่างน้อย 20px
2. [ ] ปุ่มกดทุกประเภทต้องมีขนาดพื้นที่ (Touch Target) ขั้นต่ำ 48x48px
3. [ ] ค่า Contrast Ratio ของข้อความเทียบกับพื้นหลังต้องผ่านมาตรฐาน WCAG 2.1 ระดับ AA (อย่างน้อย 4.5:1)
4. [ ] การจัดวาง Layout ต้องไม่ล้นหน้าจอเมื่อปรับขนาด Font

---

## 🛠 Technical Tasks
- [ ] ออกแบบและกำหนด Design Tokens สำหรับ Typography และ Spacing ที่เป็น Accessibility-friendly
- [ ] ปรับปรุง CSS ของ Component ต่างๆ ให้รองรับ Responsive ขนาดใหญ่
- [ ] ตรวจสอบและแก้ไขพื้นที่ปุ่มใน UI ทุกหน้าจอ
