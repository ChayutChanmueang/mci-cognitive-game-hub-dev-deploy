# User Story: US-E7-24 - ย้ายชื่อเกม "ทอดอาหาร" (Fry Food) ขึ้นแทนหมวดหมู่ MCI + จัดเป็นหมวด Physical

**Status:** ✅ Done (v0.29.0, 2026-07-06 — verified by owner)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** ก้องไผ่
**Source:** Owner Task Block — ก้องไผ่ (2026-07-06), [Sprint 07](../sprint-backlogs/sprint-07.md)

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้การ์ดเกม "ทอดอาหาร" (Fry Food) ในหน้าหลัก (Game Hub) แสดง **ชื่อเกม** ขึ้นมาอยู่ในตำแหน่งที่เดิมเป็น **ชื่อหมวดหมู่ MCI/Cognitive** และให้เกมนี้ถูกจัดอยู่ในหมวดหมู่ **Physical** (แทน `Executive` เดิม) โดยหน้า Game Hub แสดงหมวดหมู่เป็น Physical
**เพื่อให้** ผู้เล่นเห็นชื่อเกมที่คุ้นเคยเด่นชัด ไม่สับสนกับชื่อหมวดหมู่ และหมวดหมู่ของเกมสะท้อนลักษณะจริงของเกม (ใช้การเคลื่อนไหว/accelerometer)

## ✅ Acceptance Criteria

### ส่วนที่ 1 — ย้ายชื่อเกมขึ้นแทนหมวดหมู่
1. [x] บนการ์ด/โหนดของเกม **ทอดอาหาร (Fry Food)** ในหน้าหลัก ชื่อเกมถูกย้ายขึ้นมาอยู่ในตำแหน่งที่เดิมแสดงหมวดหมู่ MCI
2. [x] เป็นไปในทิศทางเดียวกับการสลับ **ชื่อเกม ↔ หมวด Cognitive** ตาม [US-E7-14](US-E7-14.md) ข้อ 2 (ยึดรูปแบบเดียวกันทั้งหน้า)
3. [x] ชื่อเกมแสดงเป็นภาษาไทย ("ทอดอาหาร") สอดคล้องกับ [US-E7-07](US-E7-07.md) (`th_name`)
4. [x] เลย์เอาต์ของการ์ดไม่ล้น/ไม่เบียด และแสดงผลถูกต้องบนมือถือจริง — owner ยืนยันแล้ว

### ส่วนที่ 2 — จัดเกมเจียวไข่เป็นหมวด Physical (เพิ่ม 2026-07-06)
5. [x] เกม **เจียวไข่/ทอดอาหาร (Fry Food, `gid = PHY001`)** ถูกจัดอยู่ในหมวดหมู่ **`Physical`** แทน `Executive` เดิม
6. [x] หน้า Game Hub แสดง **ป้ายหมวดหมู่** ของเกมเจียวไข่เป็น **Physical** โดยเพิ่มหมวด `Physical` เข้า `CATEGORY_META` พร้อมชื่อไทยแล้ว
7. [x] ค่า `mci_group` ของเกมสอดคล้องกันทั้งฝั่งข้อมูล (DB `games.mci_group` ของ `PHY001`) และ fallback ในโค้ด (`DAILY_REQUIRED_GAME_FALLBACK.mci_group = "Physical"`) — ไม่มีที่ไหนยังเป็น `Executive`
8. [x] การเพิ่มหมวด Physical ไม่ทำให้หมวดอื่นหรือการ์ดเกมอื่นเพี้ยน และแสดงผลถูกต้องบนมือถือจริง — owner ยืนยันแล้ว
