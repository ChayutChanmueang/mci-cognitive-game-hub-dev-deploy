## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้การ์ดเกม "ทอดอาหาร" (Fry Food) ในหน้าหลัก (Game Hub) แสดง **ชื่อเกม** ขึ้นมาอยู่ในตำแหน่งที่เดิมเป็น **ชื่อหมวดหมู่ MCI/Cognitive**
**เพื่อให้** ผู้เล่นเห็นชื่อเกมที่คุ้นเคยเด่นชัด ไม่สับสนกับชื่อหมวดหมู่

## ✅ Acceptance Criteria
1. [ ] บนการ์ด/โหนดของเกม **ทอดอาหาร (Fry Food)** ในหน้าหลัก ชื่อเกมถูกย้ายขึ้นมาอยู่ในตำแหน่งที่เดิมแสดงหมวดหมู่ MCI
2. [ ] เป็นไปในทิศทางเดียวกับการสลับ **ชื่อเกม ↔ หมวด Cognitive** ตาม [US-E7-14](US-E7-14.md) ข้อ 2 (ยึดรูปแบบเดียวกันทั้งหน้า)
3. [ ] ชื่อเกมแสดงเป็นภาษาไทย ("ทอดอาหาร") สอดคล้องกับ [US-E7-07](US-E7-07.md) (`th_name`)
