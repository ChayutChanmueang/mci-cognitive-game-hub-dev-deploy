## 📖 Description
**ในฐานะ** ผู้เล่นที่เล่นต่อเนื่องหลายวัน
**ฉันต้องการ** ให้ต้นคิดดี (ต้นไม้ในระบบเช็คอิน) มีหลายรูปแบบและมีเอฟเฟคที่ดู "Juicy"
**เพื่อให้** รู้สึกสดใหม่ ไม่เบื่อ และได้รางวัลทางสายตาเมื่อก้าวหน้า

---

## ✅ Acceptance Criteria
1. [ ] ต้นคิดดีมี **หลายรูปแบบ** อย่างน้อยตามที่คุณหมอแนะนำ เช่น ต้นกุหลาบ, กล้วยไม้, ต้นไม้ดอกเยอะ, ต้นทุเรียน, ต้นไม้มีผล *(ยกออกจากขอบเขต Done — ติดตามเป็นงาน art ในภายหลัง)*
2. [x] เพิ่ม **เอฟเฟค Juicy** เมื่อต้นไม้เติบโต/เปลี่ยนสถานะ (อนิเมชัน growth transition + sparkle particle)
3. [x] **อนิเมชันต้นไม้โต (growth transition)** ตาม flow: แสดง **ต้นไม้สเตจก่อนหน้า** ก่อน → เด้ง **ขยายขึ้นเล็กน้อย** แล้ว **ยุบลง** (scale ลง) → แล้ว **เด้งขยายต้นใหม่ (สเตจถัดไป) ขึ้นมา** (scale จาก bottom center ให้ดูเหมือนโตขึ้นจากกระถาง)
4. [x] วันที่ 1 มีภาพสเตจเริ่มต้น (`tree_01`) อยู่แล้ว → `prevStage = getTreeStage(completedDays - 1)` มี "ต้นก่อนหน้า" ให้แสดงเสมอ ไม่ต้องจัดการเคสว่างเปล่า
5. [x] **Sparkle Particle Effect** — อนุภาคประกายดาว (sparkle) คล้ายเอฟเฟค **bone meal ของ Minecraft** แต่**ไม่เหมือนเป๊ะ**: **สีรุ้งแบบ random** และ **ค่อย ๆ กระจายออก** (rise + spread + fade) — *ผูกกับจังหวะต้นไม้โตแล้ว: ยิงตอนต้นใหม่เด้งขึ้น (`onGrow` callback)*
6. [ ] รูปแบบต้นไม้สอดคล้องกับสไตล์ภาพ **กึ่งสมจริง** ที่คุณหมอชอบ *(ยกออกจากขอบเขต Done — ติดตามพร้อม AC#1)*
7. [x] เอฟเฟคไม่ทำให้เฟรมเรตตกบนมือถือรุ่นกลาง และ asset ไม่ทำให้ bundle โตเกินจำเป็น — ยืนยันโดยเจ้าของงาน 2026-07-06

## 🛠 Technical Tasks
- [ ] ออกแบบ/จัดหา art asset ต้นไม้หลายชนิด (กึ่งสมจริง) และจัดเก็บใน `public/assets/`
- [ ] เพิ่มระบบเลือก/สุ่มชนิดต้นไม้ในระบบเช็คอิน
- [x] ทำ **growth transition** บน `.tree-progress-plant` ใน `checkin-summary-screen.js`: scale ต้นเก่า (`getTreeStage(completedDays - 1)`) เด้งขึ้น→ยุบลง แล้วสลับ `src` เป็น `getTreeImagePath(stage)` (`tree_01`..`tree_014`) แล้วเด้งขยายต้นใหม่ขึ้น (Web Animations API, `transform-origin: bottom center`)
- [x] แยกเป็น helper เฉพาะหน้า `growTreeTransition(img, prevStage, nextStage, onGrow)` เลียนแบบแนวทาง `bounceCheckInCharacter()` (ไม่ยัดลง component กลาง), รองรับ `prefers-reduced-motion` (ข้ามอนิเมชัน → ตั้ง src ปลายทาง), มี `cancel()` handle ที่ยกเลิกใน `cleanup()`
- [x] ทำ **Sparkle Particle Effect** เป็น component ใช้ซ้ำได้ `src/ui/components/effects/sparkle-effect.js` — sparkle สีรุ้ง random กระจายรอบ anchor (rise/spread/fade) ด้วย Web Animations API, `position: fixed`, `pointer-events: none`, `cancel()` handle
- [x] ปรับจูนค่า default ให้เอฟเฟคใหญ่/แน่นขึ้น: `count` 48, รัศมีกระจาย ×1.0, และเพิ่มพารามิเตอร์ `sMinMax {min,max}` คุมขนาดดาวรายดวง (default `{min:25, max:50}` px)
- [x] ต่อเข้า `checkin-summary-screen.js` หน้า tree progression (calendar step) — anchor ที่ `.tree-progress-frame`, ยกเลิกใน `cleanup()`
- [x] รองรับ `prefers-reduced-motion` (ลดจำนวน sparkle)
- [x] ผูก sparkle เข้ากับจังหวะ **growth transition** เมื่อต้นไม้โต — ยิง sparkle ใน `onGrow` callback ตอนต้นใหม่เด้งขึ้น
- [ ] ทดสอบประสิทธิภาพบนมือถือจริง (sparkle + growth transition รวมกันต้องไม่ทำเฟรมตก)
