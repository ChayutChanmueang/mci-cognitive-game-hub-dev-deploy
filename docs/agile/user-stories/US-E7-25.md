**Status:** ✅ Done (Sprint 7) — เสร็จ v0.26.0 (เปลี่ยนเป็น art ตัวละครนั่งพัก beanbag `*_resting_02.png` + ขยับเงา); v0.26.1 แยกสไตล์ popup ด้วย variant `gh-popup--rest-day` + ตัวแปร `--popup-*` เพื่อจัดตำแหน่ง/ขนาดแยกจาก popup อื่น — ยืนยันโดยเจ้าของงาน 2026-07-06 ("สามารถแยกการจัดตำแหน่งได้")

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ Popup "วันนี้พักก่อน" (เข้าเกมซ้ำในวันที่เล่นจบแล้ว) แสดง **ตัวละครคุณตา/คุณยายนั่งพัก** ตามเพศ
**เพื่อให้** Popup สื่อสารบรรยากาศ "พักผ่อน" ได้ชัด และสอดคล้องกับตัวละครในหน้าอื่น ๆ

---

## ✅ Acceptance Criteria
1. [x] Popup "วันนี้พักก่อน" (เฉพาะกรณีเล่นครบของวันแล้วเข้ามาซ้ำในวันเดิม) แสดง **ตัวละครคนแก่นั่งพัก (beanbag)** ตามเพศ: ชาย = คุณตา, หญิง = คุณยาย
2. [x] ใช้ art ชุดใหม่ `OldMan_resting_02.png` / `OldWoman_resting_02.png` โดยเลือกตามเพศจริงจาก database (`gender`: `female` → คุณยาย, อื่น ๆ → คุณตา)
3. [x] ข้อความตรงกับแบบ: หัวข้อ "วันนี้พักก่อน" + ข้อความ "กลับมาเล่นใหม่วันพรุ่งนี้นะ"
4. [x] **ขยับ/ปรับเงาด้านล่างตัวละคร** (`.character-shadow gh-popup__character-shadow`) ให้กว้างขึ้นและนั่งใต้ฐาน beanbag พอดี โดยไม่กระทบ popup จบโปรแกรม (finish-line)
5. [ ] ทดสอบทั้งเพศชาย/หญิงบนมือถือจริงว่าเลือกภาพถูกต้องและเงาจัดวางสวยงาม *(รอ QA มือถือ)*
