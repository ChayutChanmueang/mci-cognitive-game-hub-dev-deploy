# User Story: US-E7-25 - ใส่ตัวละครคุณตา/คุณยายนั่งพักใน Popup "วันนี้พักก่อน"

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** ก้องไผ่
**Source:** Owner Task Block — ก้องไผ่ (2026-07-06), [Sprint 07](../sprint-backlogs/sprint-07.md)

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้ Popup "วันนี้พักก่อน" (เข้าเกมซ้ำในวันที่เล่นจบแล้ว) แสดง **ตัวละครคุณตา/คุณยายนั่งพัก** ตามเพศ
**เพื่อให้** Popup สื่อสารบรรยากาศ "พักผ่อน" ได้ชัด และสอดคล้องกับตัวละครในหน้าอื่น ๆ

---

## ✅ Acceptance Criteria
1. [ ] Popup "วันนี้พักก่อน" แสดง **ตัวละครคนแก่นั่งพัก** ตามเพศ: ชาย = คุณตา, หญิง = คุณยาย
2. [ ] ตัวละครยังคงอยู่ครบหลังการ reskin กรอบ Popup ตาม [US-E7-04](US-E7-04.md) (Frame_Form_Panel) — ไม่หาย/ไม่ถูกบัง
3. [ ] มี **เงาด้านล่างตัวละคร** (`.character-shadow`) ตามมาตรฐานเดียวกับ [US-E7-16](US-E7-16.md) ข้อ 4
4. [ ] ทดสอบทั้งเพศชาย/หญิงบนมือถือจริงว่าเลือกภาพถูกต้องและจัดวางสวยงาม

> **สถานะปัจจุบัน:** `src/ui/day-completion-popup.js` มี `getRestingCharacter(gender)` เลือก `OldMan_resting.png`/`OldWoman_resting.png` อยู่แล้ว — สตอรีนี้คือ **ยืนยัน/ปรับให้ใช้ art ตัวนั่งพักล่าสุด** (เช่น asset จากพี่กวาง) และยืนยันว่ายังแสดงถูกต้องหลัง Popup ถูก reskin ตาม US-E7-04
