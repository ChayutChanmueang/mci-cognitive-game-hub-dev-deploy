# User Story: US-E2-03 - ระบบ Daily Goal (ความคืบหน้าของวันนี้)

**Status:** ✅ Done
**Epic:** [E2: Core Gamehub & Progression System](../01-product-backlog.md)
**Owner:** [Team Game / Team Web]

---

## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** เห็นแถบความคืบหน้าการเล่นเกมภายในหนึ่งวัน
**เพื่อให้** ฉันมีแรงจูงใจในการเล่นให้ครบด่านเป้าหมายที่กำหนดไว้ในแต่ละวัน

---

## ✅ Acceptance Criteria
1. [x] แสดงผลแถบความคืบหน้า (Progress Bar) และตัวเลขอัตราส่วนด่านในหน้าหลัก Gamehub
2. [x] แถบจะขยับเพิ่มขึ้นเมื่อผู้เล่นเล่นผ่านแต่ละมินิเกมย่อยในวันปัจจุบัน (เช่น 1/11, 2/11, ...)
3. [x] เมื่อเล่นจนผ่านด่านหลักและจุดพักยืดเส้นสายทั้งหมด แถบความคืบหน้าจะเลื่อนมาถึงเป้าหมายสุดท้าย (100%) เพื่อเปิดใช้งานปุ่มเช็คชื่อ
4. [x] สถานะความคืบหน้าจะคำนวณและแสดงของแต่ละวันในโปรแกรม 14 วันแยกขาดจากกันชัดเจน

---

## 🛠 Technical Tasks
- [x] พัฒนา UI Progress Bar แบบตอบสนอง ขนาดใหญ่ เห็นเด่นชัด เพื่อให้ผู้ป่วยระดับ MCI ติดตามความคืบหน้าได้สะดวก
- [x] เขียนฟังก์ชันคำนวณ % ความคืบหน้าโดยดึงและเปรียบเทียบข้อมูลจำนวนด่านที่ผู้ป่วยเล่นผ่านในประวัติ Supabase
- [x] เชื่อมต่อสถานะด่านกับระบบ Daily Goal และอัปเดตสเตตัสแบบเรียลไทม์เมื่อเล่นจบมินิเกมและกลับเข้าสู่ Hub

---

## 📝 Implementation Details
- ในหน้าจอ `src/ui/game-hub-screen.js` มีฟังก์ชันการประมวลผลความสำเร็จของวันปัจจุบัน (Active Day) โดยจะนับจำนวนมินิเกมย่อยที่ขึ้นสถานะ Completed เทียบกับเป้าหมายรวมในวันนั้น
- ความคืบหน้านี้จะไปควบคุมสถานะปุ่ม 'เช็คชื่อ' (Check-in) ที่อยู่ด้านล่างสุดของรายการภารกิจ หากเปอร์เซ็นต์ยังไม่เต็ม ปุ่มเช็คชื่อจะอยู่ในสถานะล็อค (Disabled) เสมอ
