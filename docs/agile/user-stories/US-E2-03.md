# User Story: US-E2-03 - ระบบ Daily Goal (ความคืบหน้าของวันนี้)

**Epic:** [E2: Core Gamehub & Progression System](../01-product-backlog.md)
**Owner:** [TBD]

---

## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** เห็นแถบความคืบหน้าการเล่นเกมภายในหนึ่งวัน
**เพื่อให้** ฉันมีแรงจูงใจในการเล่นให้ครบ 10 ด่านตามเป้าหมายที่กำหนดไว้

---

## ✅ Acceptance Criteria
1. [ ] แสดงผลแถบความคืบหน้า (Progress Bar) ในหน้า Gamehub
2. [ ] แถบจะขยับเพิ่มขึ้นเมื่อผู้เล่นเล่นผ่านแต่ละด่านในวันนั้นๆ (1/10, 2/10, ...)
3. [ ] เมื่อเล่นครบ 10 ด่าน แถบความคืบหน้าจะเต็ม (100%)
4. [ ] ข้อมูลความคืบหน้าจะถูกรีเซ็ตในวันถัดไปเมื่อเริ่มโปรแกรมใหม่

- [ ] เชื่อมต่อสถานะด่านกับระบบ Daily Goal
