# User Story: US-E9-03 - เกมสัตว์นักสืบ: เปลี่ยน input เป็นลากเพื่อวาง

**Status:** 📋 Backlog
**Epic:** [E9: Field Feedback Hotfixes](../01-product-backlog.md)

**Source:** [Field Feedback — ลงพื้นที่ (2026-07-10)](../meeting-backlogs/2026-07-10.md) §2.3

**Target version:** `1.1.1` (PATCH)

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้เกมสัตว์นักสืบ (Zoo Detective) ใช้วิธี **ลากเพื่อวาง** เหมือนเกมอื่น
**เพื่อให้** ไม่สับสนระหว่างเกมที่จิ้มกับเกมที่ลาก

---

## 🐛 Problem (จากการลงพื้นที่ — v1.0.0)
- Zoo Detective ใช้ **จิ้มเพื่อวาง** (tap-to-place)
- เกมอื่นในแอปใช้ **ลากเพื่อวาง** (drag-to-place)
- ผู้สูงอายุ **สับสน** เพราะ input pattern ไม่สม่ำเสมอ

---

## ✅ Acceptance Criteria
1. [ ] ผู้เล่นสามารถ **ลาก** ตัวเลือก/ไอเทมไปวางในช่องเป้าหมายได้ (drag-and-drop)
2. [ ] **ไม่ใช้** tap-to-place เป็นวิธีหลักอีกต่อไป (หรือรองรับ tap เป็น fallback ตาม accessibility guideline ถ้าจำเป็น)
3. [ ] พฤติกรรมลากสอดคล้องกับเกมอื่น (เช่น Context Clues, Symmetry Decor) — hit area เพียงพอสำหรับผู้สูงอายุ
4. [ ] ระบบ hint / feedback ยังทำงานได้หลังเปลี่ยน input mode
5. [ ] ไม่กระทบข้อมูลผู้เล่นที่เล่นโปรแกรมอยู่แล้ว
6. [ ] ทดสอบบนมือถือจริง — owner ยืนยัน
