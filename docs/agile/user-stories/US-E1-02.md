**Owner:** [TBD]

---

## 📖 Description
**ในฐานะ** ผู้ป่วยใหม่
**ฉันต้องการ** กรอกข้อมูลส่วนตัวในขั้นตอนการลงทะเบียนครั้งแรก
**เพื่อให้** ระบบมีข้อมูลพื้นฐานสำหรับการประเมินและจัดโปรแกรมการเล่นที่เหมาะสม

---

## ✅ Acceptance Criteria
1. [ ] หน้าจอลงทะเบียนมีฟิลด์ข้อมูลดังนี้:
   - ชื่อ - นามสกุล
   - วันเกิด (DatePicker)
   - อายุ (คำนวณจากวันเกิดหรือกรอกเอง)
   - เพศ (ชาย, หญิง, อื่นๆ, ไม่ระบุ)
   - ระดับการศึกษา (ไม่เรียน, ประถม, มัธยมต้น, มัธยมปลาย/ปวช., อนุปริญญา/ปวส., ปริญญาตรี, สูงกว่าปริญญาตรี)
2. [ ] ข้อมูลทั้งหมดจะถูกบันทึกลงในฐานข้อมูล Supabase เมื่อกดปุ่ม "ตกลง" หรือ "ลงทะเบียน"
3. [ ] หลังจากลงทะเบียนสำเร็จ ระบบจะนำผู้ใช้เข้าสู่หน้า Gamehub ทันที
