# User Story: US-E1-02 - ลงทะเบียนผู้ใช้ใหม่

**Status:** ✅ Done
**Epic:** [E1: User Management & Authentication](../01-product-backlog.md)
**Owner:** [Team Web]

---

## 📖 Description
**ในฐานะ** ผู้ป่วยใหม่
**ฉันต้องการ** กรอกข้อมูลส่วนตัวในขั้นตอนการลงทะเบียนครั้งแรก
**เพื่อให้** ระบบมีข้อมูลพื้นฐานสำหรับการประเมินและจัดโปรแกรมการเล่นที่เหมาะสม

---

## ✅ Acceptance Criteria
1. [x] หน้าจอลงทะเบียนมีฟิลด์ข้อมูลดังนี้:
   - ชื่อ - นามสกุล (ในโค้ดแยกเป็น ชื่อ และ นามสกุล)
   - วันเกิด (DatePicker / HTML input type="date")
   - อายุ (คำนวณจากวันเกิดอัตโนมัติ)
   - เพศ (ชาย, หญิง, อื่นๆ, ยังไม่ระบุ)
   - ระดับการศึกษา (ดึงตัวเลือกมาจากตาราง `education_levels` ใน Supabase)
2. [x] ข้อมูลทั้งหมดจะถูกบันทึกลงในฐานข้อมูล Supabase เมื่อกดปุ่ม "ยืนยันข้อมูลผู้เล่น"
3. [x] หลังจากลงทะเบียนสำเร็จ ระบบจะนำผู้ใช้เข้าสู่หน้า Gamehub ทันที

---

## 🛠 Technical Tasks
- [x] สร้าง Form ลงทะเบียนโดยใช้ Material Web Components (`signup-screen.js`) ร่วมกับ CSS styling ในตัวระบบหลัก
- [x] พัฒนาฟังก์ชัน `createPatientProfile` เพื่อ Insert ข้อมูลลง Table `user_patient_data` ใน Supabase
- [x] ตรวจสอบความครบถ้วนของข้อมูล (Form Validation เช่น ตรวจสอบเบอร์โทร 10 หลัก และป้องกันวันเกิดในอนาคต)

---

## 📝 Implementation Details
- พัฒนาในส่วนหน้าจอลงทะเบียน `src/ui/signup-screen.js` โดยเชื่อมต่อเข้ากับระบบการทำธุรกรรมลงทะเบียนของ `src/core/database.js` (`createPatientProfile` และ `createUserGameProfile`) เพื่อให้มั่นใจได้ว่าข้อมูลพื้นฐานผู้ป่วยและบัญชีการเล่นถูกสร้างขึ้นอย่างครบถ้วน
- ใช้ประโยชน์จากฟังก์ชันคำนวณอายุที่ดึงมาจาก `src/util/patient-date-util.js` เพื่อประมวลผลอายุผู้ป่วยแบบเรียลไทม์ทันทีเมื่อผู้ป่วยคลิกเลือกวันเกิดในปฏิทิน
