# User Story: US-E7-27 - Popup แจ้งเตือนเมื่ออินเทอร์เน็ตหลุด/ไม่มีอินเทอร์เน็ต

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** ก้องไผ่
**Source:** Owner Task Block — ก้องไผ่ (2026-07-06), [Sprint 07](../sprint-backlogs/sprint-07.md)

---

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่ใช้แอปผ่านมือถือ/เน็ตบ้าน
**ฉันต้องการ** ให้มี Popup แจ้งเตือนอย่างชัดเจนเมื่อ **อินเทอร์เน็ตหลุด หรือไม่มีอินเทอร์เน็ต**
**เพื่อให้** เข้าใจว่าปัญหาเกิดจากเครือข่าย (ไม่ใช่แอปพัง) และรู้ว่าต้องทำอะไรต่อ (ตรวจเน็ต แล้วลองใหม่)

---

## 🖼 Reference (ดีไซน์ที่ต้องการ)
![Popup อินเทอร์เน็ตหายไปแล้ว](assets/us-e7-27-offline-popup-ref.png)

- **หัวข้อ:** "อินเทอร์เน็ตหายไปแล้ว"
- **ข้อความ:** "ตรวจสอบอินเทอร์เน็ต แล้วกลับมาใหม่อีกครั้งนะ"
- **ตัวละคร:** คุณตา/คุณยาย ปีนต้นมะพร้าวชูมือถือหาสัญญาณ (สื่อว่า "หาเน็ต")
- **ปุ่ม:** ปุ่มเขียว "ลองอีกครั้ง"

---

## ✅ Acceptance Criteria
1. [ ] เมื่อ **ตรวจพบว่าออฟไลน์** (ไม่มีเน็ต หรือเน็ตหลุดกลางคัน) แอปแสดง Popup ตามดีไซน์: หัวข้อ "อินเทอร์เน็ตหายไปแล้ว" + ข้อความ "ตรวจสอบอินเทอร์เน็ต แล้วกลับมาใหม่อีกครั้งนะ" + ปุ่ม "ลองอีกครั้ง"
2. [ ] Popup ใช้กรอบ/สไตล์เดียวกับ popup อื่น (Frame_Form_Panel + Start-Game-Button) และแยกสไตล์ด้วย variant ของตัวเอง (ไม่ปนกับ popup อื่น ตามแนวทาง v0.26.1)
3. [ ] ปุ่ม "ลองอีกครั้ง" → ตรวจการเชื่อมต่อใหม่/ลองซ้ำ action ที่ล้มเหลว (หรือรีโหลดหน้า) ; ถ้ายังออฟไลน์อยู่ให้คง popup ไว้/แสดงซ้ำ
4. [ ] ครอบคลุมทั้ง 2 กรณี: (ก) **ไม่มีเน็ตตั้งแต่แรก** และ (ข) **เน็ตหลุดระหว่างใช้งาน** (เช่น โหลด leaderboard / บันทึกคะแนน / โหลดโปรแกรมรายวัน ล้มเหลวเพราะเครือข่าย)
5. [ ] ตัวละครแยกตามเพศ (คุณตา/คุณยาย) ตาม data จริง ถ้ามี asset ทั้งสองเพศ (ถ้ายังมีรูปเดียวให้ใช้รูปเดียวไปก่อน + ทำ TODO asset อีกเพศ)
6. [ ] ไม่ขึ้น popup ซ้ำซ้อน (กันการเด้งหลายอันพร้อมกัน) และเมื่อเน็ตกลับมาแล้ว popup ปิด/ผู้ใช้ทำงานต่อได้
7. [ ] แสดงผลถูกต้อง อ่านง่ายบนมือถือจริง

---

## 🛠 Technical Tasks
- [ ] สร้าง popup ใหม่ (เช่น `src/ui/offline-popup.js`) ใช้ `renderFramePopupMarkup`/`renderFramePopupShortMarkup` ([frame-popup.js](../../../src/ui/components/frame-popup.js)) พร้อม `variant: "offline"` (หรือ `network-error`) + เพิ่ม override สไตล์ variant ใน `public/components.css` (ตามแพทเทิร์น `--popup-*` v0.26.1)
- [ ] ตรวจจับสถานะเครือข่าย: `navigator.onLine` + event `window` `online`/`offline`; และดักความล้มเหลวจากเครือข่ายในชั้นข้อมูล (`src/core/database.js` — Supabase/RPC fetch error) เพื่อ trigger popup
- [ ] Wire ปุ่ม "ลองอีกครั้ง" → retry/refresh; กัน popup ซ้อน (singleton/guard) และปิดเมื่อ `online` กลับมา
- [ ] จัดหา/สร้าง art ตัวละครปีนต้นมะพร้าวหาสัญญาณ (คุณตา/คุณยาย) ใน `public/assets/common/character/...` — ถ้ายังไม่มี ให้ทำ TODO asset ไว้
- [ ] ตรวจว่า flow เดิม (toast/retry ของ US-E7-18) ไม่ตีกันกับ popup นี้ — เลือกใช้ให้เหมาะ (toast = ชั่วคราวเล็ก, popup นี้ = บล็อกเมื่อออฟไลน์จริง)
- [ ] ทดสอบบนมือถือจริง: ปิด Wi-Fi/เปิดโหมดเครื่องบิน ระหว่างเข้าเกม/บันทึกคะแนน/ดู leaderboard
