# User Story: US-E7-14 - ปรับ Layout หน้าหลัก Game Hub (ระยะเลเวล, สลับชื่อเกม/หมวด, เงาตัวละคร)

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** ให้หน้าหลัก (Game Hub) จัด layout ชัดเจน ไม่เบียดกัน และอ่านง่าย
**เพื่อให้** กดปุ่มเริ่มเกมได้ถูกต้องโดยไม่ชนกับมินิเกมถัดไป และเห็นข้อมูลเกมได้ชัด

---

## ✅ Acceptance Criteria
1. [ ] เพิ่ม **ระยะห่างระหว่างแต่ละเลเวล** ให้มากขึ้น เพื่อให้ **ปุ่มเริ่มเกมไม่ไปเบียดมินิเกมถัดไป** — ดู [ภาพอ้างอิงจุดที่เบียด](assets/us-e7-14-level-spacing.png)
2. [ ] **สลับตำแหน่ง** ระหว่าง **ชื่อเกม** กับ **ชื่อหมวดหมู่ Cognitive** ในหน้าหลัก ตามที่กำหนด
3. [ ] เพิ่ม **เงาตัวละคร (shadow)** ในหน้าหลักให้ดูมีมิติ
4. [ ] ใส่ **เงาด้านล่างตัวละครคนแก่ทั้งใน node และใน popup** (ไม่ใช่เฉพาะหน้าหลัก) — ใช้กับ Popup ใน [US-E7-16](US-E7-16.md) ด้วย
5. [ ] Layout ใหม่ยังเลื่อน (scroll) และ scroll-to-current ทำงานถูกต้อง ไม่มี element ทับซ้อน
