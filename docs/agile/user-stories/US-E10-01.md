## 📖 Description
**ในฐานะ** ผู้วิจัย/ผู้ดูแลระบบ (Researcher/Admin)
**ฉันต้องการ** ระบบ Tag สำหรับแบ่งกลุ่มผู้เล่น (เช่น กลุ่มทดลอง/กลุ่มควบคุม หรือรอบทดสอบต่างกัน)
**เพื่อให้** สามารถแบ่งประเภทกลุ่มทดสอบได้ชัดเจน และนำไปใช้กรองข้อมูล (Leaderboard, Export) แยกตามกลุ่มได้

---

## ✅ Acceptance Criteria
1. [ ] ฐานข้อมูลมีคอลัมน์ Tag กลุ่มทดสอบ (เช่น `group_tag`) ในตารางข้อมูลผู้ป่วย `user_patient_data` — ผู้เล่นเดิมที่ยังไม่มี Tag ต้องไม่พัง (`NULL` ได้)
2. [ ] กำหนด Tag ให้ผู้เล่นได้ตั้งแต่ตอนลงทะเบียน (Sign-up) หรือผ่านเครื่องมือ Admin/CLI (ตามที่ owner เลือก)
3. [ ] หน้า Player-Info (Admin) แสดง Tag ของผู้เล่น
4. [ ] ข้อมูล Export CSV (US-E9-05) มีคอลัมน์ Tag รวมอยู่ด้วย เพื่อใช้แยกกลุ่มตอนวิเคราะห์
5. [ ] ค่า Tag เป็นชุดที่ควบคุมได้ (ไม่ใช่ free text ปนกันจนกรองไม่ได้) — นิยามรายการ Tag ร่วมกับ owner ก่อนพัฒนา
6. [ ] ระบบเดิม (login, check-in, เล่นเกม, leaderboard ปัจจุบัน) ทำงานได้ตามปกติสำหรับผู้เล่นที่ไม่มี Tag
