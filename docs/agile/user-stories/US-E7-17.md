# User Story: US-E7-17 - ปรับ Boot Loading ให้ใช้โลโก้เกม + dot progress 5 จุด

**Status:** 🔍 Review / Testing (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** ก้องไผ่
**Source:** Owner Task Block — ก้องไผ่ (2026-06-26), [Sprint 07](../sprint-backlogs/sprint-07.md)

## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุ
**ฉันต้องการ** เห็นหน้า boot loading ที่มีโลโก้เกมชัดเจนและสถานะโหลดแบบเข้าใจง่าย
**เพื่อให้** รู้ว่าแอปกำลังเริ่มทำงานโดยไม่รู้สึกว่าเกมค้างหรือยังไม่ตอบสนอง

---

## ✅ Acceptance Criteria
1. [x] Boot loading overlay แสดงโลโก้เกมเดียวกับหน้า `src/ui/welcome-screen.js` โดยใช้ asset `/Logo.png`
2. [x] ลบ spinner และข้อความ loading เดิมออกจาก boot overlay
3. [x] แสดง dot progress แบบ `.dotted-loader` จำนวน **5 dots**
4. [x] dot ทั้ง 5 จุดใช้ animation `blink`/`fade` และไล่ delay ตามลำดับ เช่น `0s`, `0.2s`, `0.4s`, `0.6s`, `0.8s`
5. [x] overlay ยังคงปิดตาม logic `finishBootLoading()` / first usable paint เดิม และไม่ย้อนกลับไปเกิดปัญหาโหลดค้างนานตาม [PB-01-02](../problems/PB-01-02.md)
6. [ ] ตรวจบน mobile viewport ว่าโลโก้และ dot progress ไม่ล้น ไม่ทับกัน และอยู่ในตำแหน่งที่อ่านสถานะได้ชัดเจน

---

## 🛠 Technical Tasks
- [x] ปรับ boot overlay markup/style ใน `index.html` ให้ใช้โลโก้ `/Logo.png`
- [x] แทน spinner/loading text เดิมด้วยโครงสร้าง `<div class="dotted-loader"><span></span><span></span><span></span><span></span><span></span></div>`
- [x] เพิ่ม/ปรับ CSS ของ `.dotted-loader`, `.dotted-loader span`, `@keyframes blink`, และ `@keyframes fade` ให้รองรับ 5 dots
- [x] ตรวจว่า `finishBootLoading()` ใน `src/main.js` ยังทำงานเหมือนเดิมและ safety timeout ยังเป็น backstop เท่านั้น
- [ ] ทดสอบ first paint บนเส้นทางเริ่มต้น Welcome/Game Hub และตรวจว่า overlay ไม่บังหน้านานเกินจำเป็น
