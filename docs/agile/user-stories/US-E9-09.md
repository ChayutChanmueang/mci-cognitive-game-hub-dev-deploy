## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่ตั้งค่าขนาดตัวอักษรระบบให้ใหญ่มาก
**ฉันต้องการ** ให้ layout ในเกมยังใช้งานได้ ไม่เพี้ยนเพราะฟอนต์ขยายตามระบบเกินไป
**เพื่อให้** ได้ทั้งความสะดวกในการอ่าน (ระบบ) และ UI ที่จัดวางถูกต้อง

---

## 🐛 Problem (จากการลงพื้นที่ — v1.0.0)
- ผู้สูงอายุหลายคนตั้ง **ขนาดตัวอักษรระบบ (Android/iOS font scale) ใหญ่มาก** เพื่ออ่านง่าย
- ฟอนต์ในเกม **ขยายตามระบบ** ทำให้ **ใหญ่เกินไป** และ **layout ผิดเพี้ยน** (ปุ่มล้น, ข้อความทับ)

---

## ✅ Acceptance Criteria
1. [ ] UI หลัก (Game Hub, Login, Sign-up, Popup) **ไม่แตก layout** เมื่อ system font scale สูง (ทดสอบอย่างน้อย Android **Large / Largest** หรือ iOS **Accessibility Larger Text**)
2. [ ] เกมกำหนดขนาดตัวอักษร UI ด้วยหน่วยที่ **ควบคุมได้** (เช่น `px` / fixed `rem` base / `max-font-size`) — ไม่ scale ไม่จำกัดตามระบบทั้งหมด
3. [ ] ข้อความสำคัญยัง **อ่านได้** แม้จำกัด scale — อาจใช้ scroll/ellipsis ที่เหมาะสมแทนการล้นจอ
4. [ ] มินิเกม Phaser HUD (ถ้ามี DOM overlay) ไม่เพี้ยนเมื่อ font scale สูง
5. [ ] ทดสอบบนมือถือจริงที่ตั้ง font scale ใหญ่

---

## 🛠 Technical Tasks
- [ ] ตรวจ `text-size-adjust`, `rem` root, MUI/Material Web components
- [ ] ตั้ง CSS strategy: isolate app font scale จาก system (เช่น `html { font-size: 16px }` + `max()` guard) — อ้างอิง [ux-ui-guidelines](../../wiki/guidelines/ux-ui-guidelines.md)
- [ ] ทดสอบ Game Hub, forms, popups ที่ font scale 125%–200%
- [ ] บันทึก guideline สั้น ๆ ใน wiki ถ้ามี pattern ใหม่
