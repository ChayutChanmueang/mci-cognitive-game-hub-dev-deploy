# User Story: US-E1-03 - ระบบคำนวณวันที่สิ้นสุดโปรแกรมอัตโนมัติ

**Status:** ✅ Done
**Epic:** [E1: User Management & Authentication](../01-product-backlog.md)
**Owner:** [Team Web]

---

## 📖 Description
**ในฐานะ** ผู้ดูแลโปรแกรม
**ฉันต้องการ** ให้ระบบบันทึกวันที่เริ่มเล่นและคำนวณวันที่สิ้นสุดโปรแกรม (14 วัน) โดยอัตโนมัติ
**เพื่อให้** ผู้ป่วยมีกรอบระยะเวลาที่ชัดเจนในการฝึกทักษะ

---

## ✅ Acceptance Criteria
1. [x] เมื่อลงทะเบียนสำเร็จ ระบบจะระบุ "วันที่เริ่มโปรแกรม" (หรือผู้ใช้สามารถคลิกเลือกวันที่จะเริ่มผ่าน DatePicker บนฟอร์มสมัครได้)
2. [x] ระบบใช้ "วันที่เริ่มโปรแกรม" ร่วมกับการอ้างอิงลำดับด่าน 14 วันในตาราง Preset (`game_level_presets`) เพื่อกำหนดช่วงการฝึกทักษะ
3. [x] ข้อมูลวันที่เริ่มและสิ้นสุดโปรแกรมจะถูกจัดเก็บในฐานข้อมูล Supabase (ฟิลด์ `started_program` ในตาราง `user_patient_data`)
4. [x] สามารถดึงข้อมูลวันที่เริ่มและสิ้นสุดออกมาสรุปผลในหน้า Dashboard และการ Export ข้อมูลในระบบได้

---

## 🛠 Technical Tasks
- [x] เพิ่มฟังก์ชันการคำนวณและกรอกวันที่เริ่มต้นการใช้งานโปรแกรมในขั้นตอนสมัคร
- [x] เชื่อมต่อและอัปเดต Database Schema ของ `user_patient_data` ฟิลด์ `started_program`
- [x] ใช้ Date Util (`src/util/patient-date-util.js`) ในการแปลงเวลาและใช้ `Intl.DateTimeFormat` จัดเขตเวลาเป็น "Asia/Bangkok"

---

## 📝 Implementation Details
- ในการลงทะเบียน `started_program` จะถูกบันทึกในรูปแบบ ISO string ไปยัง Supabase 
- ระบบใช้การคำนวณใน `database.js` (`getBangkokProgramDateKey`) เพื่อจับคู่ประวัติการเล่นกับวันของโปรแกรมอย่างถูกต้อง (เช่น วันที่ 1, 2, ..., 14 ของโปรแกรม โดยนับจากวันที่เริ่มสะสม) ช่วยให้ผู้ดูแลสามารถติดตามการเล่นและประเมินผลผ่าน CSV Export ได้อย่างถูกต้อง
