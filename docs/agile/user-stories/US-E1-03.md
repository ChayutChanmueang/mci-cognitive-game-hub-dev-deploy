# User Story: US-E1-03 - ระบบคำนวณวันที่สิ้นสุดโปรแกรมอัตโนมัติ

**Status:** 🏗 To Do
**Epic:** [E1: User Management & Authentication](../01-product-backlog.md)
**Owner:** [TBD]

---

## 📖 Description
**ในฐานะ** ผู้ดูแลโปรแกรม
**ฉันต้องการ** ให้ระบบบันทึกวันที่เริ่มเล่นและคำนวณวันที่สิ้นสุดโปรแกรม (14 วัน) โดยอัตโนมัติ
**เพื่อให้** ผู้ป่วยมีกรอบระยะเวลาที่ชัดเจนในการฝึกทักษะ

---

## ✅ Acceptance Criteria
1. [ ] เมื่อลงทะเบียนสำเร็จ ระบบจะบันทึกวันที่ปัจจุบันเป็น "วันที่เริ่มโปรแกรม"
2. [ ] ระบบคำนวณ "วันที่สิ้นสุดโปรแกรม" โดยบวกเพิ่มไปอีก 14 วันจากวันที่เริ่ม
3. [ ] ข้อมูลวันที่เริ่มและสิ้นสุดโปรแกรมจะถูกจัดเก็บในฐานข้อมูล Supabase
4. [ ] ผู้ใช้หรือผู้ดูแลสามารถดูวันที่เริ่ม/สิ้นสุดได้ในหน้า User Information

- [ ] ปรับแก้ Database Schema (Table `users`) ให้รองรับฟิลด์ `start_date` และ `end_date`
