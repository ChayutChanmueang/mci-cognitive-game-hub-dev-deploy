## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** ช่วงเวลาพักสั้นๆ ระหว่างการฝึกสมอง
**เพื่อให้** ร่างกายและจิตใจได้ผ่อนคลายก่อนไปต่อในด่านถัดไป

---

## ✅ Acceptance Criteria
1. [ ] ด่านจุดพักจะปรากฏอยู่ที่ด่านที่ 6 ของทุกวัน
2. [ ] มินิเกมจุดพักเป็นกิจกรรมง่ายๆ เช่น การกดปุ่มตามจำนวนที่กำหนด (เช่น 10 ครั้ง) เพื่อให้ Avatar ออกกำลังกาย
3. [ ] มีภาพประกอบที่สื่อถึงการผ่อนคลายหรือยืดเส้นยืดสาย
4. [ ] เมื่อทำกิจกรรมครบ จะถือว่าผ่านด่านและสามารถไปต่อด่านที่ 7 ได้

---

## 🛠 Technical Tasks
- [ ] พัฒนา Scene มินิเกมจุดพัก (Simple interaction)
- [ ] จัดการระบบ Input การกดปุ่ม และ Feedback ทางภาพ (Animation)
- [ ] รวมด่านจุดพักเข้ากับ Flow ของ Level Design
