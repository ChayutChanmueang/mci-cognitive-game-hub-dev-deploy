# User Story: US-E2-05 - ด่านจุดพัก (Rest Level)

**Status:** ✅ Done
**Epic:** [E2: Core Gamehub & Progression System](../01-product-backlog.md)
**Owner:** [Team Game]

---

## 📖 Description
**ในฐานะ** ผู้ป่วย
**ฉันต้องการ** ช่วงเวลาพักสั้นๆ ระหว่างการฝึกสมอง
**เพื่อให้** ร่างกายและจิตใจได้ผ่อนคลายก่อนไปต่อในด่านถัดไป

---

## ✅ Acceptance Criteria
1. [x] ด่านจุดพัก (Resting Point) จะปรากฏขวางเป็นภารกิจสลับคั่นระหว่างมินิเกมฝึกสมอง
2. [x] มินิเกมจุดพักเป็นกิจกรรมผ่อนคลายกล้ามเนื้ออย่างง่าย เช่น กิจกรรมยืดเส้นยืดสายหรือหายใจเข้าออกตามคำแนะนำของนักกายภาพบำบัด
3. [x] มีภาพประกอบที่สื่อถึงการผ่อนคลาย ท่าทางยืดเหยียดร่างกายที่ชัดเจน และเสียงบรรยายกระตุ้นการปฏิบัติ
4. [x] เมื่อผู้ป่วยกดทำกิจกรรมจบการยืดเส้นสายตามจำนวนที่กำหนด ระบบจะบันทึกสถานะผ่านด่านและปลดล็อคภารกิจขั้นต่อไป

---

## 🛠 Technical Tasks
- [x] พัฒนา Scene มินิเกมจุดพัก (Resting Point) โดยใช้ Phaser
- [x] จัดการระบบ Input การแตะหน้าจอเพื่อผ่อนคลาย และการแสดงผล Feedback ความคืบหน้าของการพักผ่อนแบบค่อยเป็นค่อยไป
- [x] กำหนดรหัสเกมเฉพาะ (`REST001`) และเพิ่มลงในรายการ Level Design

---

## 📝 Implementation Details
- มินิเกมจุดพักผ่อนคลายนี้พัฒนาขึ้นเพื่อให้ผู้สูงอายุลดความเครียดจากการทดสอบสมอง โดยตัวเกมจะมีท่ากายภาพบำบัดอย่างง่ายและผู้ใช้จะทำการกดปุ่มเพื่อขยับตามท่าทางจนครบขั้นตอน
- การจบด่านจุดพักจะทำการบันทึกประวัติลง Supabase ด้วยรหัส `REST001` โดยจะไม่นำไปประมวลผลเพิ่มจำนวนสถิติระดับความยากเหมือนมินิเกมฝึกความจำหรือสมาธิ เพื่อให้สถิติแยกวิเคราะห์ทางการแพทย์ไม่เกิดความคลาดเคลื่อน
