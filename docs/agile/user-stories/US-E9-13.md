## 📖 Description
**ในฐานะ** ผู้เล่นสูงอายุที่เห็น popup "อินเทอร์เน็ตหายไปแล้ว"
**ฉันต้องการ** ให้ตัวละครคุณตา/คุณยาย (ปีนต้นมะพร้าวหาสัญญาณ) **เป็น art ชุดใหม่ที่อัปเดตแล้ว**
**เพื่อให้** ภาพสื่อสารชัดและตรงกับชุด character art ปัจจุบัน

---

## 🐛 Problem
- Art เดิมใน [US-E7-27](US-E7-27.md) (`OldWoman_internet_loss.png` / `OldMan_internet_loss.png`) **กำลังถูกเปลี่ยน** เป็นชุดใหม่
- ต้อง sync ไฟล์ใน repo + ให้ offline buffer / SW แสดงรูปใหม่ได้หลัง deploy

---
