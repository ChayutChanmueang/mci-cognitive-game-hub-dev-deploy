# User Story: US-E7-12 - แสดงโดเมน Cognitive ในเกม + สรุปหลังบ้าน + เตรียมข้อมูล AI

**Status:** 📋 Backlog (Sprint 7)
**Epic:** [E7: Game Art Assets & UI/UX Polish](../01-product-backlog.md)
**Owner:** [Developer/AI]
**Source:** [Doctor Feedback — Meeting #2 (2026-06-24)](../meeting-backlogs/2026-06-24.md) §2.5, §2.6

---

## 📖 Description
**ในฐานะ** ผู้เล่นและทีมแพทย์
**ฉันต้องการ** ให้เกมบอกว่าผู้เล่นกำลังฝึก Cognitive ด้านใด และให้ข้อมูลหลังบ้านสรุปผลรายด้าน
**เพื่อให้** ผู้เล่นเข้าใจเป้าหมายการฝึก และทีมแพทย์เห็นว่าผู้เล่นควรพัฒนาด้านไหน อีกทั้งเตรียมข้อมูลไว้ต่อยอด AI

---

## ✅ Acceptance Criteria
1. [ ] มีข้อมูลแสดง **ในเกม** ว่าผู้เล่นกำลังพัฒนา Cognitive **ด้านไหน** (เช่น ความจำ, ตรรกะ, มิติสัมพันธ์)
2. [ ] ข้อมูลหลังบ้านแสดง **สรุปรวมในแต่ละด้าน Cognitive** ของผู้เล่น (เห็นว่าด้านไหนต้องพัฒนา)
3. [ ] โครงสร้างข้อมูลถูกจัดเตรียมให้พร้อม **ต่อยอด AI** (schema/field ที่จำเป็น, mapping เกม → cognitive domain)
4. [ ] ป้ายบอกโดเมนในเกมไม่รบกวนการเล่นและอ่านง่ายสำหรับผู้สูงอายุ

---

## 🛠 Technical Tasks
- [ ] กำหนด mapping ระหว่างมินิเกมแต่ละเกม → cognitive domain ให้เป็นแหล่งความจริงเดียว
- [ ] เพิ่มป้าย/ข้อมูลแสดงโดเมน Cognitive ในหน้าปกเกมหรือ Gamehub
- [ ] ออกแบบ aggregation รายด้าน Cognitive ในข้อมูลหลังบ้าน (สรุปต่อผู้เล่น)
- [ ] ทบทวน schema เพื่อความพร้อมต่อการทำ AI (ดู [TD-DB-01](TD-DB-01.md))
