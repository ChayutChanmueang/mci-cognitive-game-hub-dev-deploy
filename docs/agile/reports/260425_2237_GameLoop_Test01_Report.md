## Bug Report & UX Improvements (ข้อบกพร่องและสิ่งที่ควรปรับปรุง)

### 1. [Critical] ปัญหา Database Logging ขัดข้อง (Supabase)
- **รายละเอียด**: เกิด `Error 23503 (Foreign key constraint violation)` เมื่อตัวเกมพยายามส่ง Log ไปยังตาราง `user_event_log` 
- **สาเหตุที่เป็นไปได้**: ตัวแปร `eventid` ที่ส่งไปจากเกมไม่มีอยู่จริงในตารางอ้างอิง `eventid_list_data` ของฐานข้อมูล
- **ผลกระทบ**: ระบบจะไม่สามารถติดตามความคืบหน้าหรือเก็บคะแนนของผู้เล่นสำหรับเกมนี้ได้

### 2. [Medium] Flow การออกจากเกมไม่สมบูรณ์ (Navigation Loop)
- **รายละเอียด**: เมื่อเล่นเกมจบและกดปุ่ม "RETURN" ตัวเกมจะพากลับไปหน้าเลือกระดับความยาก (Difficulty Selection) แทนที่จะกลับไปที่ Game Hub และในหน้านั้น **ไม่มีปุ่มให้กดกลับไปยังหน้า Game Hub หรือหน้า Login**
- **ข้อเสนอแนะ**: ควรเพิ่มปุ่ม "กลับหน้าหลัก" (Back to Hub) หรือปรับให้ปุ่ม "RETURN" ในหน้าสรุปผลพากลับไปที่ Game Hub ทันทีเพื่อปิดลูปเกม

### 3. [Medium] Hitbox สำหรับกดตอบคำถามเล็กเกินไป
- **รายละเอียด**: ในการเลือกคำตอบ พบว่าพื้นที่การคลิก (Hitbox) สำหรับเกม Context Clues ค่อนข้างเล็ก ทำให้กดยากในบางจังหวะ
- **ข้อเสนอแนะ**: เนื่องจากกลุ่มเป้าหมายคือผู้สูงอายุ (MCI) ควรขยายขนาดพื้นที่กดคำตอบให้กว้างขึ้นและตอบสนองได้ง่ายขึ้น

### 4. [Low] แจ้งเตือน Plugin และ Version ใน Console
- พบ Warning: `Invalid Scene Plugin: rexUI`
- พบ Error: `Can't supported version : 3` ปรากฏซ้ำๆ ควรตรวจสอบ Asset version (อาจจะเป็นไฟล์ Tilemap หรือ Texture) หรือการตั้งค่า Plugin เพื่อลดขยะใน Log
