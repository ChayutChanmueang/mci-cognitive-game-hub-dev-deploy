# Bug Report: BUG-002 - Zoo Detective Drag-and-Drop Scroll Offset

**Status:** ✅ Resolved
**Severity:** 🟡 Low (UX Issue)
**Affected Sprint:** [sprint-03](sprint-03.md)

## 📖 Description
ปัญหาการลากวาง (Drag-and-Drop) ในเกม Zoo Detective ไม่ Snap เข้าตำแหน่งที่ถูกต้องเมื่อมีการ Scroll หน้าจอ ทำให้วางสัตว์ลงในกรงได้ยาก

## 🛠 Fix Details
- ปรับปรุงการคำนวณ Input Coordinate ของ Phaser โดยนำค่า Scroll Offset มาคำนวณร่วมด้วยในการหาตำแหน่ง Snap Point
- ใช้ฟังก์ชันตรวจสอบตำแหน่งที่แม่นยำยิ่งขึ้นเพื่อให้สอดคล้องกับพิกัดหน้าจอจริง (World Transform)
