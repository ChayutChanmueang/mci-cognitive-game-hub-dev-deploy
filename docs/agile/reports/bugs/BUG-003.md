# Bug Report: BUG-003 - Database Logging Foreign Key Fix

**Status:** ✅ Resolved
**Severity:** 🟠 Medium
**Affected Sprint:** [sprint-03](sprint-03.md)

## 📖 Description
เกิด Error `409 Conflict` และ `Error 23503: Foreign key constraint violation` เมื่อพยายามส่ง Log Event เกมไปที่ตาราง `user_event_log` เนื่องจาก `eventid` ที่ส่งไปไม่มีอยู่จริงในฐานข้อมูล

## 🛠 Fix Details
- แก้ไขข้อมูลในตารางอ้างอิง `eventid_list_data` ให้ครบถ้วน
- เพิ่มระบบ Error Handling แบบ Non-blocking ในการส่ง Log หากเกิด Foreign Key Violation เพื่อไม่ให้เกมค้าง (ผู้เล่นสามารถเล่นเกมต่อได้ปกติ)
