# Bug Report: BUG-004 - Black background after returning from full-screen mini-game

**Status:** ✅ Resolved (2026-07-07 — owner verified: แสดงผลได้ปกติ)
**Severity:** 🟠 Medium (Visual / UX)
**Affected Sprint:** [sprint-07](../../sprint-backlogs/sprint-07.md)

## 📖 Description
เมื่อผู้เล่นเข้าสู่มินิเกมที่อยู่ใน **โหมดเต็มจอ (full-screen)** แล้วกลับมาที่หน้า **Game Hub** หน้าจอจะเกิดอาการ **พื้นหลังเป็นสีดำ** (background กลายเป็นสีดำแทนพื้นหลังปกติของ Game Hub)

**Steps to reproduce:**
1. เข้าหน้า Game Hub
2. เปิดมินิเกมที่เข้าสู่โหมด full-screen
3. ออกจากมินิเกมกลับมาหน้า Game Hub
4. **ผลที่เกิด (เดิม):** พื้นหลังหน้า Game Hub เป็นสีดำ

## ✅ Resolution
- Owner ยืนยัน 2026-07-07 ว่ากลับจากมินิเกม full-screen แล้ว **พื้นหลัง Game Hub แสดงผลปกติ** (ไม่เป็นสีดำ)
- การออกจาก full-screen คืนค่า background/DOM shell ถูกต้องแล้ว

## 🛠 Proposed Fix *(implemented)*
- ตรวจสอบการออกจาก Fullscreen API และการคืนค่า/รีเซ็ต background ของ DOM shell หรือ Phaser canvas เมื่อกลับสู่ Game Hub
- คืนค่า background-color / mode class ของ body/หน้า Game Hub ให้ถูกต้องหลัง exit fullscreen
- ตรวจ lifecycle ของ Phaser scene/canvas ว่าถูกทำลาย/ซ่อนอย่างถูกต้องเมื่อกลับมา DOM
