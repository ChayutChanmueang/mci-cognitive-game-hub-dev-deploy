# Bug Report: BUG-001 - Supabase Transient Connection Fix

**Status:** ✅ Resolved
**Severity:** 🟠 Medium
**Affected Sprint:** [sprint-03](sprint-03.md)

## 📖 Description
พบปัญหา `Missing VITE_SUPABASE_URL` หรือการเชื่อมต่อล้มเหลวชั่วคราวในช่วงการ Login ครั้งแรก

## 🛠 Fix Details
- เพิ่มระบบ **Retry Mechanism** ในการเชื่อมต่อ Supabase เพื่อป้องกันปัญหา Transient Error ในช่วงการ Initialize Client หรือโหลด Environment Variables
- ตรวจสอบและปรับปรุงการโหลดค่า Config ให้เสถียรขึ้นก่อนเริ่มใช้งาน Client
