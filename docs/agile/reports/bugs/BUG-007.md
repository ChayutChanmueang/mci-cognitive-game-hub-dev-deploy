# Bug Report: BUG-007 - Game Hub header not centered in some browsers (`justify-items` on a non-grid element)

**Status:** ✅ Resolved (2026-06-26)
**Severity:** 🟡 Low (Layout / cross-browser)
**Affected Sprint:** [sprint-07](../../sprint-backlogs/sprint-07.md)
**Fixed in:** `0.14.2`

## 📖 Description
บนหน้า Game Hub กล่อง header (`.gh-header-bar`) **ไม่ถูกจัดให้อยู่กึ่งกลาง** ในบางเบราว์เซอร์ (เห็นชัดบน Firefox) — เลื่อนไปชิดซ้าย แทนที่จะอยู่กลาง shell

DevTools เตือนว่า:
> `justify-items has no effect on this element since it's not a grid container. Try adding display:grid or display:inline-grid.`

ที่ element `<div class="gh-header-float">`

## 🔎 Root Cause
`.gh-header-float` (ใน `public/components.css`) ตั้งใจจัดลูก (`.gh-header-bar`, ซึ่ง `width: min(95%, …)`) ให้อยู่กึ่งกลางด้วย `justify-items: center` — **แต่ `justify-items` มีผลเฉพาะกับ grid container** ส่วน `.gh-header-float` เป็น block flow ธรรมดา → property ถูกเพิกเฉย → ลูกชิดซ้ายตาม default ของ block

นอกจากนี้ `justify-self: center` ที่ตั้งไว้บนตัวมันเองก็ไม่มีผลเช่นกัน เพราะ parent `.hub-clean-shell` เป็น `position: relative` (block) ไม่ใช่ grid/flex — การจัดกึ่งกลางจึงไป "บังเอิญ" ทำงานต่างกันในแต่ละ engine

## ✅ Resolution (2026-06-26)
CSS-only ใน `public/components.css` ที่ `.gh-header-float`:
- เพิ่ม **`display: grid`** → `justify-items: center` ทำงานจริง จัดลูก `.gh-header-bar` ให้อยู่กึ่งกลาง
- เพิ่ม **`margin-inline: auto`** → จัดตัว `.gh-header-float` เองให้อยู่กึ่งกลางใน shell แบบเสถียร โดยไม่พึ่ง `justify-self` ที่ใช้ไม่ได้กับ block parent (ลบ `justify-self: center` ที่ตายแล้วออก)

ผล: header อยู่กึ่งกลางเหมือนกันทุกเบราว์เซอร์ และ DevTools ไม่เตือนอีก
