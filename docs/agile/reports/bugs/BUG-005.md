# Bug Report: BUG-005 - Premature navigation during slow data load bounces user back to Game Hub

**Status:** 🔴 Open
**Severity:** 🔴 High (Functional / UX blocking)
**Affected Sprint:** [sprint-07](../../sprint-backlogs/sprint-07.md)

## 📖 Description
เมื่อข้อมูลโหลดช้า (Game Hub / `main.js` ยังโหลดข้อมูลจาก database ไม่เสร็จ) แต่ผู้ใช้กดเปิดเกมหรือเปิดหน้าอื่นก่อน ระบบจะ **ดีดผู้ใช้กลับมาหน้า Game Hub** เมื่อโหลดเสร็จ ทำให้เสียการกระทำที่ทำค้างไว้

**Steps to reproduce:**
1. เปิดแอปบนเครือข่าย/อุปกรณ์ที่โหลดข้อมูลช้า
2. **กรณี A:** ผู้ใช้กดเปิดมินิเกม **ก่อน** ข้อมูลโหลดเสร็จ → พอโหลดเสร็จระบบดีดกลับมาหน้า Game Hub
3. **กรณี B:** ผู้ใช้อยู่หน้า Game Hub แล้วเปิดหน้า **Leaderboard ก่อน** Game Hub โหลดเสร็จ → ระบบดีดกลับมาหน้า Game Hub

## 🛠 Proposed Fix
แนวทางใดแนวทางหนึ่ง (หรือผสมกัน):
- เพิ่ม **หน้า Loading overlay** ทับหน้าเว็บไว้ก่อนจนกว่าข้อมูลจะโหลดเสร็จ เพื่อกันไม่ให้ผู้ใช้กดอะไรระหว่างโหลด
- แก้ flow ให้ระบบ **ไม่ reload/redirect กลับมาหน้า Game Hub** เมื่อข้อมูลโหลดเสร็จ (ให้คงหน้า/การกระทำปัจจุบันของผู้ใช้ไว้)
