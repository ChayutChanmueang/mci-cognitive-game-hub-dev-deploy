## 📖 Description
การปรับปรุงความสม่ำเสมอของส่วนต่อประสานผู้ใช้ (UI Consistency) และเพิ่มภาพเคลื่อนไหว (Animation) ให้กับหน้าจอมินิเกมต่างๆ เพื่อเพิ่มความรู้สึกที่เป็นมืออาชีพและใช้งานง่ายสำหรับกลุ่มเป้าหมาย

---

## ✅ Polish Tasks
- **UI Consistency**: ปรับแต่งปุ่มและสีธีมให้เหมือนกันทั่วทั้งโปรเจกต์
- **Animation**: เพิ่ม Transition ระหว่างหน้าจอ (Hub -> Game) เพื่อลดความกระด้างในการเปลี่ยนฉาก
- **Navigation**: ปรับปรุง Flow การออกจากเกมให้กลับไปหน้าหลักอย่างราบรื่น
