## Bug Report: ข้อบกพร่องที่พบจากการทดสอบ

### 1. พบปัญหา Foreign Key Constraint ของตาราง Logging บน Supabase
- **Title**: ระบบไม่สามารถส่ง Log Event เกมไปที่ตาราง `user_event_log` ได้
- **Environment**: Local Development
- **Pre-conditions**: ผู้เล่นเข้าสู่ระบบและกดปุ่มเริ่มเล่นเกม
- **Steps to Reproduce**:
  1. Login เข้าสู่ระบบและเข้าหน้า Game Hub
  2. กดเลือกเกม (เช่น Zoo Feeder)
  3. สังเกตการยิง API ไปยัง Supabase ใน Network/Console
- **Expected Result**: API ส่งข้อมูลสำเร็จ (Status 200/201) และไม่มี Error ปรากฏ
- **Actual Result**: พบ Error `409 Conflict` และ `Error 23503: Foreign key constraint violation` สาเหตุอาจเกิดจาก Event ID ที่กำลังจะบันทึก ไม่มีอยู่ในตาราง `eventid_list_data` ของฐานข้อมูล
- **Severity/Priority**: 🟠 Medium (ระบบเกมทำงานได้ต่อ แต่ระบบเก็บข้อมูลหลังบ้านทำงานผิดพลาด)

### 2. แจ้งเตือน Plugin ของ Phaser
- **Title**: แจ้งเตือน `Invalid Scene Plugin: rexUI`
- **Environment**: Local Development
- **Severity/Priority**: 🟡 Low
- **Note**: เป็นเพียง Warning ไม่มีผลกระทบกับการเล่นโดยตรง แต่ควรตรวจสอบการนำเข้า (Import) และตั้งค่า Plugin ของ RexUI ในระดับ Config ว่าตั้งค่าถูกวิธีหรือไม่
